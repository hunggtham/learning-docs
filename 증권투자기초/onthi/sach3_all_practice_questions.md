# 제1장 포트폴리오 이론

## 제1절 통계학 기초 — 연습문제 (37–38쪽)

1. 주사위 위에 1, 2, 3, 4, 5, 6 등 여섯 개의 숫자가 쓰여 있다. 이들 숫자의 평균과 표준편차는 얼마인가?

2. 동전을 던져서 앞면이 나오면 1만 원을 주고 뒷면이 나오면 2천 원을 주는 게임이 있다. 이 게임에 참가했을 때 받게 되는 평균 상금은 얼마인가?

3. 주사위를 던져서 짝수가 나오면 2만 원을 받고 홀수가 나오면 1만 원을 받는 게임이 있다. 이 게임에서 받게 되는 상금의 표준편차는 얼마인가?

4. 서울반도체의 5개월 간의 월말종가가 아래 표와 같을 때, 서울반도체의 월말종가 평균값은 얼마인가? (단, 10원 미만은 절사한다.)

   | 날짜 | 종가 | 날짜 | 종가 |
   |---|---:|---|---:|
   | 2007.10.31 | 10,000 | 2008.1.30 | 12,250 |
   | 2007.11.28 | 7,980 | 2008.2.27 | 22,700 |
   | 2007.12.30 | 8,880 | | |

5. POSCO의 월평균수익률이 3%라고 한다면, 6개월간 POSCO주식을 보유했을 때 총수익률은 얼마가 될 것이라고 예상할 수 있는가?

6. 쌍용건설과 SK에너지의 기대수익률의 표준편차는 각각 5, 10이고, 두 회사의 기대수익률의 공분산은 500이라고 한다. 쌍용건설과 SK에너지의 상관계수는 얼마인가?

7. 시장위험프리미엄을 X, 무위험이자율을 a, 베타값을 b, 주식의 기대수익률을 E(R)이라고 하자. CAPM에 의하면 주식의 기대수익률은 E(R)=a+bX와 같은 형태이다. 만약 시장위험프리미엄의 값이 10%, 무위험이자율은 4%, 베타값이 1.5라면 주식의 기대수익률값은 얼마인가?

## 제2절 포트폴리오 이론 — 복습문제 (67–68쪽)

※ 다음 글을 읽고 맞는 것에 ○표, 틀린 것에는 ×표를 하시오.

1. 포트폴리오 이론의 출발점이었으며, 노벨상을 수상한 마코위츠의 논문은 “포트폴리오 선택(portfolio selection)”이다. ( )

2. 예전의 유태인들은 자신들의 땅문서 등 자산적 가치를 지닌 서류들을 작은 가방에 넣고 들고 다녔는데, 그것을 “포트폴리오(portfolio)”라 하였다고 한다. ( )

3. 투자자들은 투자대상이 되는 주식에 대해서 수익률의 확률분포를 미리 알고 있으며, 그 확률분포에 대해서 모든 투자자들이 동일하게 예측한다는 가정을 동질적 예측의 가정이라고 한다. ( )

4. 기대효용이란 주식으로부터 얻게 되는 미래수익의 평균값을 말하고, 기대수익이란 투자로부터 얻게 되는 효용의 미래 확률분포의 평균값을 말한다. ( )

5. 위험회피적 투자자의 효용함수는 재산의 증가에 따라 기대효용이 커지며 체증적으로 증가한다. ( )

6. 주식수익률이란 일정 기간 동안 주식을 보유한 결과로 얻게 되는 수익률로서 배당수익과 시세차익으로 구성된다. ( )

7. 위험이란 미래현금흐름의 변동가능성을 의미하며 현금흐름의 변동폭이 크면 위험하다고 하며, 현금흐름의 변동폭이 작으면 위험이 작다고 한다. ( )

8. 위험의 크기는 실제 나타난 수익률이 예상평균수익률과 얼마나 차이가 날 수 있는가에 따라 측정한다. ( )

9. 두 주식으로 구성된 포트폴리오의 표준편차는 각 주식의 표준편차에 대하여 투자비율을 가중치로 구한 가중평균값이다. ( )

10. 두 주식으로 구성된 포트폴리오의 분산값은 두 주식의 상관계수에 따라 달라진다. ( )

11. 포트폴리오를 구성하는 주식의 수를 증가하면 포트폴리오의 분산값은 한없이 작아져서 무한대의 주식으로 구성된 포트폴리오의 분산값은 0에 가깝다. ( )

12. 포트폴리오의 구성주식수를 증가하면 줄어드는 위험부분을 개별적 위험이라고 한다. ( )

13. 기대수익률이 높으면 위험은 낮고, 기대수익률이 낮으면 위험이 높아야 한다는 원리를 기대수익률과 위험의 상충관계라 한다. ( )

14. 두 주식으로 구성된 포트폴리오 중에서 분산값이 가장 작은 포트폴리오를 최소 분산포트폴리오라고 한다. ( )

15. 분석대상이 되는 투자기회집합 전체에 대해서 지배원리를 충족시키는 포트폴리오의 집합을 효율적 투자선(efficient frontier)이라고 한다. ( )

16. 무위험자산은 실현될 수익률이 확실한 자산을 말한다. ( )

17. 무위험자산과 위험자산의 상관계수는 0이 될 수 없다. ( )

18. 무위험자산의 수익률의 분산값은 항상 0이다. ( )

19. 기대수익률을 Y축, 위험을 X축으로 2차원 평면에 자본배분선을 그리면 절편은 무위험자산의 수익률이 된다. ( )

20. 자본배분선의 기울기는 위험이 한 단위 증가하는 데에 따른 보상을 나타내므로 위험보상비율이라고 부른다. ( )

## 제3절 자본자산가격결정모형 — 복습문제 (93쪽)

※ 다음 글을 읽고 맞는 것에 ○표, 틀린 것에는 ×표를 하시오.

1. CAPM이 설정한 세상에서는 투자자는 무위험자산을 얼마든지 빌리거나 빌려줄 수 있다. ( )
2. CAPM이 설정한 세상에서는 투자자는 시장에서 결정된 가격으로 투자자산을 사고 판다. ( )
3. 자본배분선에서 위험자산을 시장포트폴리오로 놓으면 자본배분선은 자본시장선이 된다. ( )
4. 시장포트폴리오에 포함되어 있지 않은 주식도 시장에 존재할 수 있다. ( )
5. 시장포트폴리오의 구성비율은 각 주식의 시가비율에 따라 결정된다. ( )
6. 투자자들이 시장포트폴리오라는 위험자산을 보유하기 때문에 부담하는 위험은 비체계적 위험이라고 할 수 있다. ( )
7. 시장포트폴리오의 베타가 1이 아닌 경우도 있을 수 있다. ( )
8. 포트폴리오의 베타는 구성자산들의 베타를 동일한 비중에 따라 산술평균한 값이다. ( )
9. 증권시장선의 절편은 반드시 무위험자산의 수익률이다. ( )
10. 개별주식의 베타가 결정되면 그 주식의 기대수익률은 증권시장선에 의해 결정된다. ( )

### 연습문제 (94–95쪽)

1. 다음 중 CAPM에 대한 내용으로 부적절한 것은? ( )
   ① 자본자산가격결정모형
   ② 현대 재무론의 핵심
   ③ 자산의 위험에 따라 기대수익률이 어떻게 결정되는지를 보여주는 이론
   ④ 부동산의 균형가격 결정이론

2. 다음 중 균형가격과 CAPM에 대한 설명으로 가장 부적절한 것은? ( )
   ① 시장가격은 수요와 공급에 의해 결정
   ② 주식의 시장수요는 개별수요를 수평으로 합하여 결정
   ③ 균형가격은 수요와 공급이 만나는 점에서 결정
   ④ 일단 균형가격이 결정되면 항상 장기간 그 가격을 유지

3. 다음 중 CAPM이 널리 사용되는 이유로 가장 부적절한 것은? ( )
   ① 많은 중요한 응용예에서 상당한 정확성을 보였다.
   ② 위험과 기대수익률의 관계에 대해 직관을 제시한다.
   ③ 시장포트폴리오의 개념에 대한 직관을 제시한다.
   ④ CAPM이 완전히 검증된 모형이기 때문이다.

4. 다음 중 동질적 기대의 가정에 대한 설명으로 부적절한 것은? ( )
   ① homogeneous expectations
   ② 모든 투자자들은 증권을 동일한 방법으로 분석
   ③ 모든 투자자들은 세계 경제에 대해서 동일한 견해를 가짐
   ④ 모든 투자자들은 서로 동질적인 친밀감을 가지고 협력해서 투자함

5. 다음 중 시장포트폴리오에 대한 설명으로 부적절한 것은? ( )
   ① 모든 증권이 포함되어 있다.
   ② 시장포트폴리오의 구성비율은 구성주식의 시장가치의 비율이다.
   ③ 시장포트폴리오는 최적 위험포트폴리오이다.
   ④ 모든 투자자는 무위험자산은 보유하지 않고 시장포트폴리오만 보유한다.

6. 다음 중 무위험이자율이 5%, 시장포트폴리오의 기대수익률이 10%인 경우, 어떤 증권의 베타가 1.0이라면 이 증권의 기대수익률은 얼마인가? (CAPM을 이용하여 계산하시오) ( )
   ① 20%   ② 25%   ③ 15%   ④ 10%

## 제4절 효율적 시장 — 복습문제 (121–122쪽)

※ 다음 글을 읽고 맞는 것에 ○표, 틀린 것에는 ×표를 하시오.

1. 시장이자율을 기준으로 생산자와 소비자가 의사결정을 하는 경우의 효율성을 배분의 효율성이라 한다. ( )
2. 거래비용이 최소화되어 시장에서 거래가 원활하게 이루어지는 경우의 효율성을 운영의 효율성이라 한다. ( )
3. 정보가 공개되는 시점에서 가격이 변화하면 정보는 주가에 충분히 반영되었다고 할 수 있다. ( )
4. 효율적 시장에서 형성된 주가는 내재가치의 불편추정량이 되어야 한다. ( )
5. 현재의 주가가 과거의 가격이나 거래량과 같은 과거정보를 이미 반영하고 있다면 준강형 효율적이라고 할 수 있다. ( )
6. 약형 효율적 시장가설이란 현재의 주가는 공개적으로 이용가능한 모든 정보를 반영하고 있다는 것이다. ( )
7. 강형 효율적 시장에서는 어떤 투자자도 어떤 정보를 이용하여 주식거래를 한다고 하여 큰 수익을 지속적으로 얻을 수 없다. ( )
8. 효율적 시장에서는 주가가 모든 정보를 전부 즉시 반영하고 있으므로, 과거 거래자료에 기초한 기술적 분석은 가치가 없을 것이다. ( )
9. 적극적 투자관리란 시장포트폴리오의 평균수익률 이상의 수익률을 얻기 위하여 열심히 정보를 수집하고 분석하는 투자를 말한다. ( )
10. 과거수익률이 시간에 따라 일정한 방향을 보이는지 조사하는 것은 준강형 효율적 시장가설을 검증하는 한 방법이다. ( )
11. 준강형 효율적 시장가설을 검증하기 위하여 정보의 공표시점 전후의 주가동향을 조사하는 방법이 사용된다. ( )
12. 어느 해에 수익률이 많이 난 주식은 5년에 걸쳐 수익률이 줄어드는 모습을 보인다면 양의 자기상관이 있다는 증거다. ( )
13. 장기간에 걸친 음의 자기상관을 이용하여 과거 3년 동안 낮은 수익률을 보였던 주식을 모아서 포트폴리오로 투자하면, 이후 3년간 반대의 수익률을 나타내는 현상을 패자포트폴리오 현상이라고 한다. ( )
14. 미국에서 시장가치를 기준으로 기업규모를 5그룹으로 구분하고 가장 작은 기업군에 속하는 주식포트폴리오와 가장 큰 기업군에 속하는 주식포트폴리오의 수익률을 조사한 결과, 작은 기업군의 수익률이 매우 높았다. ( )
15. 주가수익비율(PER)이 낮은 포트폴리오와 높은 포트폴리오를 비교조사한 결과, 낮은 포트폴리오의 수익률이 낮은 것으로 나타났다. ( )
16. 1월의 주가수익률이 다른 월의 주가수익률에 비해 유의적으로 낮은 현상을 1월효과라 한다. ( )

### 연습문제 (123–124쪽)

1. 다음 중 효율성의 의미에 대한 설명으로 부적절한 것은? ( )
   ① 배분의 효율성
   ② 운영 효율성
   ③ 사회 전체의 효용이 극대화되도록 자원의 배분이 이루어져야 한다.
   ④ 모든 투자자산의 거래는 적정한 거래비용이 발생해야 한다.

   ② 관련 정보가 모든 투자자에게 비용이 없이 공평하게 배분
   ③ 관련 정보가 시장가격에 정확하게 반영
   ④ 관련 정보는 상황에 따라 선별적으로 제공

3. 다음 중 효율적 시장가설의 관점에서 주가의 무작위한 움직임에 대한 설명으로 적절한 것은? ( )

## 제6절 기업가치평가론 — 복습문제 (167–168쪽)

※ 다음 글을 읽고 맞는 것에 ○표, 틀린 것에는 ×표를 하시오.

1. 기업가치평가란 기업의 공정시장가치를 추정하는 과정을 말한다. ( )
2. 기업의 특성에는 주력 제품에서 발생하는 경기변동에 대한 민감도가 포함된다. ( )
3. 손익계산서는 생산을 위한 투자활동과 그에 소요되는 투자자금의 조달활동에 대한 정보를 제공한다. ( )
4. 현금흐름표는 생산 이후 판매활동의 결과를 정리한 재무제표라 할 수 있다. ( )
5. 현금흐름을 측정할 때는 기업의 미래 본원적 가치를 측정해야 하므로 자금조달과 관련한 금융비용을 제외해야 한다. ( )
6. 현금흐름을 측정할 때는 현금이 유출되는 세금을 고려하여 세후 현금흐름을 측정해야 한다. ( )
7. 기업의 자본비용이란 기업이 사업을 수행하기 위해 조달한 자본에 대한 사용대가이다. ( )
8. 자본비용은 투자자의 입장에서는 투자자의 요구수익률 또는 필수수익률이 된다. ( )
9. 전액 자기자본으로 조달한 경우에는 주식의 자본비용을 기업의 자본비용으로 사용해서는 안 된다. ( )
10. 부채의 자본비용은 자기자본의 조달비용을 의미한다. ( )
11. 타인자본비용은 이자비용이 법인소득에서 공제되기 때문에 세금차감 전의 기준으로 산정해야 한다. ( )
12. 배당성장모형은 미래의 배당수입의 현가로부터 보통주를 평가하는 방법이다. ( )
13. CAPM에 의하면 주식의 기대수익률은 증권시장선으로 측정가능하다. ( )
14. 가중평균자본비용은 각 원천별 자본비용을 각 자본의 구성비율로 가중하여 계산한다. ( )
15. 대표적인 상대가치평가방법으로는 여유현금흐름할인법과 경제적 부가가치방법을 들 수 있다. ( )
16. 여유현금흐름법에서 기업가치는 모든 미래의 여유현금흐름을 적절한 할인율로 할인한 현재가치로 추정하여 구한다. ( )
17. 투하자본이란 영업활동을 위해 투자된 자본총액을 말한다. ( )
18. 상대가치평가법에서 배수란 가치지표를 평가기준변수로 나눈 비율을 말한다. ( )
19. 주가수익비율(PER)은 주식가격을 주당순이익으로 나눈 값이다. ( )
20. 경제적 부가가치의 크기는 세후영업이익에서 금액으로 측정된 자본비용을 차감하여 구할 수 있다. ( )
