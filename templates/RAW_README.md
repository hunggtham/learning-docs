# Raw source boundary

This directory preserves source material and provenance. It is not canonical learning prose.

## Subdirectories

- original/: source files preserved as received;
- extracted/: deterministic text extraction;
- ocr/: OCR output requiring representative review;
- derived/: source-faithful conversions with provenance;
- _catalog/: metadata or reference indexes marked as non-canonical.

Do not translate, rewrite or silently correct original files. Record changes in SOURCE_MANIFEST.yaml and place research prose under the corpus research/ directory.
