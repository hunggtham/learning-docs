## 1. 고급 선택 쿼리 (Select Query — 선택 쿼리)

선택 쿼리는 하나 이상의 테이블이나 기존 쿼리로부터 특정 조건에 일치하는 데이터를 추출하여 가상 테이블 형태로 표시하는 가장 기초적이면서 필수적인 쿼리입니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ 쿼리 디자인 격자 (Query Design Grid) 인터페이스 구조                   │
├─────────────┬─────────────┬─────────────┬─────────────┬────────────────┤
│ 필드 (Field) │ 학번        │ 성명        │ 총점: [중간]+[기말]│ 판정: IIf(...) │
│ 테이블(Table)│ 학생        │ 학생        │             │                │
│ 정렬 (Sort) │             │             │ 내림차순     │                │
│ 표시 (Show) │ [v]         │ [v]         │ [v]         │ [v]            │
│ 조건 (Criteria)           │ Like "김*"  │ >= 80       │                │
│ 또는 (Or)   │             │             │             │                │
└─────────────┴─────────────┴─────────────┴─────────────┴────────────────┘
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <학생> 테이블을 이용하여 다음과 같은 조건을 만족하는 <장학대상자> 쿼리를 작성하시오.
   - '학과'가 "컴퓨터" 또는 "정보통신"이고, '평점'이 4.0 이상인 학생만을 대상으로 할 것.
   - '중간'과 '기말' 점수의 합을 계산하여 '총점' 필드를 생성할 것.
   - '총점'을 기준으로 내림차순 정렬하여 상위 5개의 레코드만 표시할 것.
```

### 1.1 조건식 연산자 및 와일드카드 기호 대조표 (Criteria)

쿼리 디자인 그리드의 **`조건 (Criteria)`** 행에 입력하는 표준 조건식 문법입니다.

| 연산자 유형 | 조건식 작성 구문 (Cú pháp điều kiện) | 실제 필터링 동작 (Hành vi lọc dữ liệu thực tế) |
|---|---|---|
| **`Like "*단어*"`** | `Like "*서울*"` | 텍스트 내 어느 위치든 "서울"이라는 단어가 포함된 레코드 추출.<br>*Trích xuất bản ghi chứa từ "서울" ở bất kỳ vị trí nào trong chuỗi.* |
| **`Like "글자*"`** | `Like "김*"` | 성이 "김"으로 시작하는 모든 레코드 추출.<br>*Trích xuất tất cả bản ghi bắt đầu bằng chữ "김" (họ Kim).* |
| **`Like "???-????"`** | `Like "???-????"` | 물음표(`?`)는 임의의 한 글자를 의미함. 4번째 자리에 하이픈이 있는 8자리 텍스트.<br>*Dấu `?` đại diện đúng 1 ký tự bất kỳ. Chuỗi gồm 8 ký tự có dấu gạch ngang ở vị trí thứ 4.* |
| **`Between ... And`**| `Between #2026-01-01# And #2026-12-31#` | 2026년도 전체 기간 내의 날짜 추출 (날짜 상수는 `#`으로 감쌈).<br>*Trích xuất các ngày trong trọn vẹn năm 2026 (hằng số ngày bọc trong dấu `#`).* |
| **`In (...)`** | `In ("VIP", "골드", "실버")` | 나열된 값 목록 중 하나와 일치하는 레코드 추출 (다중 `OR` 연산).<br>*Trích xuất bản ghi trùng với một trong các giá trị danh sách liệt kê (phép toán OR).* |
| **`Is Null`** | `Is Null` | 해당 필드의 값이 비어 있는(Null) 레코드만 추출.<br>*Chỉ trích xuất các bản ghi có trường dữ liệu này bị bỏ trống.* |
| **`Is Not Null`** | `Is Not Null` | 데이터가 입력되어 있는(Null이 아닌) 레코드만 추출.<br>*Chỉ trích xuất các bản ghi đã có dữ liệu nhập (khác rỗng).* |
| **수치 비교** | `>= 500000 And <= 1000000` | 500,000 이상 1,000,000 이하 범위의 수치 데이터 추출.<br>*Trích xuất dữ liệu số trong khoảng từ 500,000 đến 1,000,000.* |

### 1.2 계산 필드 작성 (Calculated Fields)

기존 필드들을 연산하여 새로운 열을 생성할 때는 필드 행에 다음 형식으로 작성합니다:
$$\mathbf{\text{새로운\_필드명: [기존\_필드명1] + [기존\_필드명2]}}$$

- **필수 작성 규칙:** 새 필드명 뒤에 **콜론(`:`)**을 붙이고, 수식에 사용되는 기존 필드명은 반드시 **대괄호(`[...]`)**로 묶어야 합니다.

---

### 1.3 쿼리 주요 내장 함수 모음

- **조건 판단 함수 `IIf`:**
  $$\mathbf{IIf(조건식, \; 참일때\_값, \; 거짓일때\_값)}$$
  - *예시:* `판정: IIf([평균] >= 80, "합격", "불합격")`
- **다중 분기 함수 `Switch`:**
  $$\mathbf{Switch(조건1, \; 결과1, \; 조건2, \; 결과2, \; \dots, \; True, \; 기본값)}$$
  - *예시:* `등급: Switch([점수] >= 90, "A", [점수] >= 80, "B", [점수] >= 70, "C", True, "F")`
- **서식 변환 함수 `Format`:**
  - *예시:* `변환금액: Format([단가], "#,##0원")`, `등록연월: Format([입사일], "yyyy-mm")`
- **날짜 계산 함수:**
  - `DateDiff("간격단위", [시작일], [종료일])`: 두 날짜 사이의 기간 계산. 단위: `"yyyy"`(년), `"m"`(월), `"d"`(일).  
    *예시 (나이 계산):* `나이: DateDiff("yyyy", [생년월일], Date())`
  - `DateAdd("간격단위", 더할수, [기준일])`: 날짜에 특정 기간을 합산.
  - `Year([날짜])`, `Month([날짜])`, `Day([날짜])`: 연, 월, 일 정수 추출.
- **문자열 조작 함수:**
  - `Left([필드], 개수)`, `Right([필드], 개수)`, `Mid([필드], 시작위치, 개수)`
  - `InStr([필드], "찾을문자")`: 문자열 내에서 특정 문자가 처음 나타나는 위치 반환.

## 2. 요약 집계 쿼리 (Totals / Group By Query — 요약 쿼리)

데이터를 특정 기준 필드로 그룹화(묶는 방법)하고, 각 그룹별 합계, 평균, 개수, 최댓값, 최솟값을 산출하는 쿼리입니다.

```
┌────────────────────────────────────────────────────────┐
│ 요약 쿼리 격자 행 구성                                │
├─────────────┬─────────────┬─────────────┬──────────────┤
│ 필드        │ 부서명      │ 급여        │ 사번         │
│ 테이블      │ 사원        │ 사원        │ 사원         │
│ 요약(Total) │ 묶는 방법   │ 합계        │ 개수         │
│ 표시        │ [v]         │ [v]         │ [v]          │
└─────────────┴─────────────┴─────────────┴──────────────┘
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <주문> 테이블을 이용하여 부서별 주문 현황을 조회하는 <부서별요약> 쿼리를 작성하시오.
   - '부서명'별로 그룹화할 것.
   - '주문금액'의 합계와 '주문번호'의 개수를 산출할 것.
```

#### 요약(Total) 행 옵션별 설정 규칙:
- 리본 메뉴의 **[쿼리 디자인] 탭 $\rightarrow$ [표시/숨기기] 그룹 $\rightarrow$ [$\Sigma$ 요약]** 아이콘을 클릭하여 그리드에 **`요약`** 행을 활성화합니다.
- **`묶는 방법 (Group By)`:** 그룹화 기준 필드에 지정 (예: `부서명`, `지역`).
- **`합계 (Sum)` / `평균 (Avg)` / `개수 (Count)`:** 집계 수치 필드에 지정.
- **`조건 (Where)` — 핵심 필수 암기:**  
  집계 대상에서 제외할 조건을 지정하되 해당 필드를 결과 화면에 표시하지 않을 때 선택합니다. `조건`으로 바꾸면 **`표시 (Show)` 체크박스가 자동으로 해제**됩니다.

## 3. 매개변수 쿼리 (Parameter Query — 매개변수 쿼리)

쿼리를 실행할 때 사용자로부터 검색 값을 직접 입력받는 대화 상자를 띄우고, 입력된 값을 조건으로 사용하여 결과를 검색하는 쿼리입니다.

```
┌────────────────────────────────────────────────────────┐
│ 매개변수 값 입력 (Enter Parameter Value)               │
├────────────────────────────────────────────────────────┤
│ 조회할 부서명을 입력하시오                              │
│ ┌────────────────────────────────────────────────────┐ │
│ │ 영업부                                             │ │
│ └────────────────────────────────────────────────────┘ │
│                        [ 확인 ]       [ 취소 ]         │
└────────────────────────────────────────────────────────┘
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ 다음과 같은 매개변수 입력 메시지가 나타나도록 쿼리를 작성하시오.
   - '성명'에 입력된 문자가 포함된 레코드를 검색할 것.
   - 매개변수 메시지: [검색할 성명의 일부를 입력하시오]
```

#### 조건(Criteria) 행 입력 공식:
- **정확히 일치하는 매개변수 (Exact Match):**  
  대화 상자에 표시할 질문 텍스트를 대괄호(`[...]`)로 묶어 입력합니다.
  $$\mathbf{[조회할 \; 부서명을 \; 입력하시오]}$$
- **부분 일치 검색 매개변수 (Wildcard Match — 빈출 1순위):**  
  `Like` 연산자와 와일드카드 문자열(`"*"`)을 `&` 연산자로 연결합니다.
  $$\mathbf{Like \; "*" \; \& \; [검색할 \; 성명의 \; 일부를 \; 입력하시오] \; \& \; "*"}$$

#### 매개변수 데이터 형식 지정 (매개변수 창 설정):
매개변수 입력값이 날짜나 정수 등 특정 형식이어야 할 경우:  
[쿼리 디자인] 탭 $\rightarrow$ [매개변수] 클릭 $\rightarrow$ 매개변수 열에 대괄호 문구를 정확히 입력하고 데이터 형식(예: `날짜/시간`)을 지정합니다.

## 4. 크로스탭 쿼리 (Crosstab Query — 크로스탭 쿼리)

데이터를 행과 열의 2차원 교차 매트릭스 형태로 집계하여 보여주는 피벗 테이블 형식의 쿼리입니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ 크로스탭 쿼리의 3대 구성 요소 매트릭스                                 │
├────────────────┬───────────────────────────┬──────────────────────────┤
│ 행 머리글       │ 열 머리글 (Column Heading) │ 행별 합계 (선택 필드)    │
│ (Row Heading)  │  2024년 │ 2025년 │ 2026년 │ (Row Total)              │
├────────────────┼─────────┼────────┼────────┼──────────────────────────┤
│ 영업1팀        │   120   │   150  │   180  │           450            │
│ 영업2팀        │    90   │   110  │   130  │           330            │
└────────────────┴─────────┴────────┴────────┴──────────────────────────┘
                         ▲
                         └─ 값 (Value): Sum / Count / Avg
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <판매> 테이블을 이용하여 다음과 같은 구조의 <분기별판매크로스탭> 쿼리를 작성하시오.
   - 행 머리글: '제품명'
   - 열 머리글: '판매일자'에서 분기를 추출하여 '1분기', '2분기'... 형태로 표시할 것.
   - 값: '판매금액'의 합계를 표시할 것.
```

#### 크로스탭 3대 요소 설정 규칙:

| 구성 요소 | 한글 설정명 | 허용 필드 수 | 설정 지침 및 작성법 (Quy tắc cấu hình) |
|---|---|:---:|---|
| **행 머리글** | **행 머리글 (Row Heading)** | **여러 개 가능** | 표의 왼쪽에 세로로 나열될 기준 필드. `크로스탭` 행 = `행 머리글`, `요약` 행 = `묶는 방법`.<br>*Tiêu đề dòng nằm dọc bên trái. Có thể thêm nhiều trường. Dòng 크로스탭 chọn 행 머리글, dòng 요약 chọn 묶는 방법.* |
| **열 머리글** | **열 머리글 (Column Heading)**| **반드시 1개만** | 표의 상단에 가로로 펼쳐질 필드 (예: `Format([판매일자], "q""분기""")`). `크로스탭` 행 = `열 머리글`, `요약` 행 = `묶는 방법`.<br>*Tiêu đề cột trải ngang trên đỉnh bảng. Chỉ được phép đúng 1 trường duy nhất.* |
| **값** | **값 (Value)** | **반드시 1개만** | 행과 열의 교차점에 들어갈 계산 수치. `크로스탭` 행 = `값`, `요약` 행 = **`합계`, `개수`, `평균` 등 집계 함수**.<br>*Giá trị giao giữa dòng và cột. Chỉ đúng 1 trường, bắt buộc dùng hàm 집계 như Sum, Count, Avg.* |

## 5. 실행 쿼리 (Action Queries — 실행 쿼리)

실행 쿼리는 단순히 화면에 데이터를 표시하는 데 그치지 않고, 테이블에 저장된 데이터를 물리적으로 직접 변경, 삭제, 추가하거나 새 테이블을 생성하는 쿼리입니다.  
*(Truy vấn hành động trực tiếp thay đổi, cập nhật, xóa hoặc nạp mới bản ghi vào bảng vật lý trong cơ sở dữ liệu).*

```
┌────────────────────────────────────────────────────────┐
│ 실행 쿼리(Action Query)의 4대 유형                     │
├────────────────────────┬───────────────────────────────┤
│ 1. 업데이트 (Update)    │ 기존 레코드의 특정 필드값 일괄 변경│
│ 2. 삭제 (Delete)       │ 조건을 만족하는 레코드 일괄 영구 삭제│
│ 3. 추가 (Append)       │ 조회 결과를 기존 대상 테이블에 덧붙임│
│ 4. 테이블 만들기 (Make) │ 조회 결과를 바탕으로 새 물리 테이블 생성│
└────────────────────────┴───────────────────────────────┘
```

### 5.1 업데이트 쿼리 (Update Query)
- **실전 문제 지시문 (Đoạn đề bài thực tế):**  
  `▶ <제품> 테이블에서 '분류'가 "음료"인 제품들의 '단가'를 10% 인상하는 <단가인상> 업데이트 쿼리를 작성하고 실행하시오.`
- **설정법 (Các bước thiết lập):**
  1. **리본 메뉴에서 [업데이트] 단추 클릭 $\rightarrow$ 그리드에 `업데이트 (Update To)` 행 추가됨.**

  3. **조건 필드(`분류`)의 `조건` 행에 `"음료"` 입력.**

  4. **문제에서 "실행하시오"라고 요구한 경우 상단 [! 실행 (Run)] 단추 클릭.**  
     *Nếu đề yêu cầu thực thi truy vấn, bắt buộc phải bấm nút dấu chấm than đỏ [! 실행] trên Ribbon.*

## 6. 불일치 검색 쿼리 (Unmatched Query — 불일치 검색 쿼리)

불일치 검색 쿼리는 한 테이블(기본 테이블)에는 데이터가 존재하지만, 관련된 다른 테이블(참조 테이블)에는 연관 데이터가 한 번도 발생하지 않은 고아 레코드를 찾아내는 쿼리입니다 (예: "주문 내역이 한 건도 없는 고객 목록").  
*(Truy vấn tìm kiếm không khớp dùng để lọc các bản ghi ở bảng chính nhưng hoàn toàn chưa từng xuất hiện phát sinh ở bảng liên kết).*

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <고객>과 <주문> 테이블을 이용하여 한 번도 주문한 적이 없는 고객의
   '고객ID', '고객명', '전화번호'를 조회하는 <미주문고객> 쿼리를 작성하시오.
```

### 6.1 디자인 보기 수동 작성법 (Left Join & Is Null — 원리 이해 필수)
1. **[쿼리 디자인] 창에 `<고객>` 테이블과 `<주문>` 테이블을 모두 추가합니다.**  
   *Mở Query Design và thêm cả 2 bảng `<고객>` và `<주문>` vào màn hình.*
2. **두 테이블 사이의 관계 연결선을 마우스로 더블클릭하여 [조인 속성 (Join Properties)] 대화 상자를 엽니다.**  
   *Nhấp đúp vào đường nối quan hệ giữa 2 bảng để mở hộp thoại Join Properties.*
3. **옵션 2 (Left Outer Join)를 선택합니다:**  
   `2: '고객'의 모든 레코드를 포함하고, '주문'의 조인된 필드가 일치하는 레코드만 포함.`  
   *(확인을 누르면 연결선이 고객에서 주문 쪽으로 화살표 형태 $\rightarrow$로 변경됩니다).*  
   *Chọn tùy chọn số 2 (Left Join): Lấy toàn bộ khách hàng và các đơn hàng khớp, mũi tên trỏ từ khách hàng sang đơn hàng.*
4. **결과로 표시할 `<고객>` 테이블의 필드(`고객ID`, `고객명`, `전화번호`)를 그리드에 추가합니다.**  
   *Kéo thả các trường cần hiển thị của bảng chính vào lưới.*
5. **비교 대상인 `<주문>` 테이블의 `고객ID` 필드를 그리드에 추가한 뒤:**  
   - **`조건 (Criteria)` 행에 `Is Null`을 입력합니다.**  
     *Điền `Is Null` vào dòng điều kiện để chỉ lấy khách chưa từng có mã ở bảng đặt hàng.*
   - **`표시 (Show)` 체크박스를 해제하여 해당 열을 숨깁니다.**  
     *Bỏ tích ô `표시` để ẩn cột kiểm tra Is Null này khỏi kết quả hiển thị.*

```sql
-- 불일치 검색 쿼리의 표준 ANSI SQL 문장 구조
SELECT 고객.고객ID, 고객.고객명, 고객.전화번호
FROM 고객 LEFT JOIN 주문 ON 고객.고객ID = 주문.고객ID
WHERE 주문.고객ID IS NULL;
```
