## 1. 피벗 테이블 보고서 (Pivot Table — 10점 절대 사수)

피벗 테이블(PivotTable)은 방대한 양의 원본 데이터베이스로부터 다차원 요약 보고서를 신속하게 생성하고 분석하는 핵심 분석 도구이다.  
*(Pivot Table là công cụ phân tích tổng hợp dữ liệu đa chiều tốc độ cao từ các nguồn cơ sở dữ liệu lớn sang dạng báo cáo tóm tắt chuyên nghiệp).*

```
                     피벗 테이블 작성 6단계 표준 프로세스
                                      │
   [1. 외부 데이터 연결] ──> [2. 시작 셀 지정] ──> [3. 4대 영역 필드 배치]
    Access(.accdb)/Text        지시된 셀 (예: [B2])      필터, 행, 열, 값
                                                            │
                               ┌────────────────────────────┘
                               ▼
   [4. 보고서 레이아웃] ───> [5. 그룹화 및 계산필드] ──> [6. 값 필드 표시형식]
    테이블/개요/레이블반복      날짜/숫자 그룹, 수식 추가      (★셀서식 금지, 값필드설정)
```

### 1.1 지시문 분석 및 외부 데이터 연결 (Phân tích chỉ thị & Nhập dữ liệu nguồn ngoài)

#### [실제 시험 지시문 예시 — Đề bài thực tế chuẩn KCCI]
> **▶ 외부 데이터 원본 가져오기 기능을 이용하여 `C:\DB\사원관리.accdb`의 [급여내역] 테이블에서 '부서명', '직급', '입사일자', '기본급', '수당' 열을 이용하여 피벗 테이블 보고서를 작성하시오.**  
> - 피벗 테이블 보고서의 레이아웃과 위치는 <그림>을 참조하여 지정하고, 보고서의 시작 위치는 [B2] 셀로 지정하시오.  
> - 보고서 레이아웃을 '테이블 형식으로 표시'로 지정하고, 모든 항목 레이블이 반복되도록 설정하시오.  
> - '입사일자' 필드는 '연'과 '월'을 기준으로 그룹을 설정하시오.  
> - '실지급액' 계산 필드를 추가하고, 수식은 `= 기본급 + 수당`으로 지정하시오.  
> - 기본급과 실지급액 필드의 표시 형식은 '값 필드 설정'의 '셀 서식'에서 범주 '통화'를 적용하시오.

---

#### 1. Access DB (`.accdb`) 데이터 가져오기 마우스 절차
1. 상단 리본 메뉴 **`데이터` (Data)** 탭 $\rightarrow$ **`데이터 가져오기 및 변환`** 그룹 $\rightarrow$ **`데이터 가져오기` (Get Data)** 클릭.
2. **`파일에서(F)`** $\rightarrow$ **`Microsoft Access 데이터베이스에서(A)`** 선택.
3. [데이터 원본 선택] 창에서 시험 문제에 명시된 경로(예: `C:\DB\사원관리.accdb`)로 이동하여 파일을 선택하고 **`[가져오기]`** 클릭.
4. **[탐색기] 대화상자:**
   - 좌측 트리에서 지정된 테이블(예: `급여내역`)을 선택한다.
   - 우측 하단 `로드` 버튼 우측의 **작은 역삼각형 화살표**를 클릭 $\rightarrow$ **`[다음으로 로드...(L)]`**를 반드시 선택한다.
5. **[데이터 가져오기] 대화상자 설정:**
   - *이 데이터를 표시할 방법을 선택하십시오:* **`[v] 피벗 테이블 보고서(P)`** 라디오 버튼 선택.
   - *데이터를 넣을 위치를 선택하십시오:* **`[v] 기존 워크시트(E)`** 선택 후, 지시된 시작 셀인 **`=$B$2`**를 정확히 클릭.
   - `[확인]` 클릭.

```
+-----------------------------------------------------------+
| 데이터 가져오기                                        [X] |
+-----------------------------------------------------------+
| 이 데이터를 표시할 방법을 선택하십시오:                   |
|   ( ) 표(T)                                               |
|   (o) 피벗 테이블 보고서(P)   <-- [필수 선택!]            |
|   ( ) 피벗 차트(C)                                        |
|                                                           |
| 데이터를 넣을 위치를 선택하십시오:                        |
|   ( ) 새 워크시트(N)                                      |
|   (o) 기존 워크시트(E)        <-- [필수 선택!]            |
|       [ =Sheet1!$B$2                               ] [  ] |
|                                                           |
|                     [  확인  ]          [  취소  ]        |
+-----------------------------------------------------------+
```

#### 2. 텍스트 / CSV 파일 (`.txt`, `.csv`) 데이터 가져오기
- 메뉴 경로: `데이터` 탭 $\rightarrow$ `텍스트/CSV에서` 클릭 $\rightarrow$ 파일 선택.
- 구분 기호(쉼표, 탭 등)를 확인한 후 동일하게 **`[다음으로 로드...]` $\rightarrow$ `피벗 테이블 보고서` $\rightarrow$ `기존 워크시트`**로 연결한다.

### 1.2 4대 영역 필드 배치 및 보고서 레이아웃 (Kéo thả trường & Bố cục bảng)

우측의 [피벗 테이블 필드] 작업 창에서 문제의 완성 예시 <그림>을 판독하여 4개 영역으로 필드를 드래그한다.  
*(Căn cứ vào hình ảnh minh họa mẫu trong đề thi để kéo thả các trường vào đúng 4 phân vùng chức năng).*

```
                          피벗 테이블 필드 4대 영역 구조
                                        │
     ┌──────────────────┬───────────────┴───┬──────────────────┬──────────────────┐
     ▼                  ▼                   ▼                  ▼                  ▼
  [필터 (Filters)]    [열 (Columns)]       [행 (Rows)]        [값 (Values)]       [∑ 값의 위치]
보고서 최상단 배치    표의 가로 머리글     표의 세로 머리글   합계/평균 계산대상  값 필드가 2개 이상일 때
(예: 전사 필터링)    (예: 직급)          (예: 부서명)       (기본급, 실지급액)  행/열 이동 조정
```

#### 보고서 레이아웃 변경 및 레이블 반복 설정
1. 피벗 테이블 내부 임의의 셀을 클릭하여 상단에 **`피벗 테이블 디자인`** 탭을 활성화한다.
2. 좌측 **`보고서 레이아웃` (Report Layout)** 드롭다운 클릭:
   - **`테이블 형식으로 표시(T)` (Show in Tabular Form):** 각 필드가 별도의 독립된 열로 표시되며 격자선이 명확한 1급 표준 형태.
   - **`개요 형식으로 표시(O)` (Show in Outline Form):** 계층 구조 형태로 표시.
   - **`압축 형식으로 표시(C)` (Show in Compact Form):** 여러 행 필드가 동일 열에 압축 표시되는 기본 형태.
3. **모든 항목 레이블 반복 (Repeat All Item Labels):**  
   상위 분류 행이 여러 행에 걸쳐 있을 때 빈칸으로 두지 않고 모든 행마다 부서명을 반복 표기하려면:  
   `보고서 레이아웃` $\rightarrow$ **`모든 항목 레이블 반복(R)`**을 반드시 클릭한다.

### 1.3 그룹화 및 계산 필드 (Nhóm dữ liệu & Trường tính toán)

#### 1. 날짜 및 숫자 그룹화 (Grouping)
- **날짜 필드 그룹화:**
  1. 피벗 테이블의 행 레이블에 위치한 임의의 날짜 셀을 마우스 우클릭 $\rightarrow$ **`그룹(G)...`** 선택.
  2. [그룹화] 대화상자의 `단위(B)` 목록에서 지시된 단위인 **`연`**과 **`월`**을 파란색으로 동시 다중 선택하고, 나머지 단위는 클릭하여 해제한다.
  3. `[확인]` 클릭.
- **숫자 구간 그룹화:**
  1. 숫자 데이터 셀 마우스 우클릭 $\rightarrow$ **`그룹(G)...`** 선택.
  2. **`시작(S)`**, **`끝(E)`**, **`단위(B)`**(간격)를 지시문 수치대로 정확히 타이핑 입력한다.

---

#### 2. 계산 필드(Calculated Field) 삽입
피벗 테이블 원본 데이터에 존재하지 않는 새로운 연산 열을 추가할 때 사용한다.  
*(Sử dụng khi cần tạo thêm một cột tính toán mới dựa trên công thức giữa các trường có sẵn).*

1. 피벗 테이블 내부 셀 클릭 $\rightarrow$ 상단 **`피벗 테이블 분석`** 탭 선택.
2. **`계산`** 그룹 $\rightarrow$ **`필드, 항목 및 집합`** 아이콘 클릭 $\rightarrow$ **`계산 필드(F)...`** 선택.
3. [계산 필드 삽입] 대화상자 설정:
   - **이름(N):** `실지급액` 입력.
   - **수식(F):** 기존 `= 0`에서 0을 지우고, 필드 목록에서 `기본급` 더블클릭 $\rightarrow$ `+` 입력 $\rightarrow$ `수당` 더블클릭하여 `= 기본급 + 수당` 완성.
4. **`[추가(A)]`** 버튼 클릭 후 **`[확인]`**을 누른다.

> [!CAUTION]
> **계산 필드 vs 계산 항목 구분:**  
> - **계산 필드 (Calculated Field):** 새로운 '열(Field)'을 생성하는 것으로 그룹화 상태에서도 정상 작동한다.  
> - **계산 항목 (Calculated Item):** 행이나 열 내부의 특정 '요소(Item)'를 연산하는 것으로, 해당 필드가 그룹화되어 있으면 비활성화된다. 지시문의 용어를 절대 혼동하지 말 것.

### 1.4 값 표시 형식 (Show Values As)

단순 합계/평균 금액 대신 특정 기준 대비 비율이나 순위를 백분율로 환산하여 표시하는 기능이다.  
*(Tính năng chuyển đổi số tiền thuần túy thành tỷ lệ phần trăm % hoặc thứ tự xếp hạng so với tổng).*

- **실행 경로:** 값 영역의 셀 마우스 우클릭 $\rightarrow$ **`값 표시 형식(A)`** $\rightarrow$ 세부 옵션 선택:
  - **`열 합계 비율(%)(C)`:** 해당 열의 총합계를 100%로 잡고 각 항목이 차지하는 비중 계산.
  - **`행 합계 비율(%)(R)`:** 해당 행의 총합계를 100%로 환산.
  - **`기준값과의 차이(D)...`:** 특정 기준월이나 기준 직급 대비 증감 수치 표시.
  - **`순위(K)...`:** 값의 크기 순으로 순위 매김.

### 1.5 ★ KCCI 1급 절대 탈락 0점 함정: 값 필드 서식 지정 (Bẫy định dạng số qua Value Field Settings)

피벗 테이블의 숫자 서식(천 단위 구분 기호, 통화 기호, 소수점)을 지정할 때, 일반 셀 서식(`Ctrl + 1`)을 사용하면 **무조건 0점 처리**된다.  
*(Khi định dạng số trong Pivot Table, nếu dùng phím tắt `Ctrl + 1` để định dạng như ô bình thường thì bài thi sẽ bị KCCI chấm 0 điểm tuyệt đối).*

```
              피벗 테이블 숫자 서식 적용 방식의 극단적 대조
                                    │
   ┌────────────────────────────────┴────────────────────────────────┐
   ▼                                                                 ▼
[절대 금지: 일반 셀 서식 (0점)]                  [유일한 정답: 값 필드 설정 (10점)]
• 조작: 마우스로 값 셀들을 드래그 -> Ctrl + 1    • 조작: 값 영역 임의의 1개 셀 우클릭
• 결함: 피벗 테이블 새로 고침(Refresh) 또는      • 원리: 피벗 캐시의 필드 메타데이터 자체에
        필드 필터 변경 시 서식이 즉시 날아감.            영구 서식을 박아 넣으므로 동적 유지됨.
• KCCI 채점기: 필드 서식 속성 검사 시 실패 판정! • KCCI 채점기: 완벽 통과 (10점 획득)
```

#### 올바른 표준 실행 절차 (Quy trình chuẩn duy nhất để lấy trọn 10 điểm):
1. 서식을 변경하고자 하는 값 데이터 영역의 **임의의 단일 셀**을 마우스 우클릭한다. (절대로 범위를 드래그할 필요 없음).
2. 팝업 바로 가기 메뉴에서 **`[값 필드 설정(N)...]`**을 클릭한다.
3. [값 필드 설정] 대화상자의 좌측 하단에 있는 **`[표시 형식(F)]`** 버튼을 클릭한다.
4. 익숙한 [셀 서식] 대화상자가 나타나면 지시된 범주(예: **`통화`**, **`숫자` - 1000 단위 구분 기호 사용**)를 설정하고 `[확인]` $\rightarrow$ `[확인]`을 차례로 누른다.

## 2. 기타 데이터 분석 도구 (Công cụ phân tích dữ liệu khác — 10점)

컴활 1급 실기 제2분석작업은 5가지 분석 도구 중 1문제가 무작위 출제되며, 부분점수 없이 10점이 일괄 부여된다.  
*(Phần công cụ phân tích khác chọn ngẫu nhiên 1 trong 5 tính năng kinh điển, chấm điểm trọn vẹn 10 điểm hoặc 0 điểm).*

---

### 2.1 목표값 찾기 (Goal Seek)

수식의 결과값은 알고 있으나, 그 결과를 얻기 위해 입력값을 얼마로 변경해야 하는지 역산하는 도구이다.  
*(Tìm mục tiêu là công cụ tính ngược lại giá trị đầu vào cần thiết để đạt được một kết quả đầu ra mong muốn).*

- **실행 경로:** `데이터` 탭 $\rightarrow$ `예측` 그룹 $\rightarrow$ **`가상 분석` (What-If Analysis)** $\rightarrow$ **`목표값 찾기(G)...`**
- **대화상자 3대 인수 설정:**
  - **수식 셀(E):** 결과 수식이 들어 있는 셀 (예: 평균 점수 셀 `$G$10`).
  - **찾는 값(V):** 달성하고자 하는 목표 수치를 직접 키보드로 입력 (예: `90`).
  - **값을 바꿀 셀(C):** 목표를 위해 수정되어야 할 변수 셀 (예: 특정 과목 점수 셀 `$E$4`).

---

### 2.2 데이터 표 (Data Table)

특정 수식에 사용된 변수가 1개 또는 2개 변화함에 따라 결과값이 어떻게 달라지는지 행과 열의 격자 매트릭스로 일괄 시뮬레이션하는 기능이다.  
*(Bảng dữ liệu mô phỏng đồng thời hàng loạt kịch bản thay đổi của 1 biến hoặc 2 biến lên công thức gốc).*

```
           데이터 표 2변수 교차 격자 배치 구조
                           │
                 열 입력 셀 변수 (예: 이자율)
                 ┌──────┬──────┬──────┐
                 │ 4.0% │ 5.0% │ 6.0% │
  ┌──────────────┼──────┼──────┼──────┤
행│ 12개월 (1년) │결과1 │결과2 │결과3 │
입│ 24개월 (2년) │결과4 │결과5 │결과6 │
력│ 36개월 (3년) │결과7 │결과8 │결과9 │
셀└──────────────┴──────┴──────┴──────┘
  ▲
  └─ [교차 모서리 셀]: 원본 계산 수식을 연결 (=B10)
```

#### 실행 절차 (2변수 기준):
1. **모서리 수식 연결:** 행과 열 머리글이 교차하는 좌측 상단 모서리 빈 셀에 등호(`=`)를 입력하고 원본 결과 셀(예: `=B10`)을 참조하여 연결한다.
2. **테이블 전체 블록 설정:** 모서리 수식 셀과 행/열 머리글, 결과가 채워질 빈 영역 전체를 드래그하여 선택한다.
3. **도구 실행:** `데이터` 탭 $\rightarrow$ `가상 분석` $\rightarrow$ **`데이터 표(T)...`** 클릭.
4. **인수 지정:**
   - **행 입력 셀(R):** 가로 방향 머리글에 해당하는 원본 입력 셀 지정 (예: 기간 셀 `$B$3`).
   - **열 입력 셀(C):** 세로 방향 머리글에 해당하는 원본 입력 셀 지정 (예: 이율 셀 `$B$2`).
5. `[확인]` 클릭.

### 2.3 시나리오 관리자 (Scenario Manager)

다양한 가상의 상황(매출 증가, 원가 상승 등)을 미리 정의하고, 그에 따른 총수익의 변동 결과를 요약 보고서 시트로 생성하는 기능이다.  
*(Quản lý kịch bản lập các giả định dự báo kinh doanh và kết xuất bảng báo cáo tóm tắt trên một Sheet mới).*

#### 필수 4단계 절차:
1. **사전 이름 정의 (Đặt tên ô trước):**  
   문제에서 특정 셀의 이름을 정의하라고 지시한 경우(예: B3 셀을 `이자율`, G10 셀을 `순이익`), 해당 셀을 클릭하고 좌측 상단 [이름 상자]에 이름을 입력 후 반드시 `Enter`를 친다.  
   *(Nếu quên đặt tên ô, bảng tóm tắt kịch bản sẽ hiển thị địa chỉ ô thô `$B$3` và bị trừ sạch điểm).*
2. **시나리오 관리자 진입:**  
   `데이터` 탭 $\rightarrow$ `가상 분석` $\rightarrow$ **`시나리오 관리자(S)...`** 클릭 $\rightarrow$ **`[추가(A)]`** 클릭.
3. **시나리오 1 & 2 등록:**
   - **시나리오 이름:** 지시된 명칭 입력 (예: `인상`, `인하`).
   - **변경 셀:** 값이 바뀔 셀 지정 (예: `$B$3`).
   - `[확인]` 클릭 후 변경할 새 값을 입력한다.
4. **시나리오 요약 시트 생성:**
   - [시나리오 관리자] 대화상자에서 **`[요약(S)...]`** 버튼 클릭.
   - 보고서 종류: **`시나리오 요약(S)`** 선택.
   - **결과 셀(R):** 최종 결과가 반영될 셀 지정 (예: `$G$10`).
   - `[확인]`을 누르면 현재 시트 바로 왼쪽에 `시나리오 요약` 시트가 자동 생성된다.

### 2.4 데이터 통합 (Consolidate)

서로 다른 여러 워크시트나 표에 분산되어 있는 데이터들을 일정한 기준(첫 행, 왼쪽 열)에 맞추어 합계, 평균, 개수 등으로 하나의 종합 표로 합산 취합하는 기능이다.  
*(Hợp nhất dữ liệu là tính năng gom và tổng hợp dữ liệu từ nhiều bảng hoặc nhiều Sheet khác nhau vào một bảng duy nhất theo nhãn dòng và nhãn cột).*

#### 실행 절차:
1. 결과가 표시될 대상 표의 데이터 영역(머리글 포함)을 마우스로 블록 설정한다.
2. 상단 `데이터` 탭 $\rightarrow$ `데이터 도구` 그룹 $\rightarrow$ **`통합(E)`** 아이콘 클릭.
3. [통합] 대화상자 설정:
   - **함수(F):** 지시된 함수 선택 (`합계`, `평균`, `최댓값` 등).
   - **참조(R):** 첫 번째 참조 영역을 드래그하여 지정 $\rightarrow$ **`[추가(A)]`** 버튼 클릭. (모든 참조 영역을 동일한 방식으로 차례차례 추가한다).
   - **사용할 레이블:** **`[v] 첫 행(T)`**과 **`[v] 왼쪽 열(L)`** 체크박스를 **모두 반드시 체크**한다.
4. `[확인]` 클릭.

---

### 2.5 부분합 (Subtotal)

특정 분류 필드를 기준으로 데이터를 그룹화한 후 그룹별 소계(합계, 평균, 건수)와 전체 총합계를 자동으로 산출하는 기능이다.  
*(Tính tổng phụ tự động phân nhóm và chèn các dòng cộng tổng phụ theo từng phân loại).*

```
           부분합의 2단계 핵심 절차 (정렬 선행 필수!)
                               │
   [1단계: 기준 필드 정렬] ─────> 데이터 탭 -> 정렬 (오름차순/내림차순) [★미실행 시 0점]
                               │
   [2단계: 부분합 도구 실행] ───> 그룹화할 항목 선택 -> 계산 항목 및 함수 지정
```

> [!IMPORTANT]
> **정렬(Sort) 선행의 철칙 (Nguyên tắc bắt buộc sắp xếp trước):**  
> 부분합을 실행하기 전, 반드시 그룹의 기준이 되는 열을 먼저 정렬해야 한다. 정렬하지 않고 부분합을 실행하면 동일한 부서명이 흩어져 부서별 소계가 산발적으로 중복 생성되어 **100% 0점 처리**된다.

#### 중첩 부분합(2개 이상의 부분합 적용) 시 필수 주의사항:
문제에서 *"부서별 기본급의 합계를 구한 후, 실적수의 최댓값을 계산하시오"*처럼 2개의 부분합을 요구하는 경우:
1. **첫 번째 부분합:** 기본급의 합계를 구한다.
2. **두 번째 부분합 실행 시:** 함수를 `최댓값`으로 변경하고 계산 항목을 `실적수`로 바꾼 뒤, **반드시 `[ ] 새로운 값으로 대치(R)` 체크박스를 해제**해야 한다!  
   *(Nếu không bỏ chọn ô này, phần tính tổng đầu tiên sẽ bị xóa đè mất, chỉ còn lại giá trị lớn nhất và bị KCCI chấm 0 điểm).*

## 3. 분석작업 0점 방지 최종 점검 체크리스트 (Bảng kiểm tra chống mất 10 điểm nhị phân)

- [ ] **피벗 테이블 시작 위치 (Vị trí bắt đầu Pivot Table):** 보고서의 시작 위치 셀(예: `B2`)이 지시문 및 문제 그림과 한 칸의 오차도 없이 정확한가?  
  *Tiếng Việt giải thích:* Nếu đặt sai ô bắt đầu (ví dụ đề bảo B2 mà đặt vào A3), bài thi mất trọn 10 điểm.
- [ ] **피벗 테이블 보고서 레이아웃 (Bố cục báo cáo & Lặp nhãn):** `테이블 형식` 또는 `개요 형식`으로 변경하고 `모든 항목 레이블 반복`을 설정했는가?  
  *Tiếng Việt giải thích:* Luôn kiểm tra Design -> Report Layout -> Show in Tabular Form và Repeat All Item Labels theo đúng hình mẫu.
- [ ] **값 필드 서식 적용 (Định dạng số qua Value Field Settings):** 숫자 서식을 지정할 때 일반 셀 서식(`Ctrl + 1`)이 아닌 우클릭 $\rightarrow$ `값 필드 설정` $\rightarrow$ `표시 형식` 버튼을 통해 적용했는가?  
  *Tiếng Việt giải thích:* Tuyệt đối không dùng bôi đen rồi bấm Ctrl+1. Phải bấm chuột phải vào 1 ô số -> Value Field Settings -> Number Format để giữ định dạng vĩnh viễn trong Pivot Cache.
- [ ] **시나리오 이름 정의 (Đặt tên ô trước khi làm Scenario):** 시나리오 생성 전 지시문에 명시된 모든 셀의 이름 정의를 오탈자 없이 완료했는가?  
  *Tiếng Việt giải thích:* Quên đặt tên ô trong hộp Name Box trước khi tạo kịch bản sẽ làm bảng tóm tắt hiện địa chỉ ô thô ($B$3) và bị trừ toàn bộ 10 điểm.
- [ ] **부분합 사전 정렬 (Sắp xếp trước khi làm Subtotal):** 부분합 실행 전 그룹화할 기준 열의 오름차순/내림차순 정렬을 선행했는가?  
  *Tiếng Việt giải thích:* Bắt buộc phải sắp xếp (Sort) cột phân nhóm trước. Nếu không sắp xếp, Subtotal sẽ chèn dòng cộng lẻ tẻ khắp nơi và bị 0 điểm.
- [ ] **중첩 부분합 대치 해제 (Bỏ chọn ghi đè ở Subtotal thứ 2):** 두 번째 부분합 적용 시 `새로운 값으로 대치` 옵션을 해제하여 첫 번째 부분합 결과를 보존했는가?  
  *Tiếng Việt giải thích:* Khi chạy Subtotal lần thứ hai (ví dụ vừa tính Tổng vừa tính Max), phải bỏ dấu tích ở ô "Replace current subtotals" để không xóa mất kết quả lần 1.
