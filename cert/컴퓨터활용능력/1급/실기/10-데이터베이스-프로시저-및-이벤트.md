## 1. 매크로 자동화 (Access Macro — 매크로 작성)

매크로(Macro)는 복잡한 프로그래밍 코드 작성 없이 Access에 내장된 동작(Action)들을 선택하고 매개변수를 지정하여 특정 작업을 순차적으로 자동 실행하는 개체입니다.

```
┌────────────────────────────────────────────────────────┐
│ 시험에 출제되는 2가지 매크로 작성 방식 비교            │
├────────────────────────────┬───────────────────────────┤
│ 1. 독립 매크로 (매크로 개체)│ 2. 포함된 매크로 (Embedded) │
├────────────────────────────┼───────────────────────────┤
│ • [만들기] $\rightarrow$ [매크로] 메뉴에서│ • 컨트롤의 [속성 시트]     │
│   직접 작성하여 저장       │   $\rightarrow$ [이벤트]에서 작성  │
│ • 탐색 창에 'mcr_조회' 등  │ • 폼/보고서 내부의 특정   │
│   별도 개체로 저장됨       │   이벤트에만 종속되어 내장 │
│ • 여러 컨트롤에서 재사용 가능│ • 탐색 창에 표시되지 않음 │
└────────────────────────────┴───────────────────────────┘
```

> [!IMPORTANT]
> **실전 문제 판별 기준 (Quy tắc phân biệt sống còn):**  
> - 문제에 *"매크로 이름은 `mcr_출력`으로 지정하시오"*와 같이 **명시적인 매크로 이름이 주어지면 $\longrightarrow$ 반드시 [만들기] 탭의 독립 매크로**로 작성하여 저장해야 합니다.  
> - *"단추를 클릭하면 매크로를 실행하여..."*처럼 **매크로 이름이 따로 없으면 $\longrightarrow$ 컨트롤의 속성 시트 [이벤트] 탭에서 [...] 작성기를 눌러 [매크로 작성기]를 선택하는 '포함된 매크로(Embedded Macro)'**로 작성해야 합니다.

### 1.1 주요 매크로 함수(Action) 설정 대조표

| 매크로 함수 (Action) | 주요 인수 설정 (Tham số cấu hình chính) | 기능 및 실전 활용 (Ý nghĩa & Sử dụng) |
|---|---|---|
| **`OpenForm`** | • `폼 이름` (Form Name): 열고자 하는 폼 선택.<br>• `보기 형식` (View): `폼 (Form)`.<br>• `Where 조건문`: 레코드 필터링 조건식 입력. | 특정 폼을 지정된 조건에 맞는 레코드만 필터링하여 화면에 표시.<br>*Mở một Form cụ thể và lọc các bản ghi theo biểu thức điều kiện.* |
| **`OpenReport`** | • `보고서 이름` (Report Name): 출력할 보고서 선택.<br>• `보기 형식`: 반드시 **`인쇄 미리 보기 (Print Preview)`** 선택.<br>• `Where 조건문`: 보고서 출력 조건식 입력. | 보고서를 인쇄 미리 보기 창으로 열기.<br>*Mở báo cáo ở chế độ Xem trước khi in (Print Preview).* |
| **`Requery`** | • `컨트롤 이름`: 생략 시 폼 전체 다시 쿼리, 입력 시 해당 컨트롤만 다시 쿼리. | 원본 데이터를 다시 읽어와 화면의 최신 상태로 새로고침.<br>*Nạp lại dữ liệu nguồn để làm mới màn hình Form/điều khiển.* |
| **`ApplyFilter`** | • `Where 조건문`: 필터링할 조건식 입력. | 현재 열려 있는 폼이나 보고서에 필터를 즉시 적용.<br>*Áp dụng bộ lọc điều kiện ngay lập tức lên Form/báo cáo đang mở.* |
| **`CloseWindow`** | • `개체 유형`: `폼` 또는 `보고서`.<br>• `개체 이름`: 닫을 대상 창 이름.<br>• `저장`: `확인` 또는 `예`. | 지정된 폼이나 보고서 창을 화면에서 닫음.<br>*Đóng cửa sổ Form hoặc Báo cáo chỉ định.* |
| **`MsgBox`** | • `메시지`: 팝업 대화 상자에 표시할 내용.<br>• `경고음`: `예` / `아니요`.<br>• `종류`: `정보`, `경고`, `위험`.<br>• `제목`: 대화 상자 타이틀바 문구. | 화면에 팝업 메시지 대화 상자를 띄움.<br>*Bật hộp thoại thông báo dạng popup trên màn hình.* |

### 1.2 매크로 Where 조건문 컨트롤 참조 문법

매크로의 `Where 조건문` 인수에서는 테이블의 필드와 현재 열려 있는 폼 컨트롤의 값을 비교할 때 **전체 개체 경로(Forms!폼이름!컨트롤명)** 형식을 사용해야 합니다:

$$\mathbf{[필드명] = [Forms]![폼이름]![컨트롤명]}$$

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <사원관리> 폼의 '조회' 단추(cmd조회)를 클릭하면 다음과 같은 기능의 매크로를 작성하여 연결하시오.
   - <사원정보> 보고서를 '인쇄 미리 보기' 형식으로 열 것.
   - 폼의 'cmb부서코드'에서 선택한 부서와 동일한 레코드만 표시할 것.
   - 매크로 이름은 'mcr_인쇄'로 저장하시오.
```

- **설정 내용:**
  - 작업 생성: [만들기] $\rightarrow$ [매크로]
  - 매크로 함수: `OpenReport`
  - 보고서 이름: `사원정보`
  - 보기 형식: `인쇄 미리 보기`
  - Where 조건문: `[부서코드] = [Forms]![사원관리]![cmb부서코드]`
  - 저장: `mcr_인쇄`로 저장 후, `cmd조회` 단추의 `On Click` 속성에 `mcr_인쇄`를 지정.

## 2. 폼 필터링: Me.Filter & Me.FilterOn (5점)

VBA 이벤트 프로시저(Event Procedure)에서 폼의 데이터를 동적으로 검색 및 필터링할 때 가장 많이 사용되는 핵심 속성입니다.

```
┌────────────────────────────────────────────────────────┐
│ Me.Filter 2단계 표준 실행 메커니즘                     │
├────────────────────────────────────────────────────────┤
│ 1단계: 필터 조건식 문자열 설정                          │
│        Me.Filter = "필드명 = '조건값'"                 │
│                                                        │
│ 2단계: 필터 적용 스위치 ON                             │
│        Me.FilterOn = True                              │
└────────────────────────────────────────────────────────┘
```

---

### 2.1 4대 데이터 형식별 VBA 문자열 결합 공식

`Me.Filter`에 대입하는 조건식은 하나의 완성된 텍스트 문자열이어야 합니다. 따라서 폼 컨트롤의 값(`txt...`)을 큰따옴표 밖으로 빼내어 `&` 연산자로 연결하되, 데이터 형식에 맞는 서식 기호로 묶어야 합니다.

| 데이터 형식 (Data Type) | 묶는 기호 (Ký tự bao bọc) | VBA 조건식 표준 공식 (Cú pháp VBA chuẩn mực) | 실전 예시 및 Tiếng Việt giải thích |
|---|:---:|---|---|
| **문자열 (Short Text)** | **작은따옴표 `'...'`** | `Me.Filter = "필드명 = '" & txt컨트롤 & "'"` | `Me.Filter = "고객명 = '" & txt조회 & "'"`<br>*Lọc chuỗi văn bản: bắt buộc bọc trong dấu nháy đơn `'`.* |
| **숫자 (Number)** | **기호 없음** | `Me.Filter = "필드명 = " & txt컨트롤` | `Me.Filter = "나이 >= " & txt나이`<br>*Lọc dữ liệu số: không dùng bất kỳ ký hiệu bao bọc nào.* |
| **날짜 (Date/Time)** | **샵 기호 `#...#`** | `Me.Filter = "필드명 = #" & txt컨트롤 & "#"` | `Me.Filter = "입사일 >= #" & txt시작일 & "#"`<br>*Lọc ngày tháng: bắt buộc bao bọc trong cặp dấu thăng `#`.* |
| **부분 일치 (Like)** | **작은따옴표 + 별표 `'*...*'`** | `Me.Filter = "필드명 Like '*" & txt컨트롤 & "*'"` | `Me.Filter = "제품명 Like '*" & txt검색 & "*'"`<br>*Tìm kiếm gần đúng: kết hợp nháy đơn và dấu sao `'*...*'`.* |

---

### 2.2 검색 및 필터 해제 표준 VBA 코드

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <사원관리> 폼의 '조회' 단추(cmd조회)를 클릭하면 'txt이름'에 입력된 문자가
   사원명의 일부와 일치하는 레코드만을 표시하도록 이벤트 프로시저를 작성하시오.
▶ '전체보기' 단추(cmd전체)를 클릭하면 필터가 해제되어 모든 레코드가 나타나도록 하시오.
```

```vba
' 1. [조회] 단추 클릭 시: Like 연산자를 이용한 부분 일치 필터링
Private Sub cmd조회_Click()
    ' 조건식을 설정하고 필터를 활성화함
    Me.Filter = "사원명 Like '*" & txt이름.Value & "*'"
    Me.FilterOn = True
End Sub

' 2. [전체보기] 단추 클릭 시: 필터 해제
Private Sub cmd전체_Click()
    ' 필터 속성을 꺼서 전체 레코드를 원상 복구함
    Me.FilterOn = False
    
    ' 검색 텍스트 상자를 초기화하고 포커스를 이동함 (선택사항)
    txt이름 = ""
    txt이름.SetFocus
End Sub
```

## 3. 레코드 위치 이동: RecordsetClone & Bookmark (5점)

`Me.Filter`가 조건에 맞지 않는 레코드를 화면에서 숨기는 방식이라면, `RecordsetClone`과 `Bookmark`는 **전체 레코드를 그대로 유지한 상태에서 원하는 특정 레코드로 현재 커서(포커스)의 위치만 즉시 이동**시키는 고급 탐색 기법입니다.

```
┌────────────────────────────────────────────────────────┐
│ 레코드셋 복제 및 북마크 동기화 흐름                    │
├────────────────────────────────────────────────────────┤
│ [폼의 가상 복제본: Me.RecordsetClone]                  │
│   1. FindFirst: 조건에 맞는 레코드를 복제본에서 탐색    │
│         │                                              │
│         ▼                                              │
│   2. Bookmark: 일치하는 행의 북마크(고유 주소값) 획득   │
│         │                                              │
│         ▼                                              │
│ [현재 화면 폼: Me]                                     │
│   3. Me.Bookmark = Me.RecordsetClone.Bookmark          │
│      ==> 화면의 폼이 해당 레코드로 즉시 이동!          │
└────────────────────────────────────────────────────────┘
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <고객관리> 폼의 '찾기' 단추(cmd찾기)를 클릭하면 다음과 같은 기능이 수행되도록 구현하시오.
   - 'txt고객ID'에 입력된 값과 일치하는 고객의 레코드를 찾아 해당 위치로 이동할 것.
   - RecordsetClone과 Bookmark 속성을 사용할 것.
```

#### 표준 2줄 공식 코드:
```vba
Private Sub cmd찾기_Click()
    ' 1단계: 폼의 복제 레코드셋에서 조건에 일치하는 첫 번째 행 탐색
    Me.RecordsetClone.FindFirst "고객ID = '" & txt고객ID.Value & "'"
    
    ' 2단계: 복제 레코드셋의 북마크를 현재 폼의 북마크에 대입하여 화면 이동 동기화
    Me.Bookmark = Me.RecordsetClone.Bookmark
End Sub
```

#### 심화: 일치하는 데이터가 없을 때 NoMatch 예외 처리:
```vba
Private Sub cmd찾기_Click()
    Me.RecordsetClone.FindFirst "고객ID = '" & txt고객ID.Value & "'"
    
    ' 검색 실패 여부 확인 (NoMatch가 True이면 일치하는 레코드 없음)
    If Me.RecordsetClone.NoMatch = True Then
        MsgBox "일치하는 고객 정보가 없습니다.", vbInformation, "검색 실패"
    Else
        Me.Bookmark = Me.RecordsetClone.Bookmark
    End If
End Sub
```

## 4. DoCmd 객체를 이용한 조건부 개체 열기

## 4. DoCmd 객체를 이용한 조건부 개체 열기 (Mở đối tượng có điều kiện qua DoCmd)

Access의 `DoCmd` 개체는 폼 열기, 보고서 인쇄 미리 보기 등의 명령을 VBA 코드로 실행할 때 사용됩니다.  
*(Đối tượng DoCmd trong VBA dùng để thực thi các lệnh hệ thống như mở Form, mở báo cáo Print Preview kèm điều kiện lọc).*

### 4.1 DoCmd.OpenReport (보고서 열기 — Mở báo cáo)
$$\mathbf{DoCmd.OpenReport \; "보고서명", \; acViewPreview, \; , \; "Where조건식"}$$

- **인수 분석 (Phân tích các đối số):**
  1. **`ReportName`:** 열고자 하는 보고서의 이름 (큰따옴표로 묶음).  
     *(Tên báo cáo cần mở, bắt buộc đặt trong cặp ngoặc kép).*
  2. **`View`:** 표시 형식. 실기 시험에서는 항상 인쇄 미리 보기 상수인 **`acViewPreview`**를 사용.  
     *(Chế độ xem: đề thi 1급 thực hành luôn bắt buộc dùng hằng số `acViewPreview`).*
  3. **`FilterName`:** 필터 쿼리 이름 (생략하고 쉼표 `,` 연속 입력).  
     *(Tên bộ lọc truy vấn: bỏ trống và gõ tiếp dấu phẩy).*
  4. **`WhereCondition`:** 보고서에 넘겨줄 필터링 조건식 (`Me.Filter` 공식과 동일).  
     *(Biểu thức điều kiện lọc truyền vào báo cáo, tuân thủ đúng quy tắc nháy đơn/thăng của Me.Filter).*

```vba
' 실전 예시: 고객ID가 일치하는 데이터만 보고서 인쇄 미리 보기로 열기
' Mở báo cáo 고객별주문명세 ở chế độ Print Preview chỉ hiển thị khách hàng có mã txt고객ID
Private Sub cmd출력_Click()
    DoCmd.OpenReport "고객별주문명세", acViewPreview, , "고객ID = '" & txt고객ID & "'"
End Sub
```

### 4.2 DoCmd.OpenForm (폼 열기 — Mở Form)
$$\mathbf{DoCmd.OpenForm \; "폼명", \; acNormal, \; , \; "Where조건식"}$$

```vba
' 실전 예시: 선택된 제품코드의 세부 정보를 상세 폼으로 열기
' Mở Form 제품상세 ở chế độ bình thường acNormal chỉ hiển thị sản phẩm có mã txt제품코드 (dạng số)
Private Sub cmd상세보기_Click()
    DoCmd.OpenForm "제품상세", acNormal, , "제품코드 = " & txt제품코드
End Sub
```

## 5. DoCmd.RunSQL 실행 쿼리 & Me.Requery (데이터 변경 및 새로고침)

사용자 버튼 클릭 시 데이터 조작 SQL 문(`UPDATE`, `INSERT`, `DELETE`)을 즉각 수행하고, 변경된 내용을 현재 폼에 다시 반영하는 기법입니다.  
*(Kỹ thuật thực thi trực tiếp câu lệnh SQL thay đổi dữ liệu và làm mới màn hình Form qua Me.Requery).*

```vba
Private Sub cmd단가인상_Click()
    ' 1. Access 기본 시스템 확인 경고 메시지 창 끄기 (Tắt hộp thoại cảnh báo cập nhật bản ghi)
    DoCmd.SetWarnings False
    
    ' 2. 직접 SQL 문을 실행하여 데이터 갱신 (Chạy câu lệnh SQL cập nhật đơn giá tăng 10%)
    DoCmd.RunSQL "UPDATE 도서 SET 단가 = 단가 * 1.1 WHERE 출판사 = '한빛미디어';"
    
    ' 3. 시스템 경고 설정 반드시 원상 복구 (Bắt buộc bật lại cảnh báo hệ thống - quên sẽ bị trừ điểm)
    DoCmd.SetWarnings True
    
    ' 4. 폼의 데이터를 다시 조회하여 화면에 최신 데이터 갱신 반영 (Làm mới dữ liệu trên màn hình)
    Me.Requery
    
    ' 5. 작업 완료 메시지 표시 (Xuất thông báo hoàn tất)
    MsgBox "도서 단가가 정상적으로 인상되었습니다.", vbInformation, "완료"
End Sub
```

> [!CAUTION]
> **시스템 안정성 주의사항 (Cảnh báo an toàn hệ thống):**  
> `DoCmd.SetWarnings False`를 사용한 프로시저에서는 반드시 명령 실행 후 **`DoCmd.SetWarnings True`를 명시하여 시스템 경고 창 기능을 다시 켜야** 합니다. 이를 누락할 경우 후속 작업에서 안전 경고창이 작동하지 않아 치명적인 감점 사유가 될 수 있습니다.  
> *(Nếu đã dùng SetWarnings False thì cuối thủ tục bắt buộc phải có SetWarnings True. Quên bật lại sẽ bị KCCI chấm lỗi an toàn hệ thống và mất điểm toàn câu).*
