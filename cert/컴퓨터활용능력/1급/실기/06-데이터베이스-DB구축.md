## 1. 테이블 완성 (Thiết kế & Hoàn thiện bảng — 20점)

테이블 완성 작업은 주어진 테이블을 **디자인 보기 (Design View)**로 열고, 각 필드의 데이터 형식과 필드 속성을 문제의 지시사항에 따라 정확하게 수정하는 단계입니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ 테이블 디자인 보기 (Table Design View) 인터페이스 구조                  │
├───────────────────┬───────────────────┬────────────────────────────────┤
│ 필드 이름 (Field) │ 데이터 형식 (Type) │ 설명 (Description - 선택사항)  │
├───────────────────┼───────────────────┼────────────────────────────────┤
│ 고객ID [열쇠아이콘]│ 짧은 텍스트       │ 기본키 (Primary Key)           │
│ 고객명            │ 짧은 텍스트       │                                │
│ 전화번호          │ 짧은 텍스트       │ 입력 마스크 적용 필드          │
│ 나이              │ 숫자              │ 정수(Long), 유효성 검사        │
│ 등록일자          │ 날짜/시간         │ 기본값 =Date()                 │
├───────────────────┴───────────────────┴────────────────────────────────┤
│ 필드 속성 (Field Properties) - [일반] / [조회]                         │
│ • 필드 크기 (Field Size)       : 20                                    │
│ • 형식 (Format)               : yyyy-mm-dd (aaa)                      │
│ • 입력 마스크 (Input Mask)    : 000-0000-0000;0;*                     │
│ • 기본값 (Default Value)      : =Date()                               │
│ • 유효성 검사 규칙 (Rule)     : >= 0 And <= 100                       │
│ • 유효성 검사 텍스트 (Text)   : 점수는 0에서 100 사이여야 합니다.     │
│ • 필수 (Required)             : 예                                    │
│ • 인덱스 (Indexed)            : 예 (중복 불가능)                      │
└────────────────────────────────────────────────────────────────────────┘
```

### 1.1 기본키 설정 (Thiết lập khóa chính — Primary Key)

기본키(Primary Key)는 테이블 내의 모든 레코드를 고유하게 식별하는 유일한 필드(또는 필드 조합)이며, 중복 값과 Null(빈 값)을 절대로 허용하지 않습니다.

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <고객> 테이블의 '고객ID' 필드를 기본키(Primary Key)로 설정하시오.
▶ <주문상세> 테이블의 '주문번호'와 '제품코드' 필드를 복합 기본키로 설정하시오.
```

#### 단일 기본키 설정 (Thiết lập đơn khóa chính):
1. **탐색 창에서 해당 테이블을 마우스 오른쪽 단추로 클릭한 후 [디자인 보기]를 선택합니다.**
   *Trong khung điều hướng bên trái (Navigation Pane), nhấp chuột phải vào bảng yêu cầu và chọn [디자인 보기] (Design View).*
2. **기본키로 지정할 필드의 행 선택기(필드 이름 왼쪽의 사각형 영역)를 클릭합니다.**
   *Nhấp chuột vào ô chọn hàng (Row Selector) bên trái tên trường cần đặt làm khóa.*
3. **[테이블 디자인] 탭 $\rightarrow$ [도구] 그룹 $\rightarrow$ [기본 키] 아이콘(노란색 열쇠 모양)을 클릭합니다.**
   *Trên thanh Ribbon, vào tab [테이블 디자인] $\rightarrow$ nhóm [도구] $\rightarrow$ nhấp vào biểu tượng chìa khóa vàng [기본 키].*
4. **필드 이름 좌측에 열쇠 아이콘이 표시되었는지 확인합니다.**
   *Kiểm tra biểu tượng chìa khóa đã xuất hiện ở đầu dòng trường đó.*

#### 복합 기본키 설정 (Thiết lập khóa chính phức hợp / đa trường):
1. **첫 번째 필드의 행 선택기를 클릭합니다.**
   *Nhấp chuột vào ô chọn hàng của trường thứ nhất.*
2. **`Ctrl` 키(또는 연속된 행인 경우 `Shift` 키)를 누른 상태에서 두 번째 필드의 행 선택기를 클릭하여 여러 행을 동시에 선택합니다.**
   *Giữ phím `Ctrl` (hoặc `Shift` nếu các dòng liền kề) và nhấp chọn tiếp ô chọn hàng của trường thứ hai để bôi đen đồng thời các trường.*
3. **[기본 키] 아이콘을 클릭하여 선택된 모든 필드에 열쇠 모양이 동시에 나타나도록 지정합니다.**
   *Nhấp vào nút [기본 키] trên thanh công cụ để biểu tượng chìa khóa vàng xuất hiện đồng thời trên tất cả các trường đã chọn.*
> [!CAUTION]
> **주의사항 (Lưu ý chống mất điểm):** 필드를 하나씩 따로 선택하여 [기본 키]를 누르면 이전 필드의 기본키가 해제되고 마지막 필드만 기본키로 남게 됩니다. 반드시 다중 행을 블록으로 한 번에 선택한 후 기본키를 지정해야 합니다.
> *(Nếu chọn từng trường rồi bấm chìa khóa lần lượt, Access sẽ hủy khóa của trường trước và chỉ giữ lại trường cuối cùng. Bắt buộc phải bôi đen chọn nhiều dòng cùng lúc rồi mới bấm [기본 키]).*

### 1.2 데이터 형식 (Kiểu dữ liệu — Data Types)

필드에 입력될 데이터의 성격과 크기를 정의하는 속성입니다.

| 데이터 형식 (Kiểu dữ liệu tiếng Hàn) | 영어 명칭 (Tiếng Anh) | 저장 용량 및 출제 특징 (Dung lượng & Đặc điểm đề thi) |
|---|---|---|
| **짧은 텍스트** | Short Text | 최대 255자 저장. 한글, 영문, 숫자, 특수문자 입력 가능. 기본 크기는 255이며 시험에서는 보통 5~20자 내외로 `필드 크기` 축소를 지시함. — *Lưu tối đa 255 ký tự chữ/số. Kích thước mặc định là 255, đề thi thường yêu cầu rút gọn xuống 5~20 ký tự để tối ưu bộ nhớ.* |
| **긴 텍스트** | Long Text (Memo) | 대용량 텍스트 저장 (최대 1GB). 주로 '비고', '메모', '상세설명' 필드에 적용. — *Lưu văn bản dài (tối đa 1GB), chuyên dùng cho các trường ghi chú, bản tin, mô tả chi tiết.* |
| **숫자** | Number | 산술 연산에 사용되는 숫자. 하위 `필드 크기` 속성(바이트, 정수, 정수(Long), 실수)을 정확히 지정해야 함. — *Dùng cho số học tính toán. Phải cấu hình chính xác kích thước trường con (Byte, Integer, Long, Single, Double).* |
| **날짜/시간** | Date/Time | 8바이트 날짜 및 시간 값 저장 (예: 2026-10-15 14:30:00). — *Lưu giá trị ngày và giờ chuẩn 8 byte.* |
| **통화** | Currency | 통화 데이터 전용. 소수점 이하 4자리까지 정확한 금융 계산 지원 및 통화 기호 자동 부여. — *Chuyên dụng cho tiền tệ, hỗ trợ độ chính xác tài chính đến 4 chữ số thập phân và tự gắn ký hiệu tiền tệ.* |
| **일련 번호** | AutoNumber | 새 레코드가 추가될 때마다 1부터 자동으로 1씩 증가하는 4바이트 정수. 수동 편집 불가. — *Số nguyên tự động tăng 1 đơn vị mỗi khi thêm bản ghi mới, không được sửa thủ công.* |
| **Yes/No** | Yes/No (Boolean) | 참/거짓 논리값. `-1`(Yes/True) 또는 `0`(No/False)만 저장. 주로 체크 상자 형태로 표시됨. — *Lưu giá trị logic -1 (Yes) hoặc 0 (No), thường hiển thị dạng hộp kiểm Checkbox.* |
| **OLE 개체** | OLE Object | 외부 문서, 이미지, 스프레드시트 개체 연결 및 포함. — *Liên kết hoặc nhúng tệp ngoài như ảnh bitmap, tài liệu Word, bảng Excel.* |
| **하이퍼링크** | Hyperlink | 웹 사이트 URL 또는 파일 경로 저장. — *Lưu đường dẫn liên kết URL web hoặc đường dẫn tập tin nội bộ.* |
| **첨부 파일** | Attachment | 사진, PDF 문서 등 다중 파일 첨부. — *Đính kèm nhiều tệp như hình chụp thẻ nhân viên, tài liệu PDF.* |

### 1.3 필드 속성: 필드 크기 & 형식 (Field Properties)

#### 1. 필드 크기 (Field Size)
- **짧은 텍스트 (Short Text):**
  - 지시사항에 명시된 글자 수를 정수로 입력합니다 (예: `사번` 필드를 6자리로 제한 $\rightarrow$ `6` 입력).
  - *Nhập số nguyên quy định số ký tự tối đa (ví dụ trường mã nhân viên dài 6 ký tự $\rightarrow$ nhập `6`).*
- **숫자 형식의 세부 필드 크기 (Field Size for Numbers):**
  - **`바이트 (Byte)`**: $0 \sim 255$ 범위의 부호 없는 정수 (1바이트). 나이, 월(Month) 등에 사용.
  - **`정수 (Integer)`**: $-32,768 \sim 32,767$ 범위의 정수 (2바이트).
  - **`정수 (Long)`**: $-2,147,483,648 \sim 2,147,483,647$ 범위의 정수 (4바이트).
    > [!IMPORTANT]
    > **핵심 원칙:** 다른 테이블의 `일련 번호(AutoNumber)` 필드를 참조하는 외래키(Foreign Key)는 반드시 `숫자` 형식에 `정수 (Long)`으로 지정해야 관계 설정 시 형식 불일치 오류가 발생하지 않습니다.
    > *(Trường khóa ngoại tham chiếu đến trường AutoNumber của bảng cha bắt buộc phải chọn kiểu 숫자 với kích thước 정수 (Long)).*
  - **`실수 (Single)`**: 단정밀도 부동 소수점 수 (7자리 유효숫자, 4바이트).
  - **`실수 (Double)`**: 배정밀도 부동 소수점 수 (15자리 유효숫자, 8바이트).

#### 2. 형식 (Format — Định dạng hiển thị)
원본 데이터의 저장 값은 변경하지 않고, 화면에 표시되는 형태만 변환하는 속성입니다.

- **날짜/시간 서식 (Định dạng Ngày/Giờ):**
  - `yyyy-mm-dd` $\rightarrow$ `2026-10-15`
  - `yyyy-mm-dd (aaa)` $\rightarrow$ `2026-10-15 (목)` (요일 1글자 약칭)
  - `yyyy"년" mm"월" dd"일" aaaa` $\rightarrow$ `2026년 10월 15일 목요일` (요일 전체 명칭)
  - `hh:nn:ss am/pm` $\rightarrow$ `02:30:15 pm` (주의: 분 단위는 월(mm)과 구분하기 위해 반드시 `nn`을 사용함)
- **숫자 및 통화 서식 (Định dạng Số & Tiền tệ):**
  - `#,##0` $\rightarrow$ 천 단위 구분 기호(`,`)를 표시하며, 값이 0일 때 `0`을 표시함.
  - `#,###` $\rightarrow$ 천 단위 구분 기호를 표시하되, 값이 0일 때는 빈칸으로 숨김.
  - `#,##0"원"` $\rightarrow$ 숫자 뒤에 '원' 텍스트를 결합하여 표시 (예: `150,000원`).
  - `\ #,##0` 또는 `"₩"#,##0` $\rightarrow$ 원화 통화 기호 접두.
  - `00000` $\rightarrow$ 5자리 고정 표시 (자릿수가 부족하면 앞자리를 0으로 채움: 예: 25 $\rightarrow$ `00025`).
- **텍스트 서식 (Định dạng Văn bản):**
  - `>` : 모든 영문 문자를 대문자로 변환하여 표시.
  - `<` : 모든 영문 문자를 소문자로 변환하여 표시.
  - `@` : 텍스트 문자 필수 표시 자리.

### 1.4 입력 마스크 (Input Mask — mặt nạ nhập liệu)

입력 마스크는 데이터 입력 시 사용자가 정해진 서식과 규칙에 맞게 데이터를 타이핑하도록 안내하고 제어하는 강력한 입력 제어 도구입니다.

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ '전화번호' 필드는 다음과 같이 입력 마스크를 설정하시오.
   - 앞자리 3자리, 중간 4자리, 뒷자리 4자리의 숫자를 반드시 입력받도록 할 것.
   - 기호 '-'도 함께 테이블에 저장되도록 설정할 것.
   - 데이터가 입력되지 않은 자리는 '*'로 표시하시오.
```

#### 입력 마스크 사용자 지정 기호 체계 (Bảng ký tự quy ước chuẩn KCCI):

| 기호 (Ký tự) | 필수/선택 (Tính chất) | 허용 문자 및 동작 설명 (Quy tắc & Hành vi chi tiết) |
|:---:|:---:|---|
| **0** | **필수 (Bắt buộc)** | $0 \sim 9$까지의 숫자만 입력 가능. 덧셈/뺄셈 기호(`+`, `-`) 입력 불가. — *Chỉ cho phép nhập số từ 0 đến 9, cấm nhập dấu cộng/trừ.* |
| **9** | 선택 (Tùy chọn) | $0 \sim 9$까지의 숫자 또는 공백(Space) 입력 가능. 기호 불가. — *Cho phép nhập số hoặc khoảng trắng, cấm nhập dấu.* |
| **#** | 선택 (Tùy chọn) | $0 \sim 9$까지의 숫자, 공백, 덧셈/뺄셈 기호(`+`, `-`) 입력 가능. — *Cho phép nhập số, khoảng trắng hoặc dấu cộng/trừ.* |
| **L** | **필수 (Bắt buộc)** | 영문자($A \sim Z, a \sim z$) 및 한글만 입력 가능. — *Chỉ cho phép nhập chữ cái tiếng Anh hoặc chữ Hàn, cấm nhập số.* |
| **?** | 선택 (Tùy chọn) | 영문자, 한글 또는 공백 입력 가능. — *Cho phép nhập chữ cái tiếng Anh, chữ Hàn hoặc khoảng trắng.* |
| **A** | **필수 (Bắt buộc)** | 영문자, 한글, 숫자만 입력 가능 (특수문자 제외). — *Chỉ cho phép nhập chữ cái hoặc số, cấm nhập ký tự đặc biệt.* |
| **a** | 선택 (Tùy chọn) | 영문자, 한글, 숫자 또는 공백 입력 가능. — *Cho phép nhập chữ cái, số hoặc khoảng trắng.* |
| **&** | **필수 (Bắt buộc)** | 모든 문자(특수문자 포함) 및 공백 입력 가능. — *Cho phép nhập mọi ký tự bất kỳ bao gồm cả ký tự đặc biệt.* |
| **C** | 선택 (Tùy chọn) | 모든 문자 또는 공백 입력 가능. — *Cho phép nhập ký tự bất kỳ tùy chọn hoặc khoảng trắng.* |
| **>** | 제어 (Điều khiển) | 이후에 입력되는 모든 영문자를 대문자로 자동 변환. — *Tự động chuyển toàn bộ chữ cái nhập sau ký hiệu này thành chữ IN HOA.* |
| **<** | 제어 (Điều khiển) | 이후에 입력되는 모든 영문자를 소문자로 자동 변환. — *Tự động chuyển toàn bộ chữ cái nhập sau ký hiệu này thành chữ in thường.* |
| **!** | 제어 (Điều khiển) | 입력 마스크를 오른쪽에서 왼쪽으로 채워 넣음. — *Điền mặt nạ nhập liệu từ phải qua trái.* |
| **\\** | 이스케이프 (Thoát) | 바로 뒤에 오는 특수문자를 서식 기호가 아닌 일반 문자로 그대로 표시 (예: `\-`, `\A`). — *Ký tự thoát: Hiển thị ký tự đứng liền sau dưới dạng chữ thông thường.* |

#### 입력 마스크의 3개 구역 구조 (Cấu trúc 3 phần ngăn cách bởi dấu chấm phẩy `;`):
$$\mathbf{\text{제 1구역}} \; ; \; \mathbf{\text{제 2구역}} \; ; \; \mathbf{\text{제 3구역}}$$

1. **제 1구역 (서식 기호 — Khuôn mẫu mặt nạ):**
   - 위 표의 기호들을 조합하여 입력 서식을 정의합니다 (예: `000-0000-0000`, `>L000`).
2. **제 2구역 (구분 기호 저장 여부 — Lưu ký tự phân cách):**
   - `0`: 서식 문자(하이픈 `-`, 슬래시 `/` 등)를 **데이터와 함께 테이블에 저장**합니다.
   - `1` 또는 **공백(생략)**: 사용자가 입력한 순수 데이터만 저장하고 구분 기호는 **저장하지 않습니다**.
3. **제 3구역 (자리 표시 문자 — Ký tự giữ chỗ Placeholder):**
   - 데이터가 아직 입력되지 않은 위치에 화면상 표시할 기호(예: `_`, `*`, `#`)를 지정합니다. 생략하면 기본값으로 밑줄(`_`)이 표시됩니다.

#### 핵심 빈출 공식 예시 (Các ví dụ kinh điển trong đề thi):
- **예시 1:** 필수 숫자 3자리-4자리-4자리 전화번호, 하이픈 포함 저장, 빈자리 `*` 표시:
  $$\mathbf{000-0000-0000;0;*}$$
- **예시 2:** 주민등록번호 6자리-7자리 필수 숫자, 하이픈 미저장, 빈자리 `#` 표시:
  $$\mathbf{000000-0000000;1;#} \quad \text{또는} \quad \mathbf{000000-0000000;;#}$$
- **예시 3:** 첫 글자는 필수 대문자 영문, 뒤의 4자리는 필수 숫자, 기호 미포함:
  $$\mathbf{>L0000;;}$$

### 1.5 기본값 & 유효성 검사 (Default Value & Validation)

#### 1. 기본값 (기본값 — Default Value)
새로운 레코드를 생성할 때 해당 필드에 자동으로 채워질 초깃값을 지정합니다.
- 오늘 날짜 자동 입력: `=Date()`
- 현재 날짜와 시간 자동 입력: `=Now()`
- 기본 숫자 입력: `0` (따옴표 없이 입력)
- 기본 텍스트 입력: `"서울"`, `"정회원"`, `"대기"` (반드시 큰따옴표 `""`로 감쌈)

#### 2. 유효성 검사 규칙 & 유효성 검사 텍스트 (Validation Rule & Text)
- **유효성 검사 규칙 (Validation Rule):** 사용자가 잘못된 데이터를 입력하지 못하도록 논리 조건을 강제합니다. 조건식이 참(`True`)일 때만 입력을 허용합니다.
- **유효성 검사 텍스트 (Validation Text):** 사용자가 유효성 검사 규칙을 위반하는 데이터를 입력했을 때 화면에 띄울 한글 경고 메시지를 입력합니다.

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ '나이' 필드는 20 이상 60 이하의 값만 입력되도록 유효성 검사 규칙을 설정하고,
   규칙을 위반할 경우 "나이는 20에서 60 사이여야 합니다."라는 메시지를 표시하시오.
▶ '이메일' 필드는 반드시 '@' 문자가 포함되도록 설정하시오.
```

#### 주요 유효성 검사 조건식 모음 (Bảng biểu thức hợp lệ thường gặp):

| 업무 요구 조건 (Tình huống yêu cầu) | 유효성 검사 규칙 (Biểu thức Validation Rule chuẩn) |
|---|---|
| **0 이상 100 이하의 숫자만 허용**: *Chỉ cho phép số từ 0 đến 100* | `>= 0 And <= 100` 또는 `Between 0 And 100` |
| **0보다 큰 양수만 허용**: *Chỉ cho phép số dương lớn hơn 0* | `> 0` |
| **지정된 목록("A", "B", "C") 중 하나만 허용**: *Chỉ cho phép giá trị thuộc danh sách ("A", "B", "C")* | `In("A", "B", "C")` |
| **대문자 'S'로 시작하는 문자열만 허용**: *Chỉ cho phép chuỗi bắt đầu bằng chữ 'S'* | `Like "S*"` |
| **'@' 기호가 반드시 포함되어야 함 (이메일 검증)**: *Bắt buộc phải chứa ký tự '@' (kiểm tra định dạng email)* | `Like "*@*"` |
| **마지막 글자가 반드시 숫자로 끝나야 함**: *Ký tự cuối cùng bắt buộc phải là chữ số* | `Like "*[0-9]"` |
| **글자 수가 정확히 5글자여야 함**: *Độ dài chuỗi bắt buộc đúng 5 ký tự* | `Len([사번]) = 5` 또는 `Len([필드명]) = 5` |
| **오늘 날짜 이후의 날짜만 입력 허용**: *Chỉ cho phép ngày nhập lớn hơn hoặc bằng ngày hôm nay* | `>= Date()` |
| **2000년 1월 1일 이전 출생자만 허용**: *Chỉ cho phép ngày sinh trước ngày 01/01/2000* | `< #2000-01-01#` (날짜 상수는 `#` 기호로 감쌈) |
| **빈 값(Null) 불허 및 0 이상 입력**: *Cấm ô trống (Null) và giá trị phải lớn hơn hoặc bằng 0* | `Is Not Null And >= 0` |

### 1.6 기타 주요 필드 속성 (Các thuộc tính bảng quan trọng khác)

- **필수 (Required):**
  - `예 (Yes)`: 데이터를 반드시 입력해야 함 (비워둘 수 없음, 데이터베이스의 `NOT NULL` 제약 조건).
  - `아니요 (No)`: 데이터를 입력하지 않고 비워두는 것을 허용함.
- **인덱스 (Indexed):**
  - `아니요 (No)`: 인덱스를 생성하지 않음.
  - `예 (중복 가능)`: 검색 속도를 높이기 위해 인덱스를 생성하되, 동일한 값의 중복 입력을 허용함.
  - `예 (중복 불가능)`: 검색 인덱스를 생성하고, 테이블 내에서 해당 필드 값의 중복을 엄격히 차단함 (`UNIQUE` 제약 조건).
- **빈 문자열 허용 (Allow Zero Length):**
  - `예 (Yes)`: 길이가 0인 빈 문자열(`""`) 입력을 허용함 (Null 값과는 구분됨).
  - `아니요 (No)`: 빈 문자열 입력을 금지함. 보통 `필수 = 예`와 함께 지정됨.
- **IME 모드 (IME Mode):**
  - 포커스가 해당 필드로 이동했을 때 한글/영문 입력기 모드를 자동으로 전환합니다.
  - `한글`: 한글 입력 상태로 자동 전환.
  - `영숫자 반자`: 영문 및 반각 숫자 입력 상태로 자동 전환.

## 2. 관계 설정 (Thiết lập quan hệ toàn vẹn — 5점)

관계 설정(Relationships)은 기본 테이블의 기본키(1)와 관련 테이블의 외래키(다)를 연결하여 1:N(일대다) 관계를 형성하고 데이터 무결성을 보장하는 작업입니다.

```
┌─────────────────────────────────────────────────────────┐
│ 관계 편집 (Edit Relationships) 대화 상자 구조           │
├────────────────────────────┬────────────────────────────┤
│ 테이블/쿼리 (기본 테이블)  │ 관련 테이블/쿼리 (참조)    │
│ [고객]                     │ [주문]                     │
│ 고객ID                     │ 고객ID                     │
├────────────────────────────┴────────────────────────────┤
│ [v] 항상 참조 무결성 유지 (Enforce Referential Integrity)│
│ [v] 관련 필드 모두 업데이트 (Cascade Update)             │
│ [v] 관련 레코드 모두 삭제 (Cascade Delete)              │
├─────────────────────────────────────────────────────────┤
│ 관계 종류: 일대다 (One-To-Many)                         │
│                    [ 만들기 (Create) ]   [ 취소 ]        │
└─────────────────────────────────────────────────────────┘
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <고객> 테이블의 '고객ID' 필드와 <주문> 테이블의 '고객ID' 필드에 대해 다음과 같이 관계를 설정하시오.
   - 각 테이블 간에 항상 참조 무결성을 유지하도록 설정하시오.
   - <고객> 테이블의 '고객ID' 필드가 변경되면 <주문> 테이블의 '고객ID' 필드도 따라서 변경되도록 설정하시오.
   - <고객> 테이블의 레코드가 삭제될 때 <주문> 테이블의 관련 레코드도 함께 삭제되도록 설정하시오.
```

#### 단계별 표준 작업 절차 (Các bước thực hiện chuẩn xác):
1. **열려 있는 모든 테이블을 저장하고 닫습니다.**
   *Lưu và đóng toàn bộ các bảng đang mở (nếu bảng đang mở, Access sẽ khóa và không cho phép tạo quan hệ).*
2. **[데이터베이스 도구] 탭 $\rightarrow$ [관계] 그룹 $\rightarrow$ [관계] 아이콘을 클릭합니다.**
   *Trên thanh Ribbon, chọn tab [데이터베이스 도구] (Database Tools) $\rightarrow$ nhóm [관계] $\rightarrow$ nhấp chọn nút [관계].*
3. **작업 창에 지정된 테이블이 표시되지 않은 경우, 빈 영역을 마우스 우클릭 $\rightarrow$ `[테이블 표시]` (또는 리본의 `[테이블 추가]`)를 클릭하여 대상 테이블을 더블클릭으로 추가합니다.**
   *Nếu bảng yêu cầu chưa xuất hiện trên sơ đồ, nhấp chuột phải chọn [테이블 표시] và nhấp đúp để đưa các bảng vào màn hình.*
4. **기본 테이블의 기본키 필드를 드래그하여 관련 테이블의 외래키 필드 위로 정확히 끌어다 놓습니다(Drag & Drop).**
   *Kéo trường khóa chính từ bảng 1 thả chính xác lên trường khóa ngoại tương ứng ở bảng N.*
5. **[관계 편집] 대화 상자가 열리면 문제의 지시에 따라 3가지 옵션을 체크합니다:**
   - **`항상 참조 무결성 유지 (Enforce Referential Integrity)`**: 관련 테이블의 외래키에 존재하지 않는 기본키 값이 입력되는 것을 방지합니다. (Đảm bảo toàn vẹn tham chiếu, chống bản ghi mồ côi).
   - **`관련 필드 모두 업데이트 (Cascade Update Related Fields)`**: 기본 테이블의 기본키가 수정될 때 관련 테이블의 외래키 값도 자동으로 연쇄 갱신됩니다. (Tự động cập nhật đồng bộ các trường liên quan).
   - **`관련 레코드 모두 삭제 (Cascade Delete Related Records)`**: 기본 테이블의 행이 삭제될 때 관련 테이블의 연결된 행들도 자동으로 연쇄 삭제됩니다. (Tự động xóa đồng bộ các bản ghi liên quan).
6. **[만들기] 단추를 누르고 관계 창을 저장(`Ctrl + S`)한 뒤 닫습니다.**
   *Nhấn nút [만들기] để hoàn tất, nhấn lưu và đóng cửa sổ quan hệ.*

#### 시험장 오류 대처법 (Khắc phục sự cố trong phòng thi):
- **오류: "테이블이 단독 사용 중이거나 이미 열려 있습니다."**
  $\rightarrow$ 열려 있는 모든 테이블 탭을 닫고 다시 시도합니다.
- **오류: "참조 무결성을 적용할 수 없습니다. 기존 데이터가 무결성 규칙을 위반합니다."**
  $\rightarrow$ 관련 테이블(다 쪽)에 기본 테이블(1 쪽)에 존재하지 않는 데이터가 이미 들어있는 상태입니다. 이전 문제에서 데이터 정제나 오타 수정 요구사항이 누락되었는지 확인하십시오.
- **오류: "데이터 형식이 일치하지 않습니다."**
  $\rightarrow$ 기본 테이블 필드가 `일련 번호`이면 관련 테이블 필드는 반드시 `숫자 - 정수(Long)`이어야 합니다. `정수`나 `짧은 텍스트`로 되어 있으면 관계가 맺어지지 않습니다.

## 3. 조회 속성 & 외부 데이터 가져오기 (5점)

### 3.1 조회 속성 설정 (콤보 상자 변환 — Lookup Properties)

일반 텍스트 상자 형태로 표시되는 필드를 드롭다운 목록 형태의 **콤보 상자(Combo Box)**로 변경하여 데이터를 편리하게 선택 입력할 수 있도록 구성하는 작업입니다.

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <사원> 테이블의 '부서코드' 필드에 대해 다음과 같이 조회 속성을 설정하시오.
   - <부서> 테이블의 '부서코드'와 '부서명'이 콤보 상자 형태로 표시되도록 설정하시오.
   - 바운드 열은 '부서코드'(첫 번째 열)로 지정하시오.
   - 열 개수는 2개로 설정하고, 열 너비는 각각 '0cm; 3cm'로 지정하시오.
   - 목록 값만 입력할 수 있도록 설정하시오.
```

#### 속성별 설정 지침 (Chi tiết cấu hình từng thuộc tính):
1. 테이블을 **[디자인 보기]**로 열고 대상 필드를 클릭합니다.
2. 하단 [필드 속성] 영역에서 **[조회]** 탭을 클릭합니다.
3. 문제 지시에 따라 다음 항목들을 순서대로 구성합니다:

| 조회 속성 명칭 (Tiếng Hàn) | 설정값 및 실전 작성법 (Cấu hình chuẩn) | 상세 기술적 설명 (Giải thích kỹ thuật) |
|---|---|---|
| **컨트롤 표시** | `콤보 상자` (Combo Box) | 기본 텍스트 상자에서 드롭다운 콤보 상자로 변환. — *Chuyển đổi hộp văn bản thông thường thành hộp thả ComboBox.* |
| **행 원본 유형** | `테이블/쿼리` (Table/Query) | 외부 테이블/쿼리에서 목록을 가져올 때 선택. (직접 입력 시는 `값 목록`). — *Chọn nạp dữ liệu từ Table/Query ngoài (nếu gõ chữ trực tiếp chọn 값 목록).* |
| **행 원본** | `SELECT 부서코드, 부서명 FROM 부서;` | `...` 작성기 버튼을 눌러 쿼리 디자인 창에서 테이블과 필드를 추가하거나 직접 SQL문 작성. — *Nhấn nút `...` để thiết kế câu lệnh SQL chọn các trường cần hiển thị trong danh sách.* |
| **바운드 열** | `1` | 콤보 상자에서 항목을 선택했을 때 테이블 필드에 실제로 저장될 열의 순번 (1부터 시작). — *Chỉ số cột (bắt đầu từ 1) sẽ thực sự lưu giá trị vào bảng khi người dùng chọn mục.* |
| **열 개수** | `2` | 콤보 상자 목록에 표시할 전체 열의 개수. — *Tổng số cột hiển thị trong danh sách ComboBox.* |
| **열 너비** | `0cm;3cm` | 각 열의 너비를 세미콜론(`;`)으로 구분하여 입력. `0cm`로 설정된 열은 화면에서 숨겨짐. — *Độ rộng từng cột ngăn cách bằng `;`. Cột đặt `0cm` sẽ bị ẩn khỏi màn hình.* |
| **목록 너비** | `3cm` (또는 `자동`) | 콤보 상자를 클릭했을 때 펼쳐지는 드롭다운 목록의 전체 가로 너비. — *Độ rộng toàn bộ danh sách khi nhấn nút mở ComboBox.* |
| **목록 값만 허용** | `예` (Yes) | 사용자가 목록에 없는 임의의 값을 직접 키보드로 입력하는 것을 차단. — *Chỉ cho phép chọn giá trị có trong danh sách, cấm người dùng tự gõ giá trị lạ.* |

### 3.2 외부 데이터 가져오기 (Nạp dữ liệu ngoài — External Data Import)

Excel 파일(`.xlsx`) 또는 텍스트 파일(`.txt`, `.csv`)의 데이터를 Access 데이터베이스로 가져와 새 테이블을 생성하거나 기존 테이블에 레코드를 추가(Append)하는 작업입니다.

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ 외부 데이터 <C:\DB\추가사원.xlsx> 파일의 'Sheet1' 데이터를 가져와 <사원> 테이블에 추가하시오.
   - 첫 행은 열 머리글임.
   - 기본 키는 설정하지 마시오.
```

#### 표준 마법사 진행 단계 (Quy trình thuật sĩ chuẩn):
1. **[외부 데이터] 탭 $\rightarrow$ [가져오기 및 연결] 그룹 $\rightarrow$ [새 데이터 원본] $\rightarrow$ [파일에서] $\rightarrow$ [Excel]을 클릭합니다.**
   *Vào tab [외부 데이터] $\rightarrow$ nhóm [가져오기 및 연결] $\rightarrow$ [새 데이터 원본] $\rightarrow$ [파일에서] $\rightarrow$ chọn [Excel].*
2. **[찾아보기] 단추를 클릭하여 지시된 경로의 엑셀 파일을 선택합니다.**
   *Nhấp nút [찾아보기] dẫn đến file Excel cần nạp.*
3. **가져오기 방법 선택 (Chọn phương thức nạp dữ liệu):**
   - `현재 데이터베이스의 새 테이블로 원본 데이터 가져오기`: 새 테이블 생성 시 선택.
     *(Chọn mục này khi đề yêu cầu tạo một bảng mới hoàn toàn).*
   - `다음 테이블에 레코드 복사본 추가`: 기존 테이블에 레코드를 누적 추가할 때 선택하고 대상 테이블명을 지정.
     *(Chọn mục này khi đề yêu cầu nạp nối thêm bản ghi vào một bảng đã có sẵn).*
4. **[스프레드시트 가져오기 마법사] 단계별 진행 (Các bước trong trình thuật sĩ):**
   - **워크시트 선택:** 해당 데이터가 있는 시트(예: `Sheet1`)를 선택하고 [다음] 클릭.
     *Chọn Sheet chứa dữ liệu cần nạp rồi nhấn [다음].*
   - **열 머리글 설정 (가장 중요):** 문제에 *"첫 행은 열 머리글임"* 지시가 있는 경우 반드시 **[첫 행에 열 머리글이 있음]** 체크 상자에 체크합니다.
     *(Cực kỳ quan trọng: Tích chọn ô [첫 행에 열 머리글이 있음] nếu đề bài quy định dòng đầu là tiêu đề).*
   - **필드 옵션:** 특정 필드를 건너뛰거나 데이터 형식을 변경할 필요가 있는 경우 조정 후 [다음] 클릭.
     *Điều chỉnh kiểu dữ liệu từng cột nếu có yêu cầu rồi nhấn [다음].*
   - **기본 키 정의 (Khóa chính):**
     - `기본 키 직접 선택`: 특정 필드를 기본키로 지정할 때 선택.
       *(Tự chọn một trường làm khóa chính).*
     - `기본 키 없음`: 기본키를 지정하지 말라고 한 경우 선택.
       *(Không đặt khóa chính theo đúng yêu cầu đề bài).*
   - **테이블 이름 지정:** 최종 테이블 이름을 문제 요구에 맞게 정확히 타이핑한 후 [마침] 단추를 누릅니다.
     *Gõ chính xác tên bảng theo đề bài rồi bấm [마침] (Finish).*
