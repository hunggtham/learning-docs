# 08 — 조회 및 출력 (보고서 완성 및 조건부 서식)

> **시험 표준 (Tiêu chuẩn đề thi):** 컴퓨터활용능력 1급 실기 · 과목 2: 데이터베이스 실무 (Access 2021 LTSC)
> **배점 (Thang điểm phần thi):** 25점 / 100점 (권장 소요 시간: 8 – 10분)
> **세부 문항 구성 (Phân bổ nội dung chi tiết):**
> 1. 보고서 완성 (Hoàn thiện cấu trúc & Thuộc tính báo cáo): 5문항 × 3점 = 15점
> 2. 페이지 번호 출력 및 요약 집계 (Đánh số trang & Tính toán tổng hợp): 1문항 = 5점
> 3. 조건부 서식 (Định dạng có điều kiện trên Report): 1문항 = 5점

## 1. 보고서 완성 (Hoàn thiện Report — 15점)

보고서(Report)는 데이터베이스의 테이블이나 쿼리 데이터를 인쇄하거나 미리 보기 형태로 화면에 출력하기 위해 최적화된 개체입니다. 수험자는 제공된 보고서를 **[디자인 보기]**로 열고 각 구역(Section) 및 컨트롤의 속성을 **속성 시트(단축키 `F4`)**에서 수정합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ 보고서의 5대 구역 계층 구조 (Cấu trúc phân tầng 5 phân vùng Report)   │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 보고서 머리글 (Report Header) : 전체 보고서 첫 페이지 상단 1회 출력 │
├────────────────────────────────────────────────────────────────────────┤
│ 2. 페이지 머리글 (Page Header)   : 매 페이지 상단마다 반복 출력        │
├────────────────────────────────────────────────────────────────────────┤
│ 3. [그룹] 머리글 (Group Header)  : 새로운 그룹이 시작될 때마다 출력    │
├────────────────────────────────────────────────────────────────────────┤
│ 4. 본문 (Detail)                 : 원본 레코드 개수만큼 반복 출력      │
├────────────────────────────────────────────────────────────────────────┤
│ 5. [그룹] 바닥글 (Group Footer)  : 해당 그룹이 끝날 때 소계 출력       │
├────────────────────────────────────────────────────────────────────────┤
│ 6. 페이지 바닥글 (Page Footer)   : 매 페이지 하단마다 페이지 번호 출력 │
├────────────────────────────────────────────────────────────────────────┤
│ 7. 보고서 바닥글 (Report Footer) : 전체 보고서 마지막 페이지 총계 출력 │
└────────────────────────────────────────────────────────────────────────┘
```

---

### 1.1 보고서 구역별 특성 및 출력 주기 대조표

| 구역 명칭 (Tiếng Hàn) | 영문 명칭 (Tiếng Anh) | 인쇄 출력 위치 (Vị trí in) | 출력 빈도 및 역할 (Tần suất & Vai trò) |
|---|---|---|---|
| **보고서 머리글** | Report Header | 보고서의 **맨 첫 페이지 최상단** | 보고서 전체에서 **단 1회만 출력**. 보고서 제목, 회사 로고, 출력 일자 배치. — *Chỉ xuất hiện đúng 1 lần duy nhất trên đầu trang đầu tiên của báo cáo (tiêu đề, logo).* |
| **페이지 머리글** | Page Header | **모든 페이지의 최상단** (1페이지는 보고서 머리글 다음) | **매 페이지 상단마다 반복 출력**. 열 이름(칼럼 헤더: 사번, 성명, 금액 등) 배치. — *Lặp lại ở đầu tất cả các trang in (dùng đặt tên tiêu đề các cột dữ liệu).* |
| **그룹 머리글** | Group Header | **각 그룹의 시작 부분** | 그룹 기준 필드 값이 바뀔 때마다 1회 출력 (예: 부서명, 지역명). — *Xuất hiện mỗi khi giá trị nhóm thay đổi (ví dụ đầu nhóm phòng ban, đầu nhóm tỉnh thành).* |
| **본문** | Detail | 보고서의 본문 영역 | **각 데이터 레코드마다 1회씩 반복 출력**. 개별 상세 데이터 표시. — *Lặp lại cho từng bản ghi dữ liệu chi tiết của bảng.* |
| **그룹 바닥글** | Group Footer | **각 그룹의 마지막 부분** | 해당 그룹의 데이터 출력이 끝난 후 출력. **그룹 소계(Subtotal), 인원수 카운트** 배치. — *Xuất hiện ở cuối mỗi nhóm (dùng tính tổng phụ Subtotal, đếm số lượng thành viên nhóm).* |
| **페이지 바닥글** | Page Footer | **모든 페이지의 최하단** | **매 페이지 밑바닥마다 반복 출력**. **페이지 번호(`[Page]`)를 배치할 수 있는 유일한 공간**. — *Lặp lại ở chân mọi trang in (vị trí duy nhất hợp lệ để chèn số trang).* |
| **보고서 바닥글** | Report Footer | **마지막 페이지의 본문(또는 그룹 바닥글) 바로 아래** | 보고서 전체에서 **단 1회만 출력**. 전체 총합계(Grand Total), 총 레코드 수 표시. — *Chỉ xuất hiện đúng 1 lần ở cuối trang cuối cùng (tính tổng toàn bộ Grand Total).* |

## 2. 그룹화 및 정렬 (Gom nhóm & Sắp xếp dữ liệu)

보고서에서는 데이터가 뒤섞여 출력되지 않도록 특정 필드를 기준으로 그룹을 묶고 정렬 순서를 지정해야 합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ [그룹화 및 정렬] 창 설정 인터페이스                                    │
├────────────────────────────────────────────────────────────────────────┤
│ • 그룹 추가 (Add a group)  : [ 부서명            v ] [ 오름차순   v ]  │
│   └─ [자세히] 클릭:                                                    │
│      - 머리글 구역 있음 (with a header section)                        │
│      - 바닥글 구역 있음 (with a footer section)                        │
│      - 전체 그룹을 같은 페이지에 유지 (Keep whole group together)       │
│ • 정렬 추가 (Add a sort)   : [ 입사일자          v ] [ 내림차순   v ]  │
└────────────────────────────────────────────────────────────────────────┘
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ <제품별판매현황> 보고서의 정렬 및 그룹화를 다음과 같이 설정하시오.
   - 1차로 '분류코드'를 기준으로 오름차순 그룹화하고, 그룹 머리글과 바닥글을 표시하시오.
   - 2차로 동일한 그룹 내에서 '판매금액'을 기준으로 내림차순 정렬하시오.
```

#### 단계별 작업 절차 (Các bước thực hiện chuẩn):
1. 보고서 디자인 보기 상태에서 리본 메뉴의 **[보고서 디자인] 탭 $\rightarrow$ [그룹화 및 요약] 그룹 $\rightarrow$ [그룹화 및 정렬]** 아이콘을 클릭합니다.
2. 화면 하단에 `그룹화, 정렬 및 요약` 창이 열리면:
   - **`[그룹 추가]`**를 클릭 $\rightarrow$ 기준 필드(`분류코드`) 선택 $\rightarrow$ `오름차순` 지정.
   - 해당 행의 **`[자세히]`** 단추 클릭 $\rightarrow$ `머리글 구역 표시 안 함`을 **`머리글 구역 있음`**으로 변경, `바닥글 구역 표시 안 함`을 **`바닥글 구역 있음`**으로 변경.
3. 이어서 **`[정렬 추가]`**를 클릭 $\rightarrow$ 2차 정렬 필드(`판매금액`) 선택 $\rightarrow$ `내림차순` 지정.

## 3. 페이지 제어 속성 (Phân trang & Giữ trang)

보고서의 각 구역(Section) 헤더 막대를 클릭하고 속성 시트(`F4`)의 **[형식]** 탭에서 페이지 나눔과 표시 방식을 제어합니다.

### 3.1 새 페이지 설정 (Force New Page)
특정 구역이 시작되거나 끝날 때 강제로 다음 페이지로 넘어가도록 설정하는 속성입니다.

- **`없음` (None):** 기본값. 페이지를 강제로 넘기지 않고 연속하여 인쇄합니다.
- **`구역 전` (Before Section):** 해당 구역이 인쇄되기 **직전에** 새 페이지로 넘깁니다.
  > [!TIP]
  > **실전 빈출 적용:** *"분류코드가 변경될 때마다 매번 새로운 페이지에 인쇄되도록 설정하시오"* $\longrightarrow$ **`[분류코드] 머리글`** 구역을 선택하고 **`새 페이지 설정 = 구역 전`**으로 지정합니다.
- **`구역 후` (After Section):** 해당 구역의 내용이 모두 인쇄된 **직후에** 새 페이지로 넘깁니다. (주로 `그룹 바닥글`에 지정).
- **`구역 전후` (Before & After):** 해당 구역의 앞과 뒤 모두에서 페이지를 넘깁니다.

### 3.2 같은 페이지에 표시 (Keep Together)
그룹의 내용이나 특정 구역이 페이지 경계선에 걸려 반으로 잘려 다음 페이지로 넘어가는 현상을 방지합니다.
- 그룹 머리글 또는 본문 구역 속성 시트 $\rightarrow$ **`같은 페이지에 표시` = `예`**로 설정합니다.
- 또는 `그룹화 및 정렬` 창의 `[자세히]` $\rightarrow$ **`전체 그룹을 같은 페이지에 유지`**를 선택합니다.

## 4. 누적 합계 (Running Sum — Đánh số thứ tự tích lũy)

본문(Detail) 구역에서 레코드 번호(일련번호 1, 2, 3...)를 매기거나, 금액을 행마다 누적하여 합산해 나갈 때 사용합니다.

```
┌────────────────────────────────────────────────────────┐
│ 속성 시트: txt순번 (선택 유형: 텍스트 상자)             │
├────────────────────────────────────────────────────────┤
│ [데이터] 탭:                                           │
│ 컨트롤 원본 (Control Source) ...... [ =1             ] │
│ 누적 합계   (Running Sum) ......... [ 그룹           v]│
└────────────────────────────────────────────────────────┘
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ 본문 영역의 'txt순번' 컨트롤에는 그룹별로 일련번호가 1, 2, 3... 형태로 표시되도록 설정하시오.
```

#### 설정 공식 및 옵션 구분:
1. 대상 텍스트 상자(`txt순번`)를 선택하고 속성 시트의 **[데이터]** 탭으로 이동합니다.
2. **`컨트롤 원본 (Control Source)`** 속성에 다음 수식을 직접 입력합니다:
   $$\mathbf{=1}$$
3. **`누적 합계 (Running Sum)`** 속성을 문제 조건에 따라 선택합니다:
   - **`아니요` (No):** 모든 행에 단순히 숫자 `1`만 출력됩니다.
   - **`그룹` (Over Group):** **그룹 내에서만** $1, 2, 3...$으로 번호가 증가하며, **새로운 그룹이 시작되면 다시 1부터 리셋**됩니다.
   - **`모두` (Over All):** 그룹 구분 없이 보고서의 첫 페이지부터 끝 페이지까지 $1, 2, 3, 4, 5...$로 연속하여 누적 증가합니다.

## 5. 중복 내용 숨기기 (Hide Duplicates)

본문 구역에서 동일한 데이터가 세로로 연속해서 나타날 때, 첫 번째 레코드에만 값을 표시하고 이후 동일한 값은 빈칸으로 감추어 가독성을 높이는 속성입니다.

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ 본문 영역의 'txt고객명' 필드의 값이 이전 레코드와 동일한 경우에는 표시되지 않도록 설정하시오.
```

#### 작업 절차:
1. 본문 영역에서 숨기고자 하는 컨트롤(`txt고객명`)을 클릭합니다.
2. 속성 시트의 **[형식]** 탭으로 이동합니다.
3. **`중복 내용 숨기기 (Hide Duplicates)`** 속성을 찾아서 **`예 (Yes)`**로 변경합니다.

## 6. 요약 계산 및 페이지 번호 동적 출력 (5점)

### 6.1 구역별 집계 함수 작성 규칙 (Aggregate Functions)

모든 계산 컨트롤은 컨트롤 원본에 반드시 등호(`=`)로 시작하여 작성해야 합니다.

| 작성 구역 (Phân vùng) | 요구 계산 내용 (Yêu cầu) | 컨트롤 원본 작성 공식 (Cú pháp chuẩn) | 설명 (Giải thích kỹ thuật) |
|---|---|---|---|
| **그룹 바닥글** | 그룹별 합계 계산 | `=Sum([판매수량])` | 해당 그룹에 속한 레코드들의 판매수량 합계. — *Tính tổng số lượng bán của riêng nhóm đó.* |
| **그룹 바닥글** | 그룹별 평균 계산 | `=Avg([단가])` | 해당 그룹의 단가 평균 (Null 값 자동 제외). — *Tính trung bình đơn giá của nhóm (tự động bỏ qua Null).* |
| **그룹 바닥글** | 그룹별 레코드 수 카운트 | `=Count(*)` | 해당 그룹의 전체 레코드 개수 카운트. — *Đếm tổng số bản ghi trong từng nhóm.* |
| **보고서 바닥글** | 전체 총합계 계산 | `=Sum([판매금액])` | 보고서 전체 레코드의 판매금액 총합산. — *Tính tổng số tiền bán của toàn bộ báo cáo.* |
| **보고서 바닥글** | 전체 총 인원수 카운트 | `=Count(*) & "명"` | 전체 레코드 수 뒤에 '명' 텍스트 결합. — *Đếm toàn bộ số người và nối thêm chữ '명' phía sau.* |

---

### 6.2 페이지 번호 동적 출력 공식 (Dynamic Page Numbers)

Access 보고서 시스템은 현재 페이지 번호를 반환하는 `[Page]` 변수와 전체 페이지 수를 반환하는 `[Pages]` 변수를 제공합니다.
*(Hệ thống Access cung cấp biến `[Page]` đại diện cho trang hiện tại và `[Pages]` đại diện cho tổng số trang của báo cáo).*

> [!CAUTION]
> **배치 위치 필수 주의사항:**
> 페이지 번호 텍스트 상자는 **반드시 `페이지 바닥글 (Page Footer)` 또는 `페이지 머리글 (Page Header)` 구역에 배치**해야 합니다. `본문`이나 `보고서 바닥글`에 배치하면 페이지 번호 계산이 정상 작동하지 않아 0점 처리됩니다.
> *(Hộp số trang bắt buộc phải nằm ở Page Footer hoặc Page Header. Đặt nhầm vào Detail hoặc Report Footer sẽ không tính được tổng số trang và bị 0 điểm).*

#### 실전 빈출 페이지 번호 연결 공식:
- **형태 1:** `1 / 5 페이지`
  $$\mathbf{=[Page] \; \& \; " \; / \; " \; \& \; [Pages] \; \& \; " \; 페이지"}$$
- **형태 2:** `1 쪽 (총 5 쪽)`
  $$\mathbf{=[Page] \; \& \; " \; 쪽 (총 " \; \& \; [Pages] \; \& \; " 쪽)"}$$
- **형태 3:** `Page 1 of 5`
  $$\mathbf{="Page " \; \& \; [Page] \; \& \; " of " \; \& \; [Pages]}$$

## 7. 조건부 서식 (Conditional Formatting — 5점)

조건부 서식은 컨트롤의 데이터 값이 특정 논리 조건을 충족할 때 글꼴 굵게, 글꼴 색, 배경색 등의 서식을 자동으로 적용하는 기능입니다.
*(Định dạng có điều kiện tự động đổi phông chữ đậm, màu chữ, màu nền khi giá trị điều khiển thỏa mãn điều kiện logic).*

```
┌────────────────────────────────────────────────────────────────────────┐
│ 조건부 서식 규칙 관리자 대화 상자                                     │
├────────────────────────────────────────────────────────────────────────┤
│ • 규칙 유형 선택: [ 식이                            v ]                │
│ • 조건식 입력   : [ [근무년수] >= 10                  ]                │
│ • 서식 지정     : [ 굵게 (B) ]  [ 글꼴 색: 빨강 ]  [ 배경색: 노랑 ]    │
└────────────────────────────────────────────────────────────────────────┘
```

#### 실전 문제 지시문 (Đoạn đề bài thực tế mẫu):
```
▶ 본문 영역의 'txt성명', 'txt직급', 'txt기본급' 컨트롤에 대해
   '기본급'이 3,000,000 이상인 경우 글꼴 스타일을 '굵게', 배경색을 '노랑'으로 설정하시오.
```

#### 작업 절차 (Các bước thực hiện chuẩn xác):
1. **다중 컨트롤 선택 (Chọn nhiều điều khiển):**
   본문 구역에서 `txt성명`, `txt직급`, `txt기본급`을 `Shift` 키를 누른 채 클릭하여 동시에 선택합니다.
   *(Giữ phím Shift và nhấp chọn cùng lúc 3 ô txt성명, txt직급, txt기본급 ở phân vùng Detail).*
2. **조건부 서식 메뉴 실행 (Mở menu):**
   리본 메뉴의 **[서식] 탭 $\rightarrow$ [컨트롤 서식] 그룹 $\rightarrow$ [조건부 서식]** 단추를 클릭합니다.
   *(Vào tab [서식] (Format) $\rightarrow$ nhóm [컨트롤 서식] $\rightarrow$ nhấp [조건부 서식]).*
3. **새 규칙 생성 (Tạo quy tắc mới):**
   [조건부 서식 규칙 관리자]에서 **`[새 규칙]`** 단추를 클릭합니다.
   *(Nhấn nút [새 규칙] New Rule).*
4. **규칙 유형 선택 (Chọn kiểu quy tắc):**
   - **`필드 값 (Field Value Is)`**: 서식을 적용할 바로 그 컨트롤 자신의 값과 직접 비교할 때만 사용.
     *(Chỉ dùng khi so sánh trực tiếp giá trị của chính ô đó).*
   - **`식이 (Expression Is)`**: **다른 필드의 값을 참조하여 조건을 판별하거나, 여러 컨트롤에 동시에 동일한 서식을 적용할 때 필수 선택**.
     *(Bắt buộc chọn `식이` khi tham chiếu sang trường khác hoặc áp dụng định dạng cho nhiều ô cùng lúc).*
5. **조건식 작성 (Soạn biểu thức):**
   `식이`를 선택하고 조건 입력란에 대괄호를 포함하여 수식을 입력합니다:
   $$\mathbf{[기본급] >= 3000000}$$
6. **서식 지정 (Thiết lập màu sắc):**
   `[굵게]` 아이콘을 누르고 `[배경색]`을 노란색으로 지정한 뒤 [확인] $\rightarrow$ [적용] $\rightarrow$ [확인]을 차례로 클릭합니다.
   *(Bấm nút Chữ đậm, chọn nền Vàng rồi bấm OK $\rightarrow$ Apply $\rightarrow$ OK).*

## 8. 보고서 0점 방지 종합 검증 체크리스트 (Bảng kiểm tra chống mất điểm phòng thi)

| 점검 영역 (Hạng mục) | 검증 질문 (Câu hỏi tự kiểm tra tại phòng thi) | 위반 시 결과 (Hậu quả vi phạm) |
|---|---|:---:|
| **정렬 및 그룹화** — *(Nhóm & Sắp xếp)* | **머리글/바닥글 구역을 [자세히]에서 켰으며, 1차 그룹과 2차 정렬 순서를 정확히 맞췄는가?** — *Tiếng Việt giải thích:* Đã bật 머리글 구역 있음 / 바닥글 구역 있음 trong mục [자세히] và xếp đúng thứ tự ưu tiên chưa? | **3점 감점 (0점)**: 그룹 분할 오류 — *(Báo cáo không gom nhóm được dữ liệu)* |
| **새 페이지 설정** — *(Ngắt trang in)* | **"그룹 변경 시마다 새 페이지에 인쇄" 지시 시 그룹 머리글의 `새 페이지 설정`을 `구역 전`으로 지정했는가?** — *Tiếng Việt giải thích:* Khi đề yêu cầu sang trang mới khi đổi nhóm, đã chọn thuộc tính 새 페이지 설정 = 구역 전 ở Group Header chưa? | **3점 감점**: 연속 인쇄 오출력 — *(Bị in dính chùm các nhóm trên cùng 1 trang)* |
| **누적 합계** — *(Số thứ tự tích lũy)* | **일련번호 표시 시 컨트롤 원본에 `=1`을 입력하고 `누적 합계 = 그룹` (또는 `모두`)을 지정했는가?** — *Tiếng Việt giải thích:* Đánh số 1, 2, 3... đã gõ `=1` vào Control Source và chỉnh thuộc tính 누적 합계 thành 그룹/모두 chưa? | **3점 감점**: 단순 숫자 1 반복 출력 — *(Mọi dòng đều hiện mỗi số 1)* |
| **중복 내용 숨기기** — *(Ẩn trùng lặp)* | **동일 값 숨김 지시 시 컨트롤의 [형식] $\rightarrow$ `중복 내용 숨기기`를 `예`로 설정했는가?** — *Tiếng Việt giải thích:* Đã chuyển thuộc tính 중복 내용 숨기기 thành 예 để ẩn các giá trị trùng lặp ở các dòng dưới chưa? | **3점 감점**: 중복 데이터 노출 — *(Dữ liệu trùng bị lặp lại gây rối mắt)* |
| **집계 구역 배치** — *(Vị trí hàm tổng)* | **그룹 소계는 `그룹 바닥글`에, 전체 총합계는 `보고서 바닥글`에 올바르게 분리 배치했는가?** — *Tiếng Việt giải thích:* Đã đặt đúng =Sum() của nhóm vào Group Footer và =Sum() toàn trường vào Report Footer chưa? | **3점 감점 (0점)**: 집계 범위 왜곡 — *(Tính sai phạm vi nhóm và tổng kết)* |
| **페이지 번호 구역** — *(Vị trí số trang)* | **페이지 번호 컨트롤을 반드시 `페이지 바닥글` (Page Footer) 구역에 배치했는가?** — *Tiếng Việt giải thích:* Ô số trang có nằm đúng ở phân vùng Page Footer không (tuyệt đối không đặt vào Report Footer)? | **5점 감점 (0점)**: 페이지 번호 미작동 (#Error) — *(Lỗi không đếm được số trang)* |
| **조건부 서식 유형** — *(Loại quy tắc 서식)* | **다른 필드 조건(예: `[기본급] >= 3000000`) 판별 시 규칙 유형을 `식이` (Expression Is)로 선택했는가?** — *Tiếng Việt giải thích:* Khi so sánh theo trường khác, đã chọn loại quy tắc là `식이` thay vì `필드 값` chưa? | **5점 감점 (0점)**: 서식 미적용 — *(Không đổi màu ô khi thỏa mãn điều kiện)* |
