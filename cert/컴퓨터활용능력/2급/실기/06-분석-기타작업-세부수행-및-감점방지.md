# 06 — 분석·기타작업 세부수행 및 감점방지 매뉴얼 (Cẩm nang thao tác phân tích & bổ trợ và chống điểm 0)

> **시험 출제 기준 (Tiêu chuẩn đề thi):** 대한상공회의소 (KORCHAM) 컴퓨터활용능력 2급 실기 · 출제기준 2024–2026 · Microsoft Office LTSC 2021
> **배점 구조 및 채점 원칙 (Cơ cấu điểm số):** 분석작업 총 **20점 (2문항 × 10점, 부분점수 없음)** + 기타작업 총 **20점 (매크로 10점 [2문항 × 5점] + 차트 10점 [5문항 × 2점])**
> **학습 프레임워크 (Khung đào tạo chuẩn):** 한국어 문제 지시문 (Korean Directive) → 핵심 메커니즘 (Mechanism) → KCCI 감점 함정 (Traps) → 마우스 클릭 절차 (Action) → 검증 루틴 (Verification)

## 0. 배점 구조 및 0점 방지 원칙 (Cơ cấu thang điểm và nỗi sợ 'Điểm 0 tuyệt đối')

- **[분석작업 20점 배점 규정]:** 분석작업은 2문항(각 10점)으로 구성되며 **부분 점수가 절대 없습니다 (All-or-Nothing)**. 피벗 테이블의 사소한 옵션 누락이나 부분합 전 정렬 미수행 시 10점 전액이 0점 처리됩니다.
  *Tiếng Việt giải thích:* Phần phân tích gồm 2 câu hỏi lớn (10đ/câu), hoàn toàn không có điểm thành phần. Quên một tùy chọn nhỏ trong Pivot Table hoặc quên sắp xếp trước khi chạy Subtotal sẽ bị trừ sạch 10 điểm ngay lập tức.
- **[기타작업 20점 배점 규정]:** 매크로 10점(2문항 × 5점), 차트 10점(5문항 × 2점). 차트는 부분 점수가 부여되지만, **기존 차트를 삭제하고 새로 작성하면 10점 전액 0점 처리**됩니다.
  *Tiếng Việt giải thích:* Phần bổ trợ gồm Macro (2 câu × 5đ) và Biểu đồ (5 câu × 2đ). Biểu đồ có điểm thành phần, nhưng cấm tuyệt đối việc xóa đi vẽ mới (mất trắng 10 điểm).

## 1. 부분합 (Subtotal - Tính tổng con theo nhóm)

### 1.1 핵심 메커니즘 (Cơ chế vận hành)
- **[정렬 선행 원칙 (Sort First Rule)]:** 부분합은 동일한 데이터 그룹이 연속으로 나열되어 있을 때만 정상 작동합니다. 반드시 부분합 실행 전에 기준 열을 기준으로 **정렬(오름차순/내림차순)**을 먼저 완료해야 합니다.
  *Tiếng Việt giải thích:* Excel chỉ gom nhóm chính xác khi các bản ghi trùng nhau nằm liên tục. Bắt buộc phải sắp xếp (Sort) cột nhóm trước khi chạy lệnh Subtotal.

### 1.2 KCCI 3대 감점 함정 (3 Bẫy trừ điểm chết)
1. **[함정 1: 정렬 미수행 후 부분합 실행 (10점 감점 / 0점 처리)]:**
   - **지시문:** "부분합을 작성하기 전에 '부서'를 기준으로 오름차순 정렬하시오."
   - 정렬하지 않고 실행하면 부서가 바뀔 때마다 소계 행이 삽입되어 표가 완전히 분할되며 0점 처리됩니다.
2. **[함정 2: 두 번째 부분합 시 '새로운 값으로 대치' 체크 해제 누락]:**
   - **지시문:** "합계를 구한 후, 평균을 추가로 계산하시오."
   - 두 번째 부분합 대화상자에서 **`새로운 값으로 대치(Replace current subtotals)`**의 체크를 반드시 해제해야 합니다. 해제하지 않으면 첫 번째 합계 결과가 삭제되고 평균만 남아 0점 처리됩니다.
3. **[함정 3: 윤곽 지우기(윤곽 기호 제거) 요구]:**
   - **지시문:** "부분합 결과의 윤곽(윤곽 기호)을 지우시오."
   - `데이터` 탭 → `윤곽선` 그룹 → `그룹 해제` 드롭다운 → **`윤곽 지우기(Clear Outline)`**를 클릭해야 감점되지 않습니다.

### 1.3 표준 마우스 클릭 수행 절차 (5단계)
1. **표 안의 임의의 셀 클릭** → `데이터` 탭 → `정렬` 클릭.
2. `기준 추가`에서 문제에서 지정한 열(예: `부서`) 선택, 정렬 순서(예: `오름차순`) 선택 → `확인`.
3. `데이터` 탭 → `부분합` 클릭.
4. **[1차 부분합 설정]:**
   - `그룹화할 항목`: 정렬한 열 이름 선택 (예: `부서`).
   - `사용할 함수`: 지시된 함수 선택 (예: `합계`).
   - `부분합 계산 항목`: 계산할 열만 체크 (기본 체크된 불필요한 열은 반드시 체크 해제!).
   - `확인` 클릭.
5. **[2차 부분합 설정 (추가 함수 계산 시)]:**
   - 다시 `부분합` 버튼 클릭.
   - `사용할 함수`: 두 번째 함수 선택 (예: `평균`).
   - `부분합 계산 항목`: 지정 열 체크.
   - **★ 핵심: `새로운 값으로 대치` 체크 상자 클릭하여 해제!** → `확인`.
6. (윤곽 지우기 지시가 있는 경우) `데이터` → `그룹 해제` → `윤곽 지우기`.

## 2. 피벗 테이블 (PivotTable - 동적 다차원 요약 보고서)

### 2.1 핵심 메커니즘 (Cơ chế vận hành)
- 원본 데이터의 행(Row), 열(Column), 값(Value), 필터(Filter) 영역으로 필드를 드래그 앤 드롭하여 집계하는 동적 분석 도구입니다.

### 2.2 KCCI 4대 감점 함정 (4 Bẫy trừ điểm chết)
1. **[함정 1: 시작 위치 셀 오지정 (10점 감점)]:**
   - **지시문:** "피벗 테이블 보고서는 [A20] 셀에서 시작하시오."
   - 새 워크시트에 생성하거나 시작 셀을 잘못 지정하면 전체 0점 처리됩니다.
2. **[함정 2: 보고서 레이아웃 미변경]:**
   - **지시문:** "보고서 레이아웃을 '개요 형식으로 표시' 또는 '테이블 형식으로 표시'로 지정하시오."
   - `디자인` 탭 → `보고서 레이아웃`에서 지시된 형식으로 변경하지 않고 기본 압축 형식을 유지하면 감점됩니다.
3. **[함정 3: 셀 서식(Ctrl+1)으로 숫자 서식 변경 시 오답]:**
   - 피벗 테이블 영역을 드래그하여 `Ctrl+1`로 숫자를 변경하면 데이터 새로고침 시 서식이 유실됩니다.
   - **필수 절차:** 피벗 테이블 필드 목록의 값 영역에서 해당 필드 클릭 → **`값 필드 설정(Value Field Settings)`** → 좌측 하단 **`표시 형식(Number Format)`** 버튼 클릭 후 서식 지정.
4. **[함정 4: 피벗 테이블 옵션 누락]:**
   - **지시문:** "레이블이 있는 셀 병합 및 가운데 맞춤, 빈 셀은 '**'로 표시하고, 행의 총합계는 표시하지 마시오."
   - 마우스 우클릭 → `피벗 테이블 옵션` 대화상자에서 해당 항목들을 정확히 설정해야 합니다.

### 2.3 표준 마우스 클릭 수행 절차
1. 원본 데이터 표 내부 셀 클릭 → `삽입` 탭 → `피벗 테이블` 클릭.
2. `기존 워크시트` 선택 → 문제에서 지정한 시작 셀(예: `A20`) 클릭 → `확인`.
3. 우측 피벗 테이블 필드 창에서 지시된 필드를 `행`, `열`, `값`, `필터` 영역으로 각각 드래그.
4. 값 필드의 집계 함수(평균, 개수 등) 변경 및 표시 형식 설정:
   - 값 영역 필드 클릭 → `값 필드 설정` → 함수 선택 → `표시 형식` 클릭 → 범주 지정 → `확인`.
5. 피벗 테이블 선택 상태에서 리본 메뉴 `디자인` 탭:
   - `보고서 레이아웃` → `개요 형식으로 표시` 또는 `테이블 형식으로 표시` 선택.
   - `총합계` → `열의 총합계만 설정` 또는 `행 및 열의 총합계 해제` 등 지시대로 설정.
6. 피벗 테이블 내부 마우스 우클릭 → `피벗 테이블 옵션`:
   - `레이아웃 및 서식` 탭: `레이블이 있는 셀 병합 및 가운데 맞춤` 체크, `빈 셀 표시`에 `**` 입력.
   - `요약 및 필터` 탭: `행 총합계 표시` 체크 해제.
   - `확인` 클릭.

## 3. 데이터 표 (Data Table - 민감도 가상 분석)

### 3.1 핵심 메커니즘 (Cơ chế vận hành)
- 공식의 1개 또는 2개 입력 변수가 다양하게 변할 때 계산 결과가 어떻게 달라지는지 행과 열의 교차 지점에 일괄 표시하는 도구입니다.

### 3.2 2대 감점 함정 (2 Bẫy trừ điểm chết)
- **[함정 1: 좌상단 교차 셀에 원본 수식 미연결 (2변수 표 0점 방지)]:**
  - 결과 표의 행 머리글과 열 머리글이 만나는 **좌측 상단 모퉁이 빈 셀에 반드시 `=`를 입력하고 원본 수식 결과 셀(예: `C5`)을 클릭**하여 연결해야 합니다. 이 연결이 없으면 표 전체가 빈칸이나 0으로 채워집니다.
- **[함정 2: 행 입력 셀과 열 입력 셀의 역지정]:**
  - **`행 입력 셀(Row input cell)`:** 결과 표에서 **가로(행) 방향**으로 나열된 변수 값이 원본 수식의 어느 입력 셀에 대입되는지 지정합니다.
  - **`열 입력 셀(Column input cell)`:** 결과 표에서 **세로(열) 방향**으로 나열된 변수 값이 원본 수식의 어느 입력 셀에 대입되는지 지정합니다.
  - 두 입력을 반대로 지정하면 결과 수치가 뒤바뀌어 0점 처리됩니다.

### 3.3 표준 마우스 클릭 수행 절차 (2변수 표 기준)
1. 결과 표의 좌측 상단 모퉁이 교차 셀 클릭 → `=` 입력 후 원본 수식 셀(예: `C5`) 클릭 → `Enter`.
2. 좌상단 수식 연결 셀과 행/열 변수 값, 결과 영역 전체를 마우스로 드래그 선택 (예: `E5:J12`).
3. `데이터` 탭 → `예측` 그룹 → `가상 분석` 드롭다운 → `데이터 표` 클릭.
4. `행 입력 셀`: 가로 방향 변수가 참조하는 원본 입력 셀(예: `C2`) 클릭.
5. `열 입력 셀`: 세로 방향 변수가 참조하는 원본 입력 셀(예: `C3`) 클릭.
6. `확인` 클릭.

### 4. 시나리오 (Scenario - kịch bản phân tích giả định)

### 4.1 핵심 메커니즘 (Cơ chế vận hành)
- 변동 가능한 여러 가정(예: 할인율 10% 인상, 5% 인하)에 따른 최종 결과 셀(예: 순이익)의 변동 내역을 별도의 '시나리오 요약' 시트에 일괄 비교 출력하는 도구입니다.

### 4.2 2대 감점 함정 (2 Bẫy trừ điểm chết)
1. **[함정 1: 이름 정의 누락 및 오타 (10점 전액 감점 / 0점 처리)]:**
   - **지시문:** "B10 셀의 이름은 '할인율', D15 셀의 이름은 '순매출'로 정의하시오."
   - 시나리오를 만들기 전에 셀 이름을 정의하지 않으면 요약 보고서에 `할인율` 대신 `$B$10` 셀 주소가 출력되어 **해당 문항 전체가 0점 처리**됩니다.
   - 이름 오타 수정 시에는 Name Box에 덮어쓰지 말고 반드시 **`Ctrl + F3`**를 눌러 `이름 관리자`에서 수정하거나 삭제 후 재정의해야 합니다.
2. **[함정 2: 시나리오 요약 시트 위치 이동 누락]:**
   - Excel은 시나리오 요약 시트를 기본적으로 현재 시트의 **왼쪽(앞)**에 삽입합니다.
   - 문제에서 "시나리오 요약 시트는 [분석작업-1] 시트의 바로 뒤(오른쪽)에 위치시키시오"라고 지시하면 시트 탭을 마우스로 드래그하여 반드시 뒤로 이동시켜야 합니다.

### 4.3 표준 마우스 클릭 수행 절차
1. 변동 셀(예: `B10`) 클릭 → 좌상단 이름 상자(Name Box) 클릭 → `할인율` 입력 후 **`Enter`**.
2. 결과 셀(예: `D15`) 클릭 → 이름 상자 클릭 → `순매출` 입력 후 **`Enter`**.
3. `데이터` 탭 → `예측` → `가상 분석` → `시나리오 관리자` 클릭.
4. `추가` 버튼 클릭:
   - 시나리오 1: `시나리오 이름`에 `할인율 인상` 입력, `변경 셀`이 `$B$10`인지 확인 → `확인` → 값(예: `0.15`) 입력 → `추가`.
   - 시나리오 2: `시나리오 이름`에 `할인율 인하` 입력 → `확인` → 값(예: `0.05`) 입력 → `확인`.
5. 시나리오 관리자 창에서 **`요약(Summary)`** 버튼 클릭.
6. 보고서 종류에서 `시나리오 요약` 선택, `결과 셀`이 `$D$15`인지 확인 → `확인`.
7. 생성된 시나리오 요약 시트 탭의 위치를 지시사항에 맞게 점검 (필요시 드래그 이동).

## 5. 목표값 찾기 (Goal Seek) & 데이터 통합 (Consolidate)

### 5.1 목표값 찾기 (Goal Seek)
- **[한국어 개념 및 메커니즘]:** 이미 알고 있는 최종 목표 결과를 얻기 위해 단 하나의 입력 변수 값이 얼마가 되어야 하는지 역산하는 도구입니다.
  *Tiếng Việt giải thích:* Tìm giá trị của biến số đầu vào cần thiết để công thức đạt được một con số kết quả mong muốn đã định trước.
- **[대화상자 3대 필수 인수]:**
  1. **`수식 셀(Set cell)`:** 계산 공식이 이미 입력되어 있는 결과 셀 (클릭 선택).
  2. **`찾는 값(To value)`:** 달성하고자 하는 목표 수치 (**반드시 키보드로 직접 숫자 입력, 셀 참조 불가!**).
  3. **`값을 바꿀 셀(By changing cell)`:** 목표를 위해 변경할 단 하나의 입력 변수 셀 (클릭 선택).
- **표준 절차:** `데이터` 탭 → `가상 분석` → `목표값 찾기` → 3개 항목 입력 → `확인`.

---

### 5.2 데이터 통합 (Consolidate)
- **[한국어 개념 및 메커니즘]:** 여러 시트나 여러 표에 분산된 동일 구조의 데이터를 하나의 표로 합산, 평균 등의 함수로 취합하는 도구입니다.
  *Tiếng Việt giải thích:* Hợp nhất số liệu từ nhiều bảng hoặc sheet khác nhau vào một bảng tổng hợp duy nhất.
- **[2대 필수 체크 옵션]:**
  - **`사용할 레이블(Use labels in)`**에서 **`첫 행(Top row)`**과 **`왼쪽 열(Left column)`**의 두 체크 상자를 **모두 체크**해야 열 머리글과 행 머리글이 일치하는 데이터끼리 정확히 통합됩니다.
- **표준 절차:**
  1. 결과가 표시될 빈 표 전체 영역 드래그 선택.
  2. `데이터` 탭 → `데이터 도구` → `통합` 클릭.
  3. `함수`: 합계, 평균 등 지시된 함수 선택.
  4. `참조`: 원본 표 범위 드래그 선택 → `추가` 버튼 클릭 (여러 표 반복 추가).
  5. `사용할 레이블`의 **`첫 행`**과 **`왼쪽 열`** 둘 다 체크 → `확인`.

## 6. 기타작업 — 매크로 자동화 (Macro 10점 [2문항 × 5점])

### 6.1 핵심 메커니즘 및 배점 원칙
- 반복되는 작업 절차(서식 적용, 합계 계산 등)를 기록하여 단추(Button) 또는 도형(Shape)에 연결하고, 클릭 한 번으로 실행되도록 구현합니다.

### 6.2 KCCI 4대 감점 함정 (4 Bẫy trừ điểm chết)
1. **[함정 1: 기록 전 빈 셀 미선택 (치명적 오류)]:**
   - 데이터 셀(예: `A3`)이 선택된 상태에서 매크로 기록을 시작하면 해당 셀을 클릭하는 동작이 기록되지 않습니다. 빈 셀을 클릭하고 매크로 단추를 누르면 엉뚱한 위치에 서식이 적용되어 감점됩니다.
   - **절대 규칙:** **반드시 데이터 표 외부의 임의의 빈 셀을 클릭한 후 `매크로 기록`을 시작하십시오.**
2. **[함정 2: 단추/도형 생성 시 Alt 키 미사용]:**
   - **지시문:** "[E12:F13] 영역에 단추를 생성하고..."
   - 마우스로 임의로 그리면 셀 눈금선에 정확히 밀착되지 않아 감점됩니다. **반드시 키보드 `Alt` 키를 누른 채로 드래그하여 셀 경계선에 자석처럼 스냅(Snap to Grid)되도록 생성**해야 합니다.
3. **[함정 3: 단추 텍스트 오타 및 띄어쓰기 오류]:**
   - 텍스트에 오타나 불필요한 공백이 있으면 5점 전액 감점됩니다.
4. **[함정 4: 개발 도구 리본 탭 활성화]:**
   - `개발 도구` 탭이 안 보일 경우: `파일` → `옵션` → `리본 사용자 지정` → 우측 목록에서 `개발 도구` 체크 → `확인`. (또는 `보기` 탭의 `매크로` 메뉴 사용 가능).

### 6.3 표준 마우스 클릭 수행 절차
#### [매크로 기록 절차]
1. 표 외부의 빈 셀 클릭.
2. `개발 도구` 탭 → `매크로 기록` 클릭.
3. 문제에서 지정한 `매크로 이름`(예: `서식적용`) 입력 → `확인` (이후 모든 동작이 기록됨).
4. 대상 영역(예: `A3:E3`) 드래그 선택 → 지시된 서식(채우기 색, 글꼴 등) 지정.
5. 표 외부 빈 셀 클릭 (선택 해제).
6. `개발 도구` 탭 → **`기록 중지`** 클릭 (중지 누락 주의!).

#### [단추 생성 및 매크로 지정 절차]
1. `개발 도구` → `삽입` → 양식 컨트롤의 `단추(Button)` 클릭 (도형일 경우 `삽입` → `도형`).
2. **`Alt` 키를 누른 상태**로 지정 영역(예: `G2:H3`)을 정확히 드래그.
3. 마우스를 놓으면 나타나는 `매크로 지정` 창에서 방금 기록한 매크로(`서식적용`) 선택 → `확인`.
4. 단추 위 마우스 우클릭 → `텍스트 편집` 클릭 → 기존 텍스트 삭제 후 지시된 텍스트(`서식적용`) 입력.
5. 빈 셀을 클릭하여 편집 완료 후, 단추를 클릭하여 매크로가 정상 작동하는지 테스트.

## 7. 기타작업 — 차트 편집 (Chart 10점 [5문항 × 2점])

### 7.1 절대 원칙 (Absolute Rule)
- **"기존에 제공된 차트를 수정하여 완성해야 하며, 차트를 새로 작성하면 0점 처리됩니다."**

### 7.2 실전 빈출 5대 차트 편집 기법
1. **[데이터 계열 추가 및 삭제]:**
   - 삭제: 차트 안에서 삭제할 막대나 꺾은선을 직접 클릭 → `Delete` 키 입력.
   - 추가: 원본 표에서 추가할 범위를 드래그 선택 → `Ctrl + C` → 차트 클릭 → `Ctrl + V`.
2. **[보조 축 지정 및 혼합형 차트 변경 (Combo Chart)]:**
   - 차트 우클릭 → `차트 종류 변경` → 좌측 하단 `혼합` 선택.
   - 지시된 계열의 차트 종류를 `표식이 있는 꺾은선형`으로 변경하고, 우측의 **`보조 축`** 체크 상자에 체크 → `확인`.
3. **[단일 요소 데이터 레이블 추가]:**
   - 특정 하나의 막대에만 레이블을 추가하려면: 해당 막대를 클릭(전체 선택됨) → **1초 후 해당 막대를 다시 한 번 클릭(단일 요소만 선택됨)** → 마우스 우클릭 → `데이터 레이블 추가` 클릭.
4. **[축 서식 눈금 조정 (최소값, 최대값, 주 단위)]:**
   - 세로 축(또는 보조 세로 축)의 숫자를 더블 클릭 → 우측 `축 서식` 창 열림.
   - `축 옵션`에서 `최소값`, `최대값`, **`주 단위(Major Unit)`**를 지시된 수치로 직접 입력.
5. **[차트 제목 셀 연동]:**
   - 차트 우측 상단 `+` 버튼 → `차트 제목` 체크.
   - 차트 제목 상자의 외곽 테두리를 클릭(커서가 깜빡이지 않도록 선택) → 상단 **수식 입력줄(Formula Bar)을 클릭** → `=A1` 입력 후 `Enter`.
