# 90 — 실전 모의고사 및 실기 시험장 오류 복구 전략 (Chiến lược giải đề mô phỏng & Phục hồi lỗi phòng thi)

> **시험 출제 기준 (Tiêu chuẩn đề thi):** 대한상공회의소 (KORCHAM) 컴퓨터활용능력 2급 실기 · 출제기준 2024–2026 · Microsoft Office LTSC 2021
> **시험 시간 및 합격 기준:** 정규 시험 시간 **40분** · 총점 100점 만점에 **70점 이상 합격**
> **채점 원칙 (Scoring Principles):** 컴퓨터 자동 채점 프로그램에 의한 이진 채점 (계산작업 8점/0점, 분석작업 10점/0점, 매크로 5점/0점 등 부분점수 극히 제한)
> **학습 프레임워크:** 한국어 지시문 분석 (Korean Directive) → 40분 시간 배정 (Time Budget) → 영역별 실전 루틴 (Execution) → 긴급 오류 복구 (Error Recovery) → 최종 제출 검증 (Checklist)

## 1. 실전 풀이 순서의 최적화 (Chiến lược thứ tự làm bài tối ưu trong 40 phút)

실전 시험에서는 문제지의 번호 순서(1번 → 2번 → 3번 → 4번)대로 문제를 풀어서는 안 됩니다.

- **[전략적 문제 해결 순서]:**
  1. **1단계 (0~10분): 기본작업-2 (10점) & 기본작업-3 (5점)**
     - 점수 획득이 가장 확실하고 쉬운 셀 서식(10점)과 조건부서식/고급필터(5점)를 먼저 해결하여 15점을 확보합니다.
     - **주의: 기본작업-1(자료입력 5점)은 시간이 많이 걸리므로 절대 처음에 하지 않고 건너뜁니다.**
  2. **2단계 (10~18분): 분석작업 2문항 (20점)**
     - 부분합(정렬 선행), 피벗 테이블(시작 셀 및 값 필드 서식), 데이터 표, 시나리오(이름 정의)를 집중 수행하여 20점을 확보합니다.
  3. **3단계 (18~26분): 기타작업 (20점)**
     - 매크로(10점, 빈 셀 클릭 후 기록 시작, Alt 키 스냅)와 차트(10점, 기존 차트 편집)를 차례로 완성합니다.
  4. **4단계 (26~36분): 계산작업 (40점)**
     - 5문항 중 자신이 가장 자신 있는 3~4문항(24~32점)을 먼저 풀어 확실하게 정답을 맞힙니다. 1문항에 3분 이상 막히면 즉시 다음 문제로 넘어갑니다.
  5. **5단계 (36~40분): 기본작업-1 (자료입력 5점) & 최종 저장 검토**
     - 남은 시간에 기본작업-1의 데이터를 타이핑하고, 전체 시트의 수식/오류/저장 상태(`Ctrl + S`)를 최종 점검합니다.

*Tiếng Việt giải thích:* Nếu làm theo thứ tự từ câu 1 (ngồi gõ phím cả bảng dữ liệu 5 điểm mất 8-10 phút), thí sinh sẽ bị cuốn vào tâm lý hoảng loạn và thiếu giờ làm phần tính toán. Thứ tự vàng: `기본작업-2,3 (15đ)` → `분석작업 (20đ)` → `기타작업 (20đ)` → `계산작업 (40đ)` → `기본작업-1 (5đ) & Kiểm tra lưu bài`.

## 3. 시험 시작 직후 3분 점검 루틴 (Initial Setup Routine)

수험표와 좌석 번호를 확인하고 모니터에 시험지가 배부되면 감독관 지시에 따라 아래 4가지를 3분 내에 점검합니다:

1. **[문제 파일 및 워크시트 구조 확인]:**
   - 문제 파일(예: `OA\수험번호.xlsm` 또는 `.xlsx`)이 올바르게 열렸는지 확인.
   - 하단 시트 탭 이름([기본작업-1], [기본작업-2], [계산작업], [분석작업-1], [분석작업-2], [기타작업-1], [기타작업-2])이 온전히 존재하는지 확인.
2. **[리본 메뉴 개발 도구 탭 노출 확인]:**
   - 매크로 작성을 위해 상단 리본 메뉴에 `개발 도구` 탭이 있는지 확인.
   - 없을 경우: `파일` → `옵션` → `리본 사용자 지정` → 우측 `개발 도구` 체크박스 체크 후 `확인`.
3. **[Excel 옵션 계산 모드 확인]:**
   - `수식` 탭 → `계산 옵션`이 **`자동(Automatic)`**으로 설정되어 있는지 확인 (수동으로 되어 있으면 수식 결과가 즉시 갱신되지 않음).
4. **[첫 저장 및 단축키 손 풀기]:**
   - 키보드의 **`Ctrl + S`**를 눌러 정상 저장되는지 확인하고, 키보드 NumLock 상태 및 한/영 전환 상태 점검.

## 4. 한국어 지시문 구문 분석 프레임워크 (Directive Parsing Template)

KCCI 실기 시험 지시문은 복잡한 문장으로 서술되지만, 항상 아래 5개 성분으로 분해하여 해석하면 실수를 0으로 줄일 수 있습니다:

$$\text{Target (대상 범위)} \rightarrow \text{Operation (실행 도구)} \rightarrow \text{Condition (조건 규칙)} \rightarrow \text{Output (출력 위치)} \rightarrow \text{Constraint (제한 및 지정 함수)}$$

### 실전 예시 분석
- **[지시문 원문]:**
  > "[기본작업-3] 시트에서 [A3:G20] 영역에 대해 부서가 '영업부'이거나 총점이 80 이상인 데이터를 고급 필터를 사용하여 조건은 [A23:B25], 복사 위치는 [A28] 셀부터 표시하시오. (OR 함수 사용)"
- **[구문 분해 (Parsing)]:**
  - **Target (대상 범위):** `A3:G20` (목록 범위)
  - **Operation (실행 도구):** `데이터` → `고급` (고급 필터)
  - **Condition (조건 규칙):** `부서="영업부"` OR `총점>=80` (수식 조건이므로 조건 머리글은 `조건`, 서로 다른 행에 배치하거나 OR 수식 작성)
  - **Output (출력 위치):** `A28`부터
  - **Constraint (제한 사항):** `OR` 함수 사용 필수, `다른 장소에 복사` 선택

## 5. 영역별 실전 실행 루틴 (Standard Execution Routines)

### 5.1 계산작업 7단계 루틴 (Calculation Routine)
1. 문제에서 제시한 **지정 함수 목록**을 확인 (예: `IF`, `INDEX`, `MATCH`).
2. 첫 번째 결과 셀 클릭 후 `=` 입력하고 가장 바깥쪽 함수부터 작성 시작.
3. 기준표 참조 시 주저 없이 **`F4`**를 눌러 `$A$10:$D$20` 절대참조 적용.
4. 코드/문자열 검색 시 정확 일치 옵션 `0(FALSE)` 입력 확인.
5. 첫 결과 셀에서 `Enter` 입력 후 비정상적인 값이나 오류(`#N/A` 등)가 없는지 육안 검증.
6. 채우기 핸들을 더블클릭하거나 아래로 드래그하여 수식 복사.
7. **가장 마지막 행의 셀을 클릭하고 `F2` 키를 눌러 참조 범위가 고정되어 있는지 시각적 확인.**

### 5.2 분석작업 3단계 핵심 수칙
- **부분합:** 무조건 `정렬` 먼저 수행 → 2차 부분합 시 `새로운 값으로 대치` 해제.
- **피벗 테이블:** 문제에서 지정한 `시작 셀(A20)` 정확히 클릭 → 숫자 서식은 `값 필드 설정 → 표시 형식` 경로로 변경.
- **데이터 표:** 2변수 표 좌상단 교차 셀에 `=수식셀` 연결 필수.
- **시나리오:** 요약 보고서 만들기 전에 반드시 Name Box 또는 `Ctrl + F3`로 변경 셀/결과 셀 이름 정의.

### 5.3 기타작업 (차트/매크로) 3단계 핵심 수칙
- **차트:** 기존 차트를 절대로 삭제하지 않고 편집 (혼합형 축 변경 시 `보조 축` 체크, 데이터 레이블은 더블 클릭으로 단일 요소만 선택).
- **매크로:** 반드시 **표 외부의 빈 셀을 먼저 클릭**한 후 `매크로 기록` 시작 → 단추/도형 생성 시 **`Alt` 키 누른 채 드래그 밀착** → 도형 텍스트 오타 확인 → 반드시 `기록 중지` 클릭.

## 6. 시험장 오류 긴급 복구 매뉴얼 (Emergency Error Recovery)

실전에서 예기치 않은 오류가 발생했을 때 당황하지 않고 30초 내에 원상 복구하는 절차입니다:

### 6.1 수식 오류 코드 긴급 대응
| 오류 코드 | 주요 발생 원인 | 긴급 조치 방법 (Quick Fix) |
|---|---|---|
| **`#N/A`** | VLOOKUP/MATCH에서 값을 찾지 못함, 참조표 범위 F4 누락 | 1. 참조 영역에 `$A$10:$D$20` 절대참조가 걸려있는지 확인. — 2. 정확 일치 옵션 `0`이 누락되었는지 확인. — 3. 문제에 `IFERROR` 지시가 있는지 확인하여 감싸기. |
| **`#VALUE!`** | 인수 데이터 형식 불일치 (텍스트를 숫자로 연산) | 1. MID/LEFT 추출 숫자를 비교할 때 따옴표 `="1"`를 붙였는지 확인. — 2. SUMIFS/AVERAGEIFS의 합계 범위와 조건 범위 크기가 일치하는지 확인. |
| **`#REF!`** | 참조하던 셀이나 행/열이 삭제되어 참조 무효화됨 | 1. `Ctrl + Z`를 즉시 눌러 삭제 동작 취소. — 2. 수식 내부의 참조 셀 주소를 문제지의 정상 셀로 재입력. |
| **`#DIV/0!`** | 0으로 나누거나 빈 셀로 나눔 | 분모가 0이 되는 조건이 있는지 확인하고 IFERROR로 예외 처리. |
| **`#NAME?`** | 함수 이름 오타 또는 큰따옴표 누락 | 함수 철자(예: VLOOKUP을 VLOOKP로 입력 등) 및 문자열 양쪽 따옴표(`"영업부"`) 확인. |

### 6.2 고급 필터 결과 오류 긴급 대응
- **[증상 1: 필터 결과가 전혀 나오지 않고 머리글만 복사됨]:**
  - 원인: 조건 영역의 논리 오류. 수식 조건인데 머리글을 원본과 똑같이 썼거나, AND 조건을 서로 다른 행에 적음.
  - 조치: 수식 조건 머리글을 `조건`으로 수정하고, 조건식을 단일 셀에 바르게 입력.
- **[증상 2: 필터 결과에 원본 표의 모든 열이 추출됨]:**
  - 원인: 고급 필터 대화상자의 `복사 위치`에 특정 열 머리글 범위를 지정하지 않고 단일 셀(`A20`)만 클릭함.
  - 조치: 잘못 추출된 범위를 드래그하여 지우고(`Delete`), 대상 머리글을 미리 복사한 뒤 `복사 위치`에 해당 머리글 범위 전체를 지정하여 재실행.

### 6.3 피벗 테이블 긴급 대응
- **[증상: 새로고침하거나 수정했더니 셀 서식이 초기화됨]:**
  - 원인: `Ctrl + 1`로 셀 서식을 지정함.
  - 조치: 피벗 필드 목록의 값 영역에서 해당 필드 클릭 → `값 필드 설정` → `표시 형식` 버튼 클릭하여 서식 재지정.

### 6.4 매크로 긴급 대응
- **[증상: 매크로 단추를 눌렀는데 엉뚱한 셀에 서식이 칠해짐]:**
  - 원인: 매크로 기록 시작 전 빈 셀을 누르지 않아 셀 선택 동작이 누락됨.
  - 조치: `개발 도구` → `매크로` 클릭 → 해당 매크로 선택 후 `삭제` → 표 외부 빈 셀 클릭 → `매크로 기록` 재수행 → 단추 우클릭 `매크로 지정`에서 재연결.

## 7. 최종 3분 제출 전 마감 검토 체크리스트 (Final 3-Minute Routine)

시험 종료 3분 전 알림이 울리면 새로운 문제 풀이를 즉시 중단하고 다음 6개 항목을 순서대로 점검하십시오:

1. **[강제 저장 실행 (Ctrl + S)]:**
   - 가장 먼저 `Ctrl + S`를 눌러 지금까지 작업한 내용을 안전하게 디스크에 저장합니다.
2. **[빈 출력 셀 스캔 (Missing Output)]:**
   - 각 작업 시트([기본작업], [계산작업], [분석작업], [기타작업])를 탭별로 빠르게 클릭하며 결과를 입력해야 할 셀이 빈칸으로 방치되어 있지 않은지 스캔합니다.
3. **[수식 바 오류 코드 확인]:**
   - 계산작업 시트에서 `#N/A`, `#VALUE!`, `#REF!` 등의 오류 코드가 화면에 노출되어 있는지 확인합니다.
4. **[부분합 윤곽 및 정렬 확인]:**
   - 부분합 표의 그룹별 소계 및 총계가 논리적으로 맞는지 확인합니다.
5. **[차트 및 매크로 단추 위치 확인]:**
   - 차트가 문제지 그림과 동일한 형태인지, 매크로 단추가 지정 셀 범위(`Alt` 스냅) 안에 단정하게 들어있는지 확인합니다.
6. **[마지막 저장 및 프로그램 정상 종료 대기]:**
   - 다시 한 번 `Ctrl + S`를 누르고 손을 키보드에서 뗀 후 감독관의 종료 지시를 기다립니다.

## 8. 실기 오답 원인 분류 체계 (Exam Error Taxonomy)

모의고사 연습 후 틀린 문제를 단순히 "실수"로 치부하지 않고 원인을 정확히 분류하여 취약점을 제거합니다:

```text
오답 원인 (Taxonomy)
├── 1. Knowledge (지식 결함): 함수 구문이나 분석 도구의 옵션 의미 자체를 모름 → 해당 이론 문서 복습
├── 2. Navigation (메뉴 탐색 지연): 리본 메뉴나 대화상자 위치를 못 찾아 시간을 낭비함 → 경로 암기
├── 3. Reference (참조 오류): F4 절대참조($) 누락 또는 행/열 혼합참조 방향 착오 → F4 습관화
├── 4. Condition (조건 논리 오류): AND/OR 배치 착오, 부등호 오류, 문자열 따옴표 누락 → 조건 구문 재훈련
├── 5. Output (출력 규격 위반): 시작 셀 위치 오류, 표시 형식 생략, 단추 텍스트 오타 → 지시문 꼼꼼 점검
├── 6. Time (시간 배분 실패): 계산 1문제에 5분 이상 매달려 다른 쉬운 문제 누락 → 3분 패스 룰 적용
└── 7. Recovery (복구 실패): 오류 발생 시 Ctrl+Z나 원복 절차를 몰라 백지화됨 → 긴급 복구 매뉴얼 숙지
```
