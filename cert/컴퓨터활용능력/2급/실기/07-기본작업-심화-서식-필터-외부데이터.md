# 07 — 기본작업 심화 — 서식·필터·외부데이터 (Cẩm nang chuyên sâu thao tác cơ bản)

> **시험 출제 기준 (Tiêu chuẩn đề thi):** 대한상공회의소 (KORCHAM) 컴퓨터활용능력 2급 실기 · 출제기준 2024–2026 · Microsoft Office LTSC 2021  
> **배점 구조 및 채점 원칙 (Cơ cấu điểm số):** 기본작업 총 **20점** (기본작업-1 자료입력 5점 + 기본작업-2 셀 서식 10점 [5문항 × 2점, 부분점수 인정] + 기본작업-3 조건부서식/고급필터 5점 [단일 배점, 부분점수 없음])  
> **학습 프레임워크 (Khung đào tạo chuẩn):** 한국어 문제 지시문 (Korean Directive) → 핵심 메커니즘 (Mechanism) → KCCI 감점 함정 (Traps) → 마우스 클릭 절차 (Action) → 검증 루틴 (Verification)

## 0. 배점 구조 및 0점 방지 전략 (Cơ cấu 20 điểm phần cơ bản và chiến lược thời gian)

- **[기본작업-1 자료 입력 (5점)]:** 문제지의 데이터를 오타 없이 직접 타이핑하여 입력합니다. 오타, 띄어쓰기, 영문 대소문자 오류 1개당 감점되며 시간이 많이 소요되므로 **반드시 40분 시험의 가장 마지막에 작성**하는 것이 정석 전략입니다.
  *Tiếng Việt giải thích:* Nhập liệu thô 5 điểm rất tốn thời gian và dễ sai sót chính tả. Tuyệt đối không ngồi gõ dữ liệu ngay từ đầu; hãy để câu này lại làm sau cùng trong 40 phút thi.
- **[기본작업-2 셀 서식 편집 (10점 = 5문항 × 2점)]:** 각 문항당 2점씩 독립적인 부분 점수가 주어집니다. 사용자 지정 서식, 이름 정의, 메모 삽입 및 자동 크기, 병합 및 맞춤, 테두리 설정으로 구성됩니다.
  *Tiếng Việt giải thích:* Định dạng ô gồm 5 câu nhỏ (2đ/câu), có điểm thành phần riêng biệt. Đây là mỏ điểm dễ lấy trọn 10 điểm nhất nếu nắm chắc thao tác.
- **[기본작업-3 조건부 서식 / 고급 필터 / 텍스트 나누기 / 외부 데이터 (5점)]:** 1문항 단일 5점이며 **부분 점수가 전혀 없습니다**. 수식 기호 하나, 열 고정(`$`) 하나만 틀려도 5점 전액 감점됩니다.
  *Tiếng Việt giải thích:* Câu 3 trị giá 5 điểm nhưng không có điểm thành phần (chỉ có 5 điểm hoặc 0 điểm).

## 1. 사용자 지정 표시 형식 (Custom Number Format)

### 1.1 핵심 메커니즘 (Cơ chế vận hành)
- 셀에 저장된 실제 데이터 값(원천값)을 전혀 변경하지 않고, 화면에 보이는 시각적 표시 형태만 변경하는 서식 지정 기능입니다.

### 1.2 4개 섹션 표준 구조
사용자 지정 서식 코드는 세미콜론(`;`)으로 최대 4개 구역으로 구분됩니다:
```text
양수 서식 ; 음수 서식 ; 0 서식 ; 텍스트 서식
```
- **[대표 종합 예시]:** `#,##0원;[빨강]-#,##0원;"-";@ "귀하"`
  - 양수 입력 시 (예: 1000): `1,000원` 표시.
  - 음수 입력 시 (예: -1000): 빨강 글꼴로 `-1,000원` 표시.
  - 0 입력 시: 하이픈 `-` 표시.
  - 텍스트 입력 시 (예: 홍길동): `홍길동 귀하` 표시.

### 1.3 핵심 서식 코드 기호
| 코드 기호 | 역할 및 표시 규칙 | 입력 예시 (값: 15) | 화면 표시 결과 |
|---|---|---|---|
| `0` | 유효하지 않은 0도 강제 표시 (자릿수 채움) | `000` | `015` |
| `#` | 유효한 자릿수만 표시 (의미 없는 0은 숨김) | `###` | `15` |
| `?` | 0 대신 공백을 두어 소수점 위치를 정렬 | `?.?` | `15. ` |
| `,` | 천 단위 구분 기호 (맨 끝에 두면 1,000단위 생략) | `#,##0,` | `0` (천원 단위 절삭) |
| `@` | 입력된 텍스트 문자열이 들어갈 자리 | `@ "팀장"` (홍길동) | `홍길동 팀장` |

### 1.4 KCCI 3대 출제 함정 (3 Bẫy đề thi thường gặp)
1. **[천 원 / 백만 원 단위 생략 (맨 뒤 쉼표)]:**
   - **지시문:** "숫자 1,250,000을 1,250으로 표시하고 뒤에 '천원'을 붙이시오."
   - 서식 코드: `#,##0, "천원"` (맨 뒤에 쉼표 `,` 1개가 위치).
   - 백만 원 단위 생략(6자리 절삭): `#,##0,, "백만원"` (맨 뒤에 쉼표 2개).
2. **[색상 및 조건식의 위치 규칙]:**
   - 색상(`[파랑]`, `[빨강]`)과 조건(`[>=1000]`)은 대괄호로 묶으며, **반드시 숫자 서식 코드보다 앞에 위치**해야 합니다: `[파랑][>=1000]#,##0;[빨강][<500]#,##0;#,##0`.
3. **[요일 및 날짜 서식 코드]:**
   - 연/월/일: `yyyy-mm-dd`
   - **요일 표시 코드:**
     - `aaa`: 한 글자 한글 요일 (예: `수`)
     - `aaaa`: 전체 한글 요일 (예: `수요일`)
     - `ddd`: 영문 약어 요일 (예: `Wed`)
     - `dddd`: 영문 전체 요일 (예: `Wednesday`)
   - 지시문이 "2026-10-15 (목)" 형식일 때 표준 코드: `yyyy-mm-dd (aaa)`.

### 1.5 표준 마우스 클릭 수행 절차
1. 대상 셀 범위 드래그 선택.
2. 단축키 **`Ctrl + 1`** 입력하여 `셀 서식` 창 열기.
3. `표시 형식` 탭 → 좌측 하단 `사용자 지정` 범주 클릭.
4. `형식(T)` 입력란에 서식 코드 직접 입력 → `확인`.

## 2. 기본작업-2 셀 서식 심화 편집 기법

### 2.1 셀 병합 vs 선택 영역의 가운데로 (Merge vs Center Across Selection)
- **`셀 병합하고 가운데 맞춤(Merge & Center)`:**
  - 물리적으로 여러 셀을 하나로 합치고 내용을 가운데 정렬합니다 (`홈` 탭의 도구 아이콘 클릭).
- **`선택 영역의 가운데로(Center Across Selection)`:**
  - **셀들을 절대로 합치지 않으며**, 셀은 각각 독립되어 있으나 첫 번째 셀의 내용이 선택 영역 전체의 중앙에 떠 있는 것처럼 표시됩니다.
  - **표준 절차:** 범위 선택 → `Ctrl + 1` → `맞춤` 탭 → `가로` 목록에서 **`선택 영역의 가운데로`** 선택 → `확인`.
  - **KCCI 함정:** 지시문이 "선택 영역의 가운데로"인데 병합 버튼을 누르면 2점 감점됩니다.

## 3. 조건부 서식 (Conditional Formatting - 수식 기반 행 전체 서식)

### 3.1 핵심 메커니즘 (Cơ chế vận hành)
- 지정한 수식의 결과가 참(TRUE)인 행 또는 셀에 대해 자동으로 채우기 색, 글꼴 스타일(굵게), 글꼴 색 등의 서식을 실시간 적용합니다.

### 3.2 2대 절대 불변 수식 작성 원칙
1. **[원칙 1: 범위 지정 시 열 머리글(Header) 절대 제외]:**
   - 데이터가 시작되는 첫 번째 행부터 마지막 행까지 순수 데이터 영역만 드래그 선택해야 합니다 (예: `A3:E15`). 머리글을 포함하면 첫 행의 판단 기준이 1행씩 밀려 전체 0점 처리됩니다.
2. **[원칙 2: 행 전체 서식 적용 시 열 고정 혼합참조(`=$C3`) 필수 적용]:**
   - 기준 열 앞에 반드시 달러 기호(`$`)를 붙여 열을 고정해야 행의 모든 열(A, B, C, D...)이 동일한 기준 열의 값을 참조하여 한 행 전체가 동시에 같은 서식으로 변경됩니다.
   - 행 번호 앞에는 `$`를 붙이지 않아야(상대참조) 아래 행으로 내려가면서 순차적으로 각 행을 개별 판별합니다 (`=$C3>=80`).
   - 만약 `$C$3`으로 절대참조하면 모든 행이 오직 C3 셀 하나만 바라보므로 표 전체가 한꺼번에 색칠되거나 아무것도 칠해지지 않아 0점 처리됩니다.

### 3.3 실전 빈출 수식 패턴
1. **[AND 조건 (동시 만족)]:**
   ```excel
   =AND($B3="기획부", $D3>=90)
   ```
2. **[OR 조건 (하나 이상 만족)]:**
   ```excel
   =OR($B3="인사부", $B3="총무부")
   ```
3. **[통계 / 텍스트 함수 결합]:**
   - 표 전체 평균 이상인 행:
     ```excel
     =$C3>=AVERAGE($C$3:$C$15)
     ```
     *(주의: AVERAGE 함수 내부의 참조 범위는 반드시 `$C$3:$C$15` 절대참조로 고정해야 함).*
   - 사원코드의 첫 글자가 "A"인 행:
     ```excel
     =LEFT($A3, 1)="A"
     ```

### 3.4 표준 마우스 클릭 수행 절차
1. 머리글을 제외한 순수 데이터 영역 드래그 선택 (예: `A3:F18`).
2. `홈` 탭 → 스타일 그룹의 `조건부 서식` 클릭 → `새 규칙` 클릭.
3. 규칙 유형 목록 맨 아래의 **`▶ 수식을 사용하여 서식을 지정할 셀 결정`** 선택.
4. `다음 수식이 참인 값의 서식 지정` 입력 상자에 공식 입력 (예: `=AND($B3="영업", $E3>=500)`).
5. 우측 하단 `서식` 버튼 클릭 → `글꼴` 탭(굵게, 색) 또는 `채우기` 탭(배경색) 지정 → `확인`.
6. 새 서식 규칙 창에서 `확인` 클릭.

## 4. 고급 필터 (Advanced Filter - 직접 조건 vs 수식 조건)

### 4.1 핵심 메커니즘 (Cơ chế vận hành)
- 복잡한 다중 조건을 별도의 조건 영역(Criteria Range)에 사전 정의한 후, 조건에 일치하는 행을 원본 위치에서 필터링하거나 새로운 영역으로 복사 추출하는 도구입니다.

### 4.2 조건 작성 2대 방식 비교 (Direct vs Formula Criteria)
| 비교 항목 | 직접 조건 (Direct Criteria) | 수식 조건 (Formula Criteria) |
|---|---|---|
| **출제 형태** | 텍스트 단순 일치 또는 단순 숫자 부등호 | 함수(AVERAGE, LEFT, OR 등)를 사용하는 공식 |
| **조건 머리글 규칙** | **원본 표의 열 머리글과 100% 동일하게 작성** | **원본 열 머리글과 반드시 달라야 함 (보통 `조건` 입력)** |
| **조건값 입력 방식** | 순수 텍스트 또는 연산자 직접 입력 (`영업부`, `>=80`) | `=`로 시작하는 논리 수식 (`=C3>=AVERAGE($C$3:$C$20)`) |

### 4.3 KCCI 3대 감점 함정 (3 Bẫy trừ điểm chết)
1. **[함정 1: 수식 조건 작성 시 원본 열 머리글 명칭 사용 (5점 감점 / 0점 처리)]:**
   - 수식 조건(`=C3>=AVERAGE(...)`)을 작성하면서 조건 머리글에 원본과 동일한 `점수`를 입력하면 필터링 엔진이 충돌하여 엉뚱한 결과가 나오며 0점 처리됩니다. 수식 조건 머리글은 반드시 `조건`으로 작성하십시오.
2. **[함정 2: AND(동일 행)와 OR(다른 행) 배치 오류]:**
   - **AND 조건 (모두 만족):** 조건값들을 **동일한 행**에 나란히 배치.
   - **OR 조건 (하나라도 만족):** 조건값들을 **서로 다른 행에 계단식(대각선)**으로 배치.
3. **[함정 3: 특정 열 추출 시 대상 머리글 사전 복사 누락]:**
   - **지시문:** "결과는 '성명', '부서', '급여' 열만 [A20] 셀부터 표시하시오."
   - 고급 필터 창을 열기 전에 해당 3개 열의 머리글을 복사하여 `[A20:C20]`에 미리 붙여넣어야 합니다. 필터 대화상자의 `복사 위치`에 해당 머리글 영역(`$A$20:$C$20`)을 드래그 지정하지 않고 `A20` 단일 셀만 지정하면 표의 모든 열이 추출되어 오답 처리됩니다.

### 4.4 표준 마우스 클릭 수행 절차 (특정 열 추출 기준)
1. 추출할 열 머리글들을 원본 표에서 드래그하여 `Ctrl + C` 복사 후 대상 위치(예: `A20:C20`)에 붙여넣기.
2. 조건 영역 설정 (예: `G2:G3`):
   - `G2` 셀에 `조건` 입력.
   - `G3` 셀에 수식 입력 (예: `=C3>=AVERAGE($C$3:$C$15)`).
3. 원본 데이터 표 내부 임의의 셀 클릭.
4. `데이터` 탭 → `정렬 및 필터` 그룹 → `고급` 클릭.
5. 고급 필터 대화상자 설정:
   - 결과: **`다른 장소에 복사`** 라디오 버튼 체크.
   - `목록 범위(List range)`: 머리글을 포함한 원본 표 전체 (예: `$A$2:$F$15`).
   - `조건 범위(Criteria range)`: 조건 영역 (예: `$G$2:$G$3`).
   - `복사 위치(Copy to)`: 1단계에서 미리 붙여넣은 대상 머리글 범위 (예: `$A$20:$C$20`).
6. `확인` 클릭.

## 5. 텍스트 나누기 (Text to Columns) & 외부 데이터 가져오기

### 5.1 텍스트 나누기 (Text to Columns)
- **[한국어 개념 및 메커니즘]:** 하나의 열에 특정 구분 기호(쉼표, 공백, 탭, 세미콜론)로 결합된 텍스트 데이터를 여러 개의 개별 열로 자동 분리하는 기능입니다.
- **[표준 절차]:**
  1. 분리할 데이터 열 드래그 선택 → `데이터` 탭 → `데이터 도구` → `텍스트 나누기` 클릭.
  2. `구분 기호로 분리됨(Delimited)` 선택 → `다음`.
  3. 문제에서 지정한 구분 기호(쉼표, 공백 등)에 체크 (기타의 경우 직접 입력) → `다음`.
  4. (특정 열을 제외하라는 지시가 있는 경우) 해당 열 미리보기에서 클릭 후 **`열 가져오지 않음(건너뜀)`** 선택.
  5. `마침` 클릭.

---

### 5.2 텍스트 / CSV 외부 데이터 가져오기 (External Data)
- **[지시문 예시]:** "[성적.txt] 외부 데이터 파일을 열고 [A3] 셀부터 표시하시오."
- **[표준 절차]:**
  1. `데이터` 탭 → `데이터 가져오기` 또는 `텍스트/CSV에서` 클릭.
  2. 문제에서 지정한 텍스트 파일 선택 후 `가져오기`.
  3. 미리보기 창에서 구분 기호 확인 후 우측 하단 `로드` 옆의 화살표 클릭 → `다음으로 로드...` 선택.
  4. 데이터 가져오기 창에서 `기존 워크시트` 선택 후 지정된 시작 셀(예: `=$A$3`) 클릭 → `확인`.
