# 03 — 실기 3: 분석작업 (Phân tích dữ liệu, Báo cáo Pivot & Quản trị What-If)

> **시험 출제기준:** 대한상공회의소 컴퓨터활용능력 2급 실기 · 2024–2026 출제기준 · Microsoft Excel 2021 LTSC  
> **과목 배점 및 문항 구성:** 총 20점 배점 (2문항 출제, 문항당 10점, **부분 점수 없음 0점/10점 nhị phân**) · 권장 소요 시간 7분 이내  
> **치명적 위험도:** 분석작업은 계산작업과 달리 부분 점수가 일절 주어지지 않습니다. 사소한 정렬 누락이나 옵션 체크 하나만 잘못되어도 **한 번에 10점이 통째로 감점**되어 즉각 불합격 위기에 처하게 됩니다.  
> **학습 전략 원칙:** 한국어 공식 시험 지시문과 마우스 조작 경로를 완벽히 숙지하고, 바로 아래 베트남어 기술 해설을 통해 6대 분석 도구(피벗 테이블, 부분합, 데이터 통합, 목표값 찾기, 데이터 표, 시나리오)의 선행 조건 및 0점 방지 체크리스트를 체계적으로 정복합니다.

## 0. 분석작업 6대 도구 핵심 분류 및 기능 매핑 (6 công cụ phân tích dữ liệu kinh điển)

| 분석 도구 (Công cụ) | 출제 빈도 | 한국어 핵심 기능 정의 | Tiếng Việt giải thích bản chất nghiệp vụ |
|---|:---:|---|---|
| **피벗 테이블 (Pivot Table)** | **최다 출제 (70%)** | 방대한 목록 데이터를 행, 열, 값, 필터 축으로 재배치하여 동적 다차원 요약 보고서 작성 | Báo cáo xoay đa chiều tổng hợp số liệu |
| **부분합 (Subtotal)** | **초빈출 (60%)** | 특정 항목을 그룹화하여 그룹별 합계, 평균 등의 소계를 데이터 목록 중간에 산출 | Tổng phụ theo nhóm (bắt buộc Sort trước) |
| **데이터 통합 (Consolidate)** | **빈출 (40%)** | 같은 시트 또는 다른 시트에 분산된 여러 표를 하나의 요약 표로 통합 합산 | Gộp dữ liệu từ nhiều bảng nguồn vào bảng đích |
| **목표값 찾기 (Goal Seek)** | **빈출 (30%)** | 수식의 최종 결과값을 알고 있을 때, 이를 달성하기 위한 **단 하나의 입력 변수** 역산 | Tìm giá trị đầu vào để đạt doanh số/lợi nhuận mục tiêu |
| **데이터 표 (Data Table)** | **빈출 (30%)** | 1개 또는 2개 변수의 연속적 변화에 따른 수식 결과값을 매트릭스 표로 일괄 산출 | Phân tích độ nhạy theo ma trận 1 biến hoặc 2 biến |
| **시나리오 (Scenario)** | **빈출 (30%)** | 여러 변수가 동시에 변화하는 다양한 가상 상황(낙관, 비관)을 정의하고 요약 보고서 생성 | Dự báo nhiều kịch bản biến động (tối đa 32 biến) |

# 1. 피벗 테이블 보고서 (Pivot Table Report — 10점 만점 공략)

**[한국어 공식 지시문 패턴]**
> `[분석작업-1] 시트의 데이터를 이용하여 '부서명'은 행, '직급'은 열로 처리하고, '값'에 '기본급'의 평균과 '수당'의 합계를 계산하는 피벗 테이블 보고서를 작성하시오.`  
> `- 피벗 테이블 보고서는 동일 시트의 [A20] 셀에서 시작할 것`  
> `- 보고서 레이아웃은 '개요 형식으로 표시'를 적용하고, '열의 총합계'만 표시하시오.`  
> `- 값 필드의 표시 형식은 셀 서식의 '숫자' 범주에서 '1000 단위 구분 기호(,)'를 사용할 것`

**[마우스 조작 절차 (Office 2021 LTSC 표준)]**
1. **피벗 테이블 삽입:**
   - 원본 표 데이터 내부 임의의 셀(`A3`) 클릭.
   - [삽입] 탭 > [표] 그룹 > **[피벗 테이블]** 클릭.
   - [피벗 테이블 만들기] 창에서:
     - 표/범위: 원본 표 전체 `A3:G18` 확인.
     - 피벗 테이블 배치 위치: **`[기존 워크시트]`** 라디오 단추 선택 > 위치 란에 **`A20`** 셀 클릭 후 [확인].
2. **필드 목록 4대 영역 배치 (드래그 & 드롭):**
   - 우측 [피벗 테이블 필드] 창에서:
     - `부서명` 필드를 마우스로 끌어 **[행 (Rows)]** 영역에 배치.
     - `직급` 필드를 마우스로 끌어 **[열 (Columns)]** 영역에 배치.
     - `기본급` 필드를 마우스로 끌어 **[값 (Values)]** 영역에 배치.
     - `수당` 필드를 마우스로 끌어 **[값 (Values)]** 영역에 순차 배치.
3. **값 필드 요약 함수 및 표시 형식 변경:**
   - 기본급이 '합계'로 들어갔다면, [값] 영역의 `합계 : 기본급` 클릭 > **[값 필드 설정]** 선택.
   - 사용할 함수: **[평균]** 선택.
   - 좌측 하단의 **[표시 형식]** 버튼 클릭 > [숫자] 범주 선택 > **[1000 단위 구분 기호(,) 사용]** 체크 후 [확인] > [확인].
   - `수당` 필드도 동일하게 [값 필드 설정] 들어가서 요구된 표시 형식 설정.
4. **보고서 레이아웃 및 총합계 디자인 설정:**
   - 피벗 테이블 내부 셀 클릭 > 리본 메뉴의 [피벗 테이블 디자인] 탭 클릭.
   - [레이아웃] 그룹 > **[보고서 레이아웃]** 클릭 > **`[개요 형식으로 표시]`** (또는 '테이블 형식으로 표시') 선택.
   - [총합계] 클릭 > **`[열의 총합계만 설정]`** (또는 '행 및 열의 총합계 해제') 선택.

*Tiếng Việt giải thích & Bẫy 0 điểm KCCI:*
- **Vị trí đặt Pivot Table:** Đề bảo đặt tại `A20` của "기존 워크시트" (Existing Worksheet) mà bạn để mặc định "새 워크시트" (New Worksheet) là bị 0 điểm ngay lập tức.
- **Sửa hàm trong Values:** Không được click đúp trực tiếp vào ô trên bảng để sửa chữ "합계" thành "평균", phải vào đúng `[값 필드 설정]` (Value Field Settings).

# 2. 부분합 (Subtotal — 정렬 선행 필수 10점 공략)

**[한국어 공식 지시문 패턴]**
> `[분석작업-1] 시트에서 '학과'별로 '출석'의 최댓값과 '평가점수'의 평균을 계산하는 부분합을 작성하시오.`  
> `- 정렬은 '학과'를 기준으로 '오름차순'으로 처리할 것`  
> `- 최댓값과 평균은 위에 명시된 순서대로 처리할 것`

**[마우스 조작 절차 (0점 방지 생명선)]**
1. **1단계: 기준 필드 정렬 (Sort 선행 — 누락 시 0점):**
   - 원본 표의 `학과` 열 제목 셀(`B3`) 클릭.
   - [데이터] 탭 > [정렬 및 필터] 그룹 > **[오름차순 정렬 (ㅎ/ㄱ)]** 아이콘 클릭.
2. **2단계: 첫 번째 부분합 실행 (최댓값):**
   - [데이터] 탭 > [윤곽선] 그룹 > **[부분합]** 클릭.
   - 부분합 창 설정:
     - **그룹화할 항목:** 반드시 정렬 기준인 **`학과`** 선택.
     - **사용할 함수:** **`최대`** 선택.
     - **부분합 계산 항목:** **`출석`** 체크 (기존에 체크되어 있던 다른 필드는 반드시 체크 해제!).
     - [확인] 클릭.
3. **3단계: 두 번째 중첩 부분합 실행 (평균 — 덮어쓰기 방지):**
   - 범위 선택을 건드리지 말고 곧바로 다시 [데이터] 탭 > **[부분합]** 클릭.
   - 부분합 창 설정:
     - 그룹화할 항목: `학과` 유지.
     - 사용할 함수: **`평균`** 선택.
     - 부분합 계산 항목: `출석` 체크 해제, **`평가점수`** 체크.
     - **★ KCCI 최우선 주의:** 맨 아래 **`[새로운 값으로 대치]` 체크 상자를 반드시 해제(언체크)**할 것!
     - [확인] 클릭.

*Tiếng Việt giải thích & Bẫy 0 điểm:*
- Nếu quên sắp xếp (Sort) trước khi làm Subtotal: Toàn bộ bảng sẽ nát vụn thành từng dòng riêng lẻ → **0 điểm**.
- Khi làm hàm thứ hai, nếu quên **BỎ CHỌN `[새로운 값으로 대치]`**: Hàm thứ nhất vừa tính sẽ biến mất hoàn toàn → **0 điểm**.

# 3. 데이터 통합 (Consolidate — Gộp nhiều bảng dữ liệu)

**[한국어 공식 지시문 패턴]**
> `[데이터 통합] 기능을 이용하여 [표1], [표2], [표3]의 '전공과목'별 '중간고사', '기말고사'의 '평균'을 [표4] 영역에 계산하시오.`

**[마우스 조작 절차]**
1. **결과가 들어갈 목표 표 범위 블록 지정 (핵심):**
   - 결과 표의 행/열 머리글을 포함하여 **`E14:G18` 영역 전체를 마우스로 드래그 선택**합니다. (빈칸 데이터 셀만 선택하면 레이블 기준 통합 불가).
2. **데이터 통합 창 실행:**
   - [데이터] 탭 > [데이터 도구] 그룹 > **[통합]** 클릭.
3. **옵션 및 참조 영역 등록:**
   - 함수: **`[평균]`** (또는 합계) 선택.
   - 참조: 첫 번째 원본 표 범위(`A3:D8`) 드래그 후 우측의 **[추가]** 버튼 클릭.
   - 동일한 방식으로 두 번째 표(`F3:I8`), 세 번째 표(`A11:D16`)를 차례로 드래그하여 **모두 [추가]**하여 목록에 등록.
4. **레이블 옵션 체크:**
   - 사용할 레이블: **`[첫 행]`**과 **`[왼쪽 열]`** 2개 체크 상자를 모두 반드시 체크.
   - [확인] 클릭.

*Tiếng Việt giải thích:* Trước khi bấm Consolidate, phải bôi đen toàn bộ bảng đích CẢ TIÊU ĐỀ HÀNG VÀ CỘT. Luôn tích cả 2 ô: `첫 행 (Top row)` và `왼쪽 열 (Left column)`.

# 4. 가상 분석 3총사: 목표값 찾기, 데이터 표, 시나리오 (What-If Analysis)

### 4.1 목표값 찾기 (Goal Seek)
- **한국어 지문:** `[표1]에서 '만기수령액[G10]'이 '10,000,000'이 되려면 '월납입액[C10]'이 얼마가 되어야 하는지 계산하시오.`
- **마우스 절차:**
  1. [데이터] 탭 > [예측] 그룹 > [가상 분석] > **[목표값 찾기]** 클릭.
  2. 대화 상자 입력:
     - **수식 셀:** `G10`
     - **찾는 값:** `10000000` (쉼표 없이 순수 숫자만 직접 타이핑 입력).
     - **값을 바꿀 셀:** `C10`
  3. [확인] > [확인] 클릭.

### 4.2 데이터 표 (Data Table)
- **한국어 지문:** `[데이터 표] 기능을 이용하여 '이자율'과 '기간'의 변동에 따른 '월불입액[C8]'의 변화를 표 [C12:G18]에 계산하시오.`
- **마우스 절차:**
  1. **수식 복사 연결 (선행 필수):** 매트릭스 표의 좌측 상단 모서리 빈 셀(`C12`)을 클릭하고, **`=C8`**을 입력하여 엔터를 칩니다.
  2. **전체 표 범위 드래그 선택:** `C12:G18` 범위를 드래그.
  3. [데이터] 탭 > [가상 분석] > **[데이터 표]** 클릭.
  4. 대화 상자 입력:
     - **행 입력 셀:** 표의 가로(행) 방향에 나열된 변수의 원본 셀 선택 (예: 기간 `C6`).
     - **열 입력 셀:** 표의 세로(열) 방향에 나열된 변수의 원본 셀 선택 (예: 이자율 `C5`).
  5. [확인] 클릭.

### 4.3 시나리오 관리자 (Scenario Manager)
- **한국어 지문:** `[시나리오 관리자]를 이용하여 '환율[B3]'이 1,350원으로 인상되는 '시나리오1: 환율인상'과 1,200원으로 인하되는 '시나리오2: 환율인하'를 작성하고, 이에 따른 '순이익[F15]'의 변동 요약 보고서를 작성하시오.`
- **마우스 절차:**
  1. **셀 이름 정의 (사전 작업 권장):** 문제에서 요구한 경우 `B3` 셀을 클릭하고 이름 상자에 `환율`, `F15` 셀에 `순이익` 입력 후 Enter.
  2. [데이터] 탭 > [가상 분석] > **[시나리오 관리자]** 클릭.
  3. [추가] 클릭 > 시나리오 이름: `환율인상`, 변경 셀: `B3` 확인 후 [확인] > 값 입력란에 `1350` 입력 후 [추가].
  4. 두 번째 시나리오: 이름: `환율인하`, 값: `1200` 입력 후 [확인].
  5. 시나리오 관리자 창에서 우측의 **[요약]** 버튼 클릭 > 보고서 종류: **`[시나리오 요약]`** 선택, 결과 셀: **`F15`** 확인 후 [확인].
  6. **주의:** 자동으로 생성된 `시나리오 요약` 시트의 위치를 임의로 다른 곳으로 옮기지 마십시오.

## 5. KCCI 분석작업 0점 방지 종합 검증 체크리스트 (Bảng tự kiểm tra phòng ngừa 0 điểm 분석작업)

| 점검 영역 (Vùng kiểm tra) | 공식 검증 기준 (Tiêu chuẩn KCCI) | 합격 여부 (Tự đánh giá) |
|---|---|:---:|
| **부분합 정렬 선행** | 부분합을 실행하기 전에 그룹 기준 열을 오름차순/내림차순으로 사전 정렬했는가? | [ ] 통과 |
| **중첩 부분합 덮어쓰기** | 2번째 부분합 실행 시 `[새로운 값으로 대치]` 체크를 반드시 해제하였는가? | [ ] 통과 |
