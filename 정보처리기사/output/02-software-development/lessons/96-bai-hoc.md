## Exam Pattern Pack 02 — 소프트웨어 개발

> 실제 기출을 복사하지 않은 **원문 변형 연습**이다. 2025년 공개 복원 자료에서 확인되는 정적 분석, 화이트박스, 정렬 trace, 빌드 자동화, 자료구조 유형을 묶었다.

### Q1. 정적 분석

실행하지 않고 소스 코드의 규칙 위반·복잡도·잠재 오류를 검사하는 도구 유형은?

1. 정적 분석  2. 동적 분석  3. 부하 테스트  4. 인수 테스트

**정답: 1** — 정적 분석은 실행 전/실행 없이 코드를 검사한다. Valgrind처럼 실행 중 메모리를 관찰하는 도구는 동적 분석에 가깝다.

### Q2. 선택 정렬 2회전

`[7, 2, 9, 4, 1]`을 오름차순 선택 정렬할 때 2회전이 끝난 배열은?

1. `[1, 2, 9, 4, 7]`  2. `[1, 2, 4, 9, 7]`  3. `[2, 1, 9, 4, 7]`  4. `[1, 7, 2, 4, 9]`

**정답: 1** — 1회전에서 최솟값 1을 첫 위치로, 2회전에서 남은 구간의 최솟값 2를 두 번째 위치로 보낸다.

### Q3. 빌드 도구

다음 중 Jenkins에 대한 설명으로 가장 적절한 것은?

1. Java 기반 CI 서버로 빌드·테스트 자동화에 사용된다.
2. C 언어 전용 정적 분석기다.
3. 관계형 데이터베이스의 DDL 도구다.
4. 네트워크 라우팅 프로토콜이다.

**정답: 1** — Jenkins는 CI/CD 파이프라인 자동화 도구이며 Gradle과 역할이 다르다.

### Q4. 자료구조 판별

함수 호출 복귀 주소와 후위 표기식 계산에 공통으로 활용되는 구조는?

**정답:** 스택(Stack). 마지막에 들어온 항목을 먼저 꺼내는 LIFO가 핵심이다.
