# 정보처리기사 필기 — Research Register

이 문서는 시험 범위의 chuẩn gốc (canonical / 정본) nguồn (source / 소스)와 기술 사실 확인에 사용한 1차/공식 자료를 구분한다.

> **Mạch nối:** Đọc register này khi cần kiểm tra claim trong guide hoặc lesson; sau khi xác minh nguồn, quay lại đúng topic để nối bằng chứng (evidence / 증거) với cơ chế và bẫy đề.

## 시험 범위

- [Q-Net 정보처리기사 출제기준(2023.1.1~2025.12.31)](https://www.q-net.or.kr/cst006.do?artlSeq=5210765&brdId=Q006&code=1202&gId=&gSite=Q&id=cst00602) — 시험 범위 baseline.

## 기술 사실 확인

- [RFC 8200 IPv6 Specification](https://www.rfc-editor.org/rfc/rfc8200) — 128-bit addressing, anycast, header/MTU ngữ nghĩa (semantics / 의미론).
- [Oracle Java Language Specification](https://docs.oracle.com/javase/specs/jls/se26/html/jls-4.html) — thành phần nguyên thủy (primitive / 기본 요소) types, `char`, `boolean` and numeric widths.

- [PostgreSQL SELECT documentation](https://www.postgresql.org/docs/17/queries-order.html) — `WHERE`/`GROUP BY`/`HAVING`/`ORDER BY` lập luận (reasoning / 추론) and kết quả (result / 결과) thứ tự (ordering / 순서).
- [Python control-flow tutorial](https://docs.python.org/3/tutorial/controlflow.html) — `for`, `continue`, `break` and dấu vết (trace / 추적) hành vi (behavior / 동작).
- [OWASP CSRF Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/CSRF_Prevention_Cheat_Sheet.html) — đơn vị từ (token / 토큰) and SameSite defense limits.

외부 자료는 기술 사실을 검증하기 위한 참고이며, 실제 응시 전에는 Q-Net 출제기준의 최신 게시물을 우선한다.
