## Exam Pattern Pack 04 — 프로그래밍 언어 활용

> 실제 기출을 복사하지 않은 **원문 변형 연습**이다. 공개 복원 자료에서 반복된 C/Python/Java trace, 포인터, 연산자 우선순위, IPv6·세그먼트 주소 변환 유형을 변형했다.

### Q1. C 구조체 trace

```c
int a[4] = {1, 2, 3, 4};
int total = 0;
for (int i = 0; i < 4; i += 2) total += a[i];
```

`total`의 값은?

1. 3  2. 4  3. 6  4. 10

**정답: 2** — `i=0,2`만 방문하므로 `1+3=4`이다. 홀수 인덱스까지 더한다고 착각하지 않는다.

### Q2. Java `while` trace

```java
int x = 2, y = 3;
while (y-- > 0) x++;
```

반복 종료 후 `(x, y)`는?

1. `(5, -1)`  2. `(5, 0)`  3. `(4, 0)`  4. `(4, -1)`

**정답: 2** — 조건식에서 후위 감소가 먼저 비교 후 실행되며, `y`는 `3→2→1→0`이 된다.

### Q3. Python 문자열 분리

```python
a, b = map(int, "12x34".split("x"))
print(a + b)
```

출력은?

1. `12x34`  2. `46`  3. `1234`  4. 형변환 오류

**정답: 2** — `split("x")`가 `12`, `34`를 만들고 `map(int, ...)`가 정수로 변환한다.

### Q4. IPv6와 주소 길이

IPv6에 대한 설명으로 옳은 것은?

1. 주소 길이는 32비트다.
2. 기본 헤더 길이는 항상 128바이트다.
3. 주소 길이는 128비트이며 anycast를 정의한다.
4. IPv6는 브로드캐스트를 확장한 프로토콜이다.

**정답: 3** — IPv6는 128-bit 주소와 anycast를 제공하며, 패킷/헤더 길이를 “무제한”으로 해석하면 안 된다.
