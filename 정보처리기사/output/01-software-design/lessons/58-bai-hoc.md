## Exam Pattern Pack 01 — 소프트웨어 설계

> 실제 기출을 복사하지 않은 **원문 변형 연습**이다. 2025년 공개 복원 자료에서 반복적으로 보인 SCM, EAI, NS 차트, 모듈 독립성, UML/요구사항 판별 유형을 연습한다.

### Q1. 형상 관리 항목 판별

다음 중 형상 관리(Configuration Management)의 관리 항목으로 보기 가장 어려운 것은?

1. 소스 코드  2. 요구사항 명세서  3. 설치 매뉴얼  4. 개발자의 개인 식사 일정

**정답: 4** — 형상 항목은 제품·문서·빌드·설정처럼 재현성과 변경 추적이 필요한 산출물이다.

### Q2. EAI Hybrid

Hub-and-Spoke와 Message Bus의 장점을 조합하면서 애플리케이션 간 직접 연결을 줄이는 유형은?

1. Point-to-Point  2. Hybrid  3. 단일 파일 교환  4. 수동 배치

**정답: 2** — Hybrid는 중앙 허브와 버스 방식을 상황에 맞게 결합한다. Point-to-Point는 연결 수와 변경 영향이 커지기 쉽다.

### Q3. N-S 차트

N-S 차트가 표현하기에 가장 적합한 것은?

1. 데이터베이스 인덱스 물리 주소  2. 순차·선택·반복의 제어 구조  3. 네트워크 패킷 헤더  4. 클래스의 메모리 배치

**정답: 2** — N-S 차트는 구조적 프로그램의 논리 흐름을 상자와 중첩 구조로 표현한다.

### Q4. 결합도와 독립성

모듈이 다른 모듈의 내부 자료와 구현을 직접 참조한다면 어떤 결합도에 해당하며, 품질 관점에서 어떤 방향이 바람직한가?

**정답:** 내용 결합도(Content Coupling)이며 가장 강한 결합에 가깝다. 모듈 독립성을 위해 결합도는 낮추고 응집도는 높이는 방향이 바람직하다.
