## Exam Pattern Pack 03 — 데이터베이스 구축

> 실제 기출을 복사하지 않은 **원문 변형 연습**이다. 공개 복원 자료에서 반복된 DCL, 로킹, 함수 종속, SQL 분류, 뷰·카디널리티 유형을 변형했다.

### Q1. DCL과 TCL

사용자 `U1`에게 `orders` 테이블 검색 권한을 회수하는 명령은?

1. `GRANT SELECT ON orders TO U1;`
2. `REVOKE SELECT ON orders FROM U1;`
3. `ROLLBACK SELECT ON orders;`
4. `DROP SELECT FROM U1;`

**정답: 2** — 권한 부여·회수는 DCL, 변경 확정·취소는 TCL이다.

### Q2. 로킹 단위

로킹 단위를 작게 할 때 일반적으로 기대되는 효과는?

1. 동시성 증가와 로킹 오버헤드 증가
2. 동시성 감소와 로킹 오버헤드 감소
3. 항상 교착상태 제거
4. 데이터 독립성 제거

**정답: 1** — 작은 단위는 공유도를 높이지만 관리해야 할 잠금 수가 늘어 오버헤드가 증가한다.

### Q3. 정규형

릴레이션이 3NF이면서 모든 결정자가 후보키가 되도록 강화하면 도달하는 정규형은?

1. 1NF  2. 2NF  3. BCNF  4. 4NF

**정답: 3** — BCNF는 모든 결정자가 후보키여야 한다. 2NF는 부분 함수 종속, 3NF는 이행 함수 종속 제거가 핵심이다.

### Q4. 뷰와 물리 저장

일반적인 뷰(View)에 대한 설명으로 옳은 것은?

1. 항상 독립적인 인덱스를 가진다.
2. 기본 테이블의 일부 행·열을 숨겨 보안에 활용할 수 있다.
3. 모든 뷰는 자유롭게 INSERT/UPDATE/DELETE가 가능하다.
4. 뷰를 다른 뷰로 정의할 수 없다.

**정답: 2** — 뷰는 가상 테이블이며 갱신 가능성은 정의 방식과 제약에 따라 달라진다.
