### 핵심 **<mark>318</mark>** 소프트웨어 재사용의 개요 

소프트웨어 재사용(Software Reuse)은 이미 개발되어 인 정받은 소프트웨어의 전체 혹은 일부분을 다른 소프트웨 어 개발이나 유지에 사용하는 것이다. 

- 소프트웨어 개발의 품질과 생산성을 높이기 위한 방법 으로, 기존에 개발된 소프트웨어와 경험, 지식 등을 새 로운 소프트웨어에 적용한다. 

- 재사용의 이점 

- 개발 시간과 비용을 단축시킨다. 

- 소프트웨어 품질을 향상시킨다. 

- 소프트웨어 개발의 생산성을 향상시킨다. 

- 프로젝트 실패의 위험을 감소시킨다. 

- 시스템 구축 방법에 대한 지식을 공유하게 된다. 

- 시스템 명세, 설계, 코드 등 문서를 공유하게 된다.

### 2416702 20.8 핵심 **<mark>319</mark>** 소프트웨어 재사용 방법 



<!-- Start of picture text -->
2416702<br><!-- End of picture text -->

소프트웨어 재사용 방법에는 합성 중심 방법과 생성 중심 방법이 있다.

- 회복은 트랜잭션들을 수행하는 도중 장애가 발생하여 데이터베이스가 손상되었을 때 손상되기 이전의 정상 상태로 복구하는 작업이다.

   - 트랜잭션이 성공적으로 완료될 때까지 데이터 베이스에 대한 실질적인 갱신을 연기하는 방법

- • 트랜잭션의 부분 완료(성공적인 완료 직전) 시점 

- 연기 갱신 기법 에 Log에 보관한 갱신 내용을 실제 데이터베이 (Deferred 스에 기록함 Update) • 트랜잭션이 부분 완료되기 전에 장애가 발생하 여 트랜잭션이 Rollback되면 트랜잭션이 실제 데이터베이스에 영향을 미치지 않았기 때문에 어떠한 갱신 내용도 취소(Undo)시킬 필요 없이 무시하면 됨

교착상태(Dead Lock)는 상호 배제에 의해 나타나는 문제 점으로, 둘 이상의 프로세스들이 자원을 점유한 상태에서 서로 다른 프로세스가 점유하고 있는 자원을 요구하며 무 한정 기다리는 현상을 의미한다. 

- 교착상태 발생의 필요 충분 조건 

|상호 배제<br>(Mutual<br>Exclusion)|한 번에 한 개의 프로세스만이 공유 자원을 사용<br>할 수 있어야 함|
|---|---|
|점유와 대기|최소한 하나의 자원을 점유하고 있으면서 다른 프|
|(Hold and<br>Wait)|로세스에 할당되어 사용되고 있는 자원을 추가로<br>점유하기 위해 대기하는 프로세스가 있어야 함|
|비선점<br>(Non-<br>preemption)|다른 프로세스에 할당된 자원은 사용이 끝날 때까<br>지 강제로 빼앗을 수 없어야 함|
|환형 대기<br>(Circular Wait)|공유 자원과 공유 자원을 사용하기 위해 대기하는<br>프로세스들이 원형으로 구성되어 있어 자신에게<br>할당된 자원을 점유하면서 앞이나 뒤에 있는 프로<br>세스의 자원을 요구해야 함|



###### • 교착상태의 해결 방법 

|예방 기법<br>(Prevention)|• 교착상태가 발생하지 않도록 사전에 시스템을<br>제어하는 방법으로, 교착상태 발생의 네 가지<br>조건 중에서 어느 하나를 제거(부정)함으로써 수<br>행됨<br>•자원의 낭비가 가장 심한 기법|
|---|---|
|회피 기법<br>|• 교착상태가 발생할 가능성을 배제하지 않고 교<br>착상태가 발생하면 적절히 피해나가는 방법으<br>로, 주로 은행원 알고리즘(Banker’s Algorithm)이<br>사용됨<br>|
|(Avoidance)|• 은행원 알고리즘(Banker’s Algorithm) : E. J.<br>Dijkstra가 제안한 것으로, 은행에서 모든 고객의<br>요구가 충족되도록 현금을 할당하는 데서 유래<br>한 기법|





|발견 기법<br>(Detection)|• 시스템에 교착상태가 발생했는지 점검하여 교<br>착상태에 있는 프로세스와 자원을 발견하는 것<br>을 의미함<br>• 교착상태 발견 알고리즘과 자원 할당 그래프 등<br>을 사용할 수 있음|
|---|---|
|회복 기법<br>(Recovery)|교착상태를 일으킨 프로세스를 종료하거나 교착<br>상태의 프로세스에 할당된 자원을 선점하여 프로<br>세스나 자원을 회복하는 것을 의미함|

## **<mark>211</mark>** 데이터 통신의 개요 

- 데이터 통신 : 컴퓨터의 발달을 배경으로 하여 생겨난 것 으로, 컴퓨터와 각종 통신기기 사이에서 디지털 형태로 표현된 2진 정보(0과 1)를 송·수신하는 것을 말한다. 

데이터 통신 = 데이터 전송 기술 + 데이터 처리 기술 

- 정보 통신 : 컴퓨터와 통신 기술의 결합에 의해 통신 처 리 기능과 정보 처리 기능은 물론 정보의 변환, 저장 과 정이 추가된 형태의 통신이다.

## **<mark>212</mark>** 통신 회선 

꼬임선(Twisted Pair Wire, 이중 나선) 

- 전기적 간섭 현상을 줄이기 위해서 균일하게 서로 감 겨있는 형태의 케이블이다. 

- 가격이 저렴하고, 설치가 간편하다. 

- 거리, 대역폭, 데이터 전송률 면에서 제약이 많다. 

- 다른 전기적 신호의 간섭이나 잡음에 영향을 받기가 쉽다. 

동축 케이블(Coaxial Cable) 

- 주파수 범위(대역폭)가 넓어서 데이터 전송률이 높다. 

- 꼬임선에 비해 외부 간섭과 누화의 영향이 적다. 

- 신호의 감쇠 현상을 막기 위해 일정 간격마다 중계기 를 설치해야 한다. 

- 지상에서 쏘아 올린 마이크로 주파수를 통신 위성을 통해 변환, 증폭한 후 다른 주파수로 지상에 송신하는 방식으로, 위성 통신에 사용된다. 

- 위성 통신에 사용하고 있는 주파수는 300~3,000MHz 인 UHF(Ultra High Frequency)나 3~30GHz인 SHF(Super High Frequency)를 사용한다. 

- 위성 통신 시스템은 통신 위성, 지구국, 채널로 구성된다. 

- 대역폭이 넓어 고속·대용량 통신이 가능하고, 통신 비용이 저렴하다. 

- 전송 지연 시간이 길고, 보안성이 취약하다. 

- 통신 위성은 약 35,800Km 정도의 정지 궤도 상에 위 치하여 지구의 자전 속도로 운행한다. 

- 위성 통신 시스템에서는 하나의 통신 위성에 여러 개 의 지구국이 접속하여 사용하므로, 통신 위성을 공동 으로 사용하기 위한 다중 접속 방식이 필요하다. 

- FDMA(Frequency Division Multiple Access) : 주 파수 대역을 일정 간격으로 분할하는 방식

## **<mark>246</mark>** CSMA/CD 방식 

- 채널의 사용권을 서로 경쟁하여 확보하는 방식으로 노 드 간의 충돌을 허용하는 네트워크 접근 방식이다.

- 일정 길이 이하의 데이터를 송신할 경우 충돌을 검출 할 수 없다. 

- 전송량이 적을 때 매우 효율적이고 신뢰성이 높다. 

- 전송량이 많아지면 충돌이 잦아져서 채널의 이용률이 떨어지고 전송 지연 시간이 급격히 증가한다.

- DNS(Domain Name System) : 문자로 된 도메인 네임을 컴퓨터가 이해할 수 있는 IP 주소로 변환하는 역할을 하 는 시스템

## **<mark>253</mark>** X.25 

- 패킷 교환망을 통한 DCE와 DTE 간의 인터페이스를 제공한다. 

- ITU-T에서 제정한 국제 표준 프로토콜로 우수한 호 환성을 가진다. 

- 신뢰성과 효율성이 높고, 전송 품질이 우수하다. 

- 연결형 프로토콜로 흐름 제어, 오류 제어 등의 기능이 있다.
