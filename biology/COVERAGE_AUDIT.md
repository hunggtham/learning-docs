## 10. Continuity motifs đã được kiểm tra (audit / 감사) lại

### Chênh lệch

Chemical concentration → khuếch tán → plant thế nước → electrochemical potential → điện thế màng → động lực proton (proton motive force) → morphogen → physiological exchange → ecological tài nguyên (resource / 자원) độ dốc (gradient / 기울기).

### Phản hồi

Enzym (enzyme) điều khiển → truyền tín hiệu → chu kỳ tế bào (cell cycle) → stomatal điều khiển (control / 제어) → endocrine/immune → baroreflex/motor correction → human homeostasis → health reassessment → mật độ quần thể (population density) dependence → ecosystem hiện tượng trễ → systems-điều khiển mô hình (model / 모델).

### Thông tin

DNA → phiên mã/dịch mã → trạng thái phát triển (developmental state) → hoóc-môn/thụ thể trạng thái (state / 상태) → sensory encoding → hành động (action / 동작)/học tập (learning / 학습) → health đo lường (measurement / 측정) → clinical suy luận (inference / 추론) → tính di truyền (heredity) → population evolution → digital omics biểu diễn (representation / 표현).

### Fidelity và nhiễu

Sao chép đọc sửa (proofreading) → DNA repair → developmental tính ngẫu nhiên → sensory noise → wearable/lab variability → false alarm → giải trình tự (sequencing) chất lượng (quality / 품질) → sai số thống kê (statistical error) → độ bất định của mô hình (model uncertainty).

### Cooperation và xung đột (conflict / 충돌)

Molecular cooperation in tiền tế bào → organelle nội cộng sinh → hợp tác đa bào → maternal–fetal tài nguyên (resource / 자원) negotiation → cancer as somatic xung đột (conflict / 충돌) → immune regulation → xã hội (social / 사회적) hành vi (behavior / 동작) → ecological tương tác (interaction / 상호작용).

### Căng thẳng, khôi phục (recovery / 복구) và thích nghi

Cellular damage/repair → plant drought/defense phản hồi (response / 응답) → mô tái sinh → tập luyện (exercise) thích nghi (adaptation) → gánh nặng thích nghi → pain/tải (load / 로드) management → ecological disturbance/khả năng phục hồi.

### Dòng chảy (flow)

Mạch gỗ/mạch rây → blood circulation → alveolar exchange → renal filtration → developmental morphogen diffusion → ecosystem material flux. Same pressure/độ dốc (gradient / 기울기) ideas recur across scales.

### Quy mô (scale / 규모)

Phân tử (molecule) → tế bào → mô → cơ quan → sinh vật → quỹ đạo sức khỏe → quần thể → hệ sinh thái → sinh quyển; mỗi chuyển tiếp (transition / 전이) có tường minh (explicit / 명시적) cầu nối (bridge / 브리지) chapter hoặc cầu nối (bridge / 브리지) section.

## 11. Health-content an toàn (safety / 안전) & chất lượng (quality / 품질) gates

Mọi future cập nhật (update / 업데이트) liên quan health phải qua các gate sau.
