| Đại lượng | Quantity | 양 | Thuộc tính có thể biểu diễn bằng giá trị, thường kèm unit. |

| Phản ví dụ | Counterexample | 반례 | Một case hợp lệ bác bỏ universal claim. |
| Quy nạp toán học | Mathematical induction | 수학적 귀납법 | Proof framework từ base case và inductive step. |
| Số tự nhiên | Natural number | 자연수 | Numbers dùng cho counting; convention có thể gồm 0. |

| Giá trị tuyệt đối | Absolute value | 절댓값 | Distance của real number tới 0. |
| Tỉ số | Ratio | 비 | So sánh hai quantities bằng division. |

| Phần trăm | Percentage | 백분율 | Ratio trên base 100. |

| Logarithm | Logarithm | 로그 | Exponent cần để base đạt một value. |
| Đa thức | Polynomial | 다항식 | Finite sum của nonnegative integer powers với coefficients. |

| Hệ số góc | Slope | 기울기 | Rate `Δy/Δx`; local version trở thành derivative. |
| Đồng dạng | Similarity | 닮음 | Same shape dưới uniform scale. |
| Bằng nhau hình học | Congruence | 합동 | Same shape và size dưới rigid transformation. |
| Vector | Vector | 벡터 | Ordered components / displacement trong vector space. |
| Vô hướng | Scalar | 스칼라 | Một coefficient/value dùng để scale vector. |
| Chuẩn | Norm | 노름 | Hàm đo magnitude vector. |

| Ma trận | Matrix | 행렬 | Coordinate representation của linear map / coefficient array. |

| Số chiều | Dimension | 차원 | Số independent basis directions. |

| Liên tục | Continuity | 연속성 | Limit tại point tồn tại và bằng function value. |
| Đạo hàm | Derivative | 미분계수 / 도함수 | Local rate/sensitivity; local linear coefficient. |

| Jacobian | Jacobian | 야코비안 | Matrix first derivatives của vector-valued function. |
| Hessian | Hessian | 헤시안 | Matrix second partial derivatives của scalar function. |
| Tự động vi phân | Automatic differentiation (AD) | 자동미분 | Thực thi chain rule trên computational graph để tính derivatives chính xác tới machine arithmetic, khác finite difference. |
| Đồ thị tính toán | Computational graph | 계산 그래프 | Graph các operations và dependencies dùng để evaluate value và derivatives. |
| Lan truyền ngược | Backpropagation | 역전파 | Reverse-mode derivative propagation trên computational graph, thường dùng cho scalar loss. |
| Tích phân | Integral | 적분 | Limit của accumulated local contributions. |
| Phương trình vi phân | Differential equation | 미분방정식 | Equation ràng buộc state và derivatives/rates. |
| Dãy | Sequence | 수열 | Function trên ordered discrete indices. |
| Chuỗi | Series | 급수 | Sum của sequence terms. |
| Hội tụ | Convergence | 수렴 | Tiến tới limiting value theo precise definition. |
| Xác suất | Probability | 확률 | Measure định lượng uncertainty của events. |
| Xác suất có điều kiện | Conditional probability | 조건부 확률 | Probability sau khi condition trên information/event. |
| Định lý Bayes | Bayes' theorem | 베이즈 정리 | Rule đảo conditional direction bằng prior và likelihood. |
| Tỉ số khả dĩ | Likelihood ratio | 우도비 | Ratio so sánh mức evidence giải thích được dưới hai hypotheses/models. |
| Prior | Prior distribution | 사전분포 | Distribution mô tả uncertainty trước current data. |
| Posterior | Posterior distribution | 사후분포 | Distribution sau khi prior được cập nhật bằng likelihood của observed data. |
| Phân phối hậu nghiệm dự đoán | Posterior predictive distribution | 사후예측분포 | Distribution của future observation sau khi integrate parameter uncertainty theo posterior. |
| Hiệu chỉnh xác suất | Calibration | 보정 / 확률 보정 | Mức predicted probabilities phù hợp với frequencies quan sát trong các case tương đương. |
| Can thiệp nhân quả | Causal intervention | 인과 개입 | Thay đổi variable theo hành động `do(...)`, khác với chỉ conditioning trên observation. |
| Biến ngẫu nhiên | Random variable | 확률변수 | Mapping outcomes thành numerical values. |
| Phân phối | Distribution | 분포 | Cách probability phân bổ trên values/outcomes. |
| Kỳ vọng | Expectation | 기댓값 | Probability-weighted average/center. |
| Phương sai | Variance | 분산 | Expected squared deviation khỏi mean. |

| Tương quan | Correlation | 상관관계 | Normalized association, thường Pearson linear association. |

| Trường | Field | 체 | Ring nơi mọi phần tử khác 0 có multiplicative inverse; nền của linear algebra chuẩn. |

## Terminology notes trong tài liệu Hàn

Trong giáo trình Hàn, `미분` thường dùng rộng cho differentiation/process, `미분계수` cho derivative tại một điểm và `도함수` cho derivative function. Trong tài liệu ML/engineering, `gradient` thường được viết 그대로 là `그래디언트`, trong khi textbook toán có thể dùng `기울기 벡터` tùy context.

`행렬식` là determinant, còn `행렬` là matrix; hai từ gần nhau nhưng concept khác hẳn. `상관관계` là correlation; đừng dịch thành causal relationship. `신뢰구간` là confidence interval theo thống kê, không phải một interval “chắc chắn đúng X%” theo diễn giải đời thường.

Trong probability/statistics, `우도` là likelihood và `확률` là probability; chúng liên hệ nhưng không phải synonym. Trong stochastic-process/control material, `정상성` là stationarity, `전달함수` là transfer function, `극점` là pole và `상태공간` là state space. Trong ML, `자동미분` là automatic differentiation còn `역전파` là reverse propagation/backpropagation; backpropagation là một cách thực thi reverse-mode derivative flow, không phải optimizer.
