# Môn 1 – 데이터 모델링의 이해

> **Mạch đọc:** Đây là README owner của **Môn 1 – 데이터 모델링의 이해**. Route đọc đi từ nền tảng mô hình → ERD/keys → normalization/performance → transaction/NULL/identifier, để mỗi bài nối khái niệm mô hình với hành vi cơ sở dữ liệu.
