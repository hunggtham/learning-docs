# Môn 1 – 데이터 모델링의 이해

Nên học theo thứ tự từ mô hình hóa cơ bản đến chuẩn hóa và các khái niệm SQL biểu diễn trong mô hình.

> **Mạch nối:** Hãy đọc các bài theo thứ tự được liệt kê; mỗi bài mở rộng một ranh giới (boundary / 경계) của bài trước và chuẩn bị điều kiện để đọc bài sau.

## Danh sách bài học

1. [Nền tảng mô hình hóa dữ liệu](01-nen-tang-mo-hinh-du-lieu.md) — Khái niệm, mục tiêu, đặc điểm, góc nhìn, ba cấp độ và tính độc lập dữ liệu.
2. [ERD, Entity, Attribute, Relationship và Identifier](02-erd-entity-attribute-relationship-identifier.md) — Xây dựng ERD; phân loại thực thể (entity / 엔터티)/attribute/relationship; chọn và sử dụng identifier.
3. [Mô hình dữ liệu hướng hiệu năng và chuẩn hóa](03-mo-hinh-du-lieu-huong-hieu-nang-va-chuan-hoa.md) — Quy trình tối ưu mô hình, phụ thuộc hàm, 1NF–5NF, BCNF và phi chuẩn hóa.
4. [Quan hệ, Transaction, NULL và Identifier](04-quan-he-transaction-null-va-identifier.md) — Quan hệ trong mô hình, ACID, NULL trong SQL và natural/surrogate key.
