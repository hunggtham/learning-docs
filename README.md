# Learning Docs

Kho tài liệu học được tổ chức theo từng chủ đề. Mỗi bộ có nguồn gốc (`raw`/`raw_md`), script generate và thư mục `output` đã chuẩn hóa để học.

Danh mục domain đầy đủ, metadata YAML, prerequisite và related links được quản lý tại [CATALOG.md](CATALOG.md). README này giữ phần giới thiệu ngắn; `CATALOG.md` là bản đồ cấu trúc repository và dùng `main` làm source of truth.

## Bộ tài liệu

- [정보처리기사](정보처리기사/output/README.md): 5 môn, tài liệu Hàn–Anh–Việt, sắp xếp theo mạch kiến thức.
- [SQLD](sql/output/README.md): mô hình dữ liệu và SQL cơ bản/nâng cao, có ví dụ truy vấn và quy tắc dễ nhầm.
- [Mathematics Master Knowledge Book](mathematics/README.md): 87 chủ đề Toán theo conceptual dependency và first-principles, có glossary Việt–Anh–Hàn, knowledge connections và coverage audit; bao phủ thêm analysis, tensor/autodiff, stochastic processes, Bayesian inference và dynamic programming/control.
- [Physics Knowledge Library](physics/README.md): thư viện Vật lý theo conceptual dependency từ phép đo, cơ học, sóng, chất lưu, nhiệt, điện từ và quang học đến tương đối tính, lượng tử, nguyên tử–hạt nhân, vật chất ngưng tụ, điện tử và vật lý thiên văn; có knowledge connections và depth/coverage audit.
- [Electrical Engineering Knowledge Library](electrical_engineering/README.md): domain P3 nối Physics → Electronics → Digital logic → Computer Architecture → Embedded → Software qua circuits, analog/digital electronics, signals, communications, control, embedded, power và hardware–software interfaces.
- [Biology Knowledge Library](biology/README.md): thư viện Sinh học tổ chức theo conceptual boundary từ hóa học của sự sống, tế bào, di truyền, tiến hóa và vi sinh vật đến sinh lý cơ thể, sinh thái, công nghệ sinh học, bioinformatics và systems biology; dùng thuật ngữ Việt–Anh–Hàn, mental model, mathematical connections và coverage audit.
- [Philosophy Knowledge Library](philosophy/README.md): thư viện Triết học về philosophical reasoning, epistemology, metaphysics, philosophy of science, mind, ethics, social–political philosophy và philosophy of technology; làm cầu nối giữa Mathematics, Physics, Biology, Psychology, Computer Science và AI.
- [Research Methods Knowledge Library](research_methods/README.md): domain canonical về research question, theory/design, measurement/sampling/surveys, qualitative methods, systematic reviews/evidence synthesis, mixed methods, ethics, reproducibility và open science; cross-link Econometrics cho estimator/causal-inference detail thay vì duplicate.
- [Computer Science Knowledge Library](computer_science/README.md): namespace Computer Science; phần **Basic/Foundation** gồm 100 topic chapters được đặt tại `computer_science/basic/`, còn các library chuyên sâu như Data Structures & Algorithms được tách riêng để không trộn foundation với advanced knowledge.
- [Data Engineering Knowledge Library](data_engineering/README.md): lộ trình đã triển khai từ data lifecycle, pipeline semantics, storage và reliability đến modeling, distributed processing, streaming, orchestration/backfill, warehouse/lakehouse, serving/semantic layer, governance, cost/capacity và case studies; ưu tiên mental model trước tool và có [coverage audit](data_engineering/COVERAGE_AUDIT.md).
- [Backend Development Knowledge Library](10_backend/README.md): backend core độc lập framework từ request lifecycle, HTTP contract, identity, persistence, cache, messaging, resilience, testing và observability đến module/service boundary; Java, Spring và Python là các implementation track riêng.
- [DevOps / Platform Engineering Knowledge Library](devops_platform_engineering/README.md): delivery system và operating platform từ Linux/runtime, source→artifact, CI/CD, container, IaC, cloud, Kubernetes và GitOps đến observability/SRE, security, platform-as-product, multi-tenancy, FinOps và production troubleshooting; tái sử dụng/cross-link Computer Science internals thay vì duplicate.
- [Python Knowledge Library](10_backend/python/README.md): lộ trình Python 3.14 từ execution/object model → data model/standard library → packaging/testing/concurrency → runtime internals/production; đào sâu descriptor và object/class creation, free-threaded/multiple-interpreters, engineering case studies, glossary Việt–Anh–Hàn và coverage audit.
- [Frontend Development Knowledge Library](10_frontend/README.md): domain canonical bắt đầu từ URL/request → browser/network → HTML/DOM → CSS/CSSOM → style/layout/paint/composite → interaction/event loop → state/data → accessibility → performance → security → deployment; `10_frontend/javascript/javascript_beginner_rebuilt.md` vẫn là catalog entrypoint, còn React/WebSquare là framework tracks phía trên Web Platform.
- [JavaScript Knowledge Library](10_frontend/javascript/javascript_beginner_rebuilt.md): lộ trình JavaScript Vietnamese-first từ [Beginner](10_frontend/javascript/javascript_beginner_rebuilt.md) → [Intermediate](10_frontend/javascript/javascript_intermediate.md) → [Senior](10_frontend/javascript/javascript_senior.md) → [Master](10_frontend/javascript/javascript_master_supplement_detailed.md), tập trung execution model, scope/closure, `this`/prototype, Promise/event loop, browser runtime, modern-vs-legacy evolution, memory/performance, security và production engineering.
- [TypeScript canonical track](10_frontend/javascript/typescript_00_index.md): track TypeScript nằm cùng domain JavaScript thay vì tạo library root mới; đi từ runtime boundary và structural typing đến generics/type-level programming, `tsconfig`/module resolution/declarations, TypeScript 7 native compiler, runtime validation, security và production practice; cross-link sang React thay vì lặp framework semantics.
- [React canonical track](10_frontend/react/00_index.md): lộ trình React từ Beginner → Intermediate → Advanced/Senior → Master, giữ riêng Legacy API Reference để đọc project React 15–18; baseline React 19.3, bao phủ render/reconciliation/state identity, Effects, concurrency/Suspense/Actions, SSR/hydration/RSC, React Compiler 1.0, performance evidence, security và production architecture.
- [PMP Knowledge Library](pmp/README.md): giáo trình quản lý dự án và luyện PMP theo conceptual dependency từ value/project system, lifecycle/tailoring, people/stakeholder, planning/scope/schedule/finance, quality/procurement, risk/governance đến adaptive-hybrid delivery, measurement, AI/sustainability, scenario reasoning, quantitative practice và end-to-end case studies; giữ `pmp/raw/` và `pmp/workflow-output/` làm provenance thay vì canonical learning path.

## Quy ước biên soạn

- Giữ thuật ngữ gốc để đối chiếu đề thi, kèm English và nghĩa tiếng Việt khi có thể.
- Trình bày theo thứ tự: khái niệm → cơ chế/quy tắc → so sánh → ví dụ → ôn tập.
- Không sửa nguồn thô; mọi bản học được tạo lại bằng script tương ứng trong `scripts/`.
