Bắt đầu ở **Electrical kỹ thuật (engineering / 엔지니어링) Glossary — Việt · English · 한국어** để chỉ đường quay lại owner và tài liệu chuẩn khi cần đào sâu, rồi dùng kết luận đó khi quay về lộ trình rộng hơn.

Glossary này ưu tiên các thuật ngữ xuất hiện trong thư viện (library / 라이브러리). English/Korean là từ khóa (keyword / 키워드) tra cứu; phần giải thích vẫn giữ tiếng Việt.

| Việt | English | 한국어 | Ý chính |
|---|---|---|---|
| điện áp | voltage | 전압 | chênh lệch thế giữa hai điểm |
| dòng điện | hiện tại (current / 현재) | 전류 | tốc độ dòng điện tích |
| trở kháng | impedance | 임피던스 | quan hệ phasor giữa voltage và hiện tại (current / 현재) |
| tải | tải (load / 로드) | 부하 | phần nhận năng lượng hoặc tín hiệu (signal / 신호) |
| điểm làm việc | operating điểm (point / 지점) | 동작점 | trạng thái DC quanh đó ta tuyến tính hóa |
| khuếch đại | amplifier | 증폭기 | mạch tăng biên độ theo một miền tần số |
| hồi tiếp | phản hồi (feedback / 피드백) | 피드백 | đưa đầu ra (output / 출력) trở lại đầu vào (input / 입력) để điều chỉnh hành vi |
| độ ổn định | stability | 안정성 | phản hồi (response / 응답) không tự tăng ngoài giới hạn mô hình (model / 모델) |
| nhiễu | noise | 잡음 | biến thiên không mong muốn trong tín hiệu (signal / 신호)/power |
| lấy mẫu | sampling | 샘플링 | đổi tín hiệu (signal / 신호) liên tục thành chuỗi rời rạc |
| lượng tử hóa | quantization | 양자화 | ánh xạ biên độ liên tục vào mã (code / 코드) hữu hạn |
| bí danh phổ | aliasing | 에일리어싱 | thành phần tần số bị nhận nhầm do sampling |
| bộ lọc chống alias | anti-alias filter | 안티앨리어싱 필터 | lọc analog trước ADC |
| độ trễ | độ trễ (latency / 지연 시간) | 지연시간 | thời gian từ sự kiện (event / 이벤트)/đầu vào (input / 입력) tới đầu ra (output / 출력) |
| nhiễu pha | phase noise | 위상 잡음 | dao động ngẫu nhiên của phase oscillator |
| đồng bộ | synchronization | 동기화 | căn timing/carrier/trạng thái (state / 상태) giữa các bên |
| điều chế | modulation | 변조 | ánh xạ thông tin (information / 정보) lên carrier/symbol |
| ngân sách liên kết | link ngân sách (budget / 예산) | 링크 버짓 | cân đối công suất, gain, mất mát (loss / 손실) và margin |
| điều khiển | điều khiển (control / 제어) | 제어 | tạo hành động (action / 동작) từ đo lường (measurement / 측정) để đạt mục tiêu |
| đối tượng điều khiển | plant | 플랜트 | hệ vật lý được controller tác động |
| bộ chấp hành | actuator | 액추에이터 | biến command thành tác động vật lý |
| độ quan sát được | khả năng quan sát (observability / 관측 가능성) | 관측가능성 | khả năng suy ra trạng thái (state / 상태) từ đầu ra (output / 출력) |
| khả năng điều khiển | controllability | 제어가능성 | khả năng đưa trạng thái (state / 상태) bằng đầu vào (input / 입력) |
| nhiệm vụ thời gian thực | real-time tác vụ (task / 작업) | 실시간 태스크 | công việc (work / 작업) có deadline và timing đặc tả hợp đồng (contract / 계약) |
| thời gian thực thi xấu nhất | WCET | 최악 실행 시간 | upper bound cần cho deadline phân tích (analysis / 분석) |
| bộ điều khiển ngoại vi | driver | 드라이버 | software thực thi hardware đặc tả hợp đồng (contract / 계약) |
| thanh ghi ánh xạ bộ nhớ | memory-mapped register | 메모리 매핑 레지스터 | hardware trạng thái (state / 상태) truy cập qua address |
| tương thích điện từ | EMC | 전자파 적합성 | không gây/không chịu nhiễu vượt giới hạn |
| vùng hoạt động an toàn | SOA | 안전 동작 영역 | miền voltage/hiện tại (current / 현재)/thời gian (time / 시간) thiết bị (device / 장치) chịu được |
| giảm tải an toàn | derating | 디레이팅 | vận hành dưới giới hạn danh nghĩa để có margin |
