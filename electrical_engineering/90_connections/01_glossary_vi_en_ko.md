# Electrical Engineering Glossary — Việt · English · 한국어

Glossary này ưu tiên các thuật ngữ xuất hiện trong library. English/Korean là keyword tra cứu; phần giải thích vẫn giữ tiếng Việt.

| Việt | English | 한국어 | Ý chính |
|---|---|---|---|
| điện áp | voltage | 전압 | chênh lệch thế giữa hai điểm |
| dòng điện | current | 전류 | tốc độ dòng điện tích |
| trở kháng | impedance | 임피던스 | quan hệ phasor giữa voltage và current |
| tải | load | 부하 | phần nhận năng lượng hoặc signal |
| điểm làm việc | operating point | 동작점 | trạng thái DC quanh đó ta tuyến tính hóa |
| khuếch đại | amplifier | 증폭기 | mạch tăng biên độ theo một miền tần số |
| hồi tiếp | feedback | 피드백 | đưa output trở lại input để điều chỉnh hành vi |
| độ ổn định | stability | 안정성 | response không tự tăng ngoài giới hạn model |
| nhiễu | noise | 잡음 | biến thiên không mong muốn trong signal/power |
| lấy mẫu | sampling | 샘플링 | đổi signal liên tục thành chuỗi rời rạc |
| lượng tử hóa | quantization | 양자화 | ánh xạ biên độ liên tục vào code hữu hạn |
| bí danh phổ | aliasing | 에일리어싱 | thành phần tần số bị nhận nhầm do sampling |
| bộ lọc chống alias | anti-alias filter | 안티앨리어싱 필터 | lọc analog trước ADC |
| độ trễ | latency | 지연시간 | thời gian từ event/input tới output |
| nhiễu pha | phase noise | 위상 잡음 | dao động ngẫu nhiên của phase oscillator |
| đồng bộ | synchronization | 동기화 | căn timing/carrier/state giữa các bên |
| điều chế | modulation | 변조 | ánh xạ information lên carrier/symbol |
| ngân sách liên kết | link budget | 링크 버짓 | cân đối công suất, gain, loss và margin |
| điều khiển | control | 제어 | tạo action từ measurement để đạt mục tiêu |
| đối tượng điều khiển | plant | 플랜트 | hệ vật lý được controller tác động |
| bộ chấp hành | actuator | 액추에이터 | biến command thành tác động vật lý |
| độ quan sát được | observability | 관측가능성 | khả năng suy ra state từ output |
| khả năng điều khiển | controllability | 제어가능성 | khả năng đưa state bằng input |
| nhiệm vụ thời gian thực | real-time task | 실시간 태스크 | work có deadline và timing contract |
| thời gian thực thi xấu nhất | WCET | 최악 실행 시간 | upper bound cần cho deadline analysis |
| bộ điều khiển ngoại vi | driver | 드라이버 | software thực thi hardware contract |
| thanh ghi ánh xạ bộ nhớ | memory-mapped register | 메모리 매핑 레지스터 | hardware state truy cập qua address |
| tương thích điện từ | EMC | 전자파 적합성 | không gây/không chịu nhiễu vượt giới hạn |
| vùng hoạt động an toàn | SOA | 안전 동작 영역 | miền voltage/current/time device chịu được |
| giảm tải an toàn | derating | 디레이팅 | vận hành dưới giới hạn danh nghĩa để có margin |
