## 1. VBA 사용자 정의 함수 (Hàm tự định nghĩa VBA — 6점)

*(Hàm tự định nghĩa là tính năng cho phép lập trình viên tự xây dựng các hàm tính toán mới bằng ngôn ngữ VBA để giải quyết các quy tắc nghiệp vụ phức tạp mà các hàm có sẵn của Excel khó thực hiện gọn gàng).*

#### [실제 시험 지시문 예시 — Đề bài thực tế chuẩn KCCI]
> **▶ [표1]의 기본급, 근속년, 실적건을 이용하여 [G4:G10] 영역에 비고를 계산하는 사용자 정의 함수 `fn비고`를 작성하여 표시하시오.**

#### 1. 표준 모듈(Standard Module) 삽입 필수 절차 (Quy trình chèn Module chuẩn)

사용자 정의 함수는 반드시 통합 문서의 **표준 모듈(Standard Module)** 내에 작성되어야 한다.  
*(Hàm tự định nghĩa bắt buộc phải được viết bên trong một Module chuẩn của dự án VBA).*

```
                 사용자 정의 함수 생성 5단계 표준 흐름
                                   │
   [1단계: VBE 호출] ───────────────> Alt + F11 단축키로 Visual Basic Editor 창 실행
                                   │
   [2단계: 표준 모듈 삽입] ─────────> 상단 메뉴 [삽입(I)] -> [모듈(M)] 클릭 (Module1 생성)
                                   │
   [3단계: 함수 시그니처 정의] ────> Public Function fn비고(기본급, 근속년, 실적건)
                                   │
   [4단계: 제어문 로직 구현] ──────> If 조건문 또는 Select Case 문으로 분기 작성
                                   │
   [5단계: 함수명에 결과 반환] ────> fn비고 = "최우수" (함수명 자체에 반환값 대입)
```

> [!CAUTION]
> **치명적 0점 감점 요인 (Sheet 모듈 작성 금지):**  
> Visual Basic Editor 좌측의 프로젝트 탐색기에서 `Sheet1(기본작업-1)`이나 `ThisWorkbook`을 더블클릭하여 코드를 작성하면 안 된다. 시트 모듈에 작성된 함수는 워크시트에서 전역으로 인식되지 않아 셀에 `=fn비고(...)`를 입력했을 때 **`#NAME?` 에러가 발생하며 0점 처리**된다. 반드시 **`[삽입] -> [모듈]`**을 통해 생성된 독립 모듈에 작성해야 한다.

### 1.2 2대 핵심 제어 구조 문법과 구현 (2 cấu trúc rẽ nhánh cốt lõi: If vs Select Case)

#### 1. `If ~ ElseIf ~ Else ~ End If` 분기문
조건식에 논리 연산자(`And`, `Or`, `Not`)가 복합적으로 사용되거나, 서로 다른 변수를 동시에 비교해야 할 때 사용한다.  
*(Cấu trúc If phù hợp cho các bài toán kết hợp nhiều điều kiện logic phức tạp trên các biến tham số khác nhau).*

```vba
Public Function fn비고(기본급, 근속년, 실적건)
    ' 1. 근속년수 5 이상 AND 실적건수 20 이상
    If 근속년 >= 5 And 실적건 >= 20 Then
        fn비고 = "최우수"
    ' 2. 근속년수 10 이상 OR 기본급 4,000,000 이상
    ElseIf 근속년 >= 10 Or 기본급 >= 4000000 Then
        fn비고 = "우수"
    ' 3. 그 외 나머지 조건
    Else
        fn비고 = ""
    End If
End Function
```

- **함수명 반환 원칙 (Nguyên tắc gán tên hàm):**  
  VBA 함수에서 결과값을 셀에 돌려주는 유일한 방법은 **함수의 이름(`fn비고`)에 결과값을 직접 대입**하는 것이다 (`fn비고 = ...`). 대입하지 않으면 빈 셀(0 hoặc rỗng)이 반환된다.
- **문자열 및 공백 표현:** 빈칸 출력 지시 시 반드시 빈 큰따옴표 `""`를 대입한다.

---

#### 2. `Select Case ~ Case Is ~ Case Else ~ End Select` 다중 선택문
단일 변수의 수치 구간(범위)이나 특정 코드값에 따라 결과가 계단식으로 달라지는 문제에 적용한다.  
*(Cấu trúc Select Case thích hợp cho các bài toán phân loại theo khoảng giá trị của một biến duy nhất).*

##### [실제 시험 지시문 예시]
> **▶ `fn평가` 함수를 작성하시오. 실적건수를 인수로 받아 30 이상이면 "A", 20 이상 30 미만이면 "B", 10 이상 20 미만이면 "C", 그 외에는 "D"로 표시하시오. `Select Case` 문을 사용하시오.**

```vba
Public Function fn평가(실적건)
    Select Case 실적건
        Case Is >= 30
            fn평가 = "A"
        Case Is >= 20
            fn평가 = "B"
        Case 10 To 19
            fn평가 = "C"
        Case Else
            fn평가 = "D"
    End Select
End Function
```

- **`Case Is >= 수치` 문법:** 부등호를 사용한 크기 비교 시 반드시 `Is` 키워드를 동반해야 한다 (`Case >= 30`은 컴파일 문법 오류 발생).
- **`Case 시작 To 끝` 문법:** 닫힌 정수 구간을 명시할 때 사용한다.
- **`Case Else` 문법:** 상위의 모든 조건에 해당하지 않는 나머지 전체를 처리한다.

## 2. 재무 함수 (Hàm tài chính: Dòng tiền, Lãi suất & Kỳ hạn)

상공회의소 1급 실기에서 출제되는 재무 함수는 대출금 상환액, 적금 만기액, 현재가치 등을 계산하는 함수군으로, **기간 단위 환산(연 $\leftrightarrow$ 월)**과 **현금 흐름의 부호 규약(+ / -)**이 채점의 핵심 기준이다.  
*(Nhóm hàm tài chính tính toán số tiền trả góp vay vốn, giá trị tương lai tích lũy, hoặc giá trị hiện tại. Hai mấu chốt quyết định điểm số là quy đổi đồng nhất đơn vị thời gian theo tháng và quy ước dấu âm dương của dòng tiền).*

```
                          재무 함수의 5대 핵심 함수 매핑
                                        │
     ┌──────────────────┬───────────────┴───┬──────────────────┬──────────────────┐
     ▼                  ▼                   ▼                  ▼                  ▼
  [PMT]               [FV]                [PV]               [RATE]             [NPER]
정기 납입액/상환액    미래 가치(만기액)    현재 가치(대출원금)  기간별 이자율        총 납입 횟수(기간)
```

---

### 2.1 5대 재무 함수 구문 문법 (Cú pháp 5 hàm tài chính chuẩn)

| 함수명 (Tên hàm) | 구문 구조 (Cú pháp đầy đủ) | 기능 설명 (Giải thích chức năng) |
|---|---|---|
| **`PMT`** | `=PMT(Rate, Nper, Pv, [Fv], [Type])` | 매월(매기) 균등 분할 상환해야 하는 원리금 또는 적금 납입액 계산. |
| **`FV`** | `=FV(Rate, Nper, Pmt, [Pv], [Type])` | 매월 일정액을 적립했을 때 만기 시점의 원리금 총액(미래 가치) 계산. |
| **`PV`** | `=PV(Rate, Nper, Pmt, [Fv], [Type])` | 미래에 지급받을 연금이나 상환할 부채의 현재 시점 할인 총액(현재 가치) 계산. |
| **`RATE`** | `=RATE(Nper, Pmt, Pv, [Fv], [Type])` | 주어진 기간 동안 목표 금액을 달성하기 위한 월(기) 단위 이자율 계산. |
| **`NPER`** | `=NPER(Rate, Pmt, Pv, [Fv], [Type])` | 목표 금액에 도달하기 위해 필요한 총 납입(상환) 회차 계산. |

### 2.2 월 단위 환산과 현금 흐름 부호의 황금률 (Quy tắc chuyển đổi tháng & Dấu âm dương)

#### 1. 기간 및 이자율의 단위 통일 법칙 (Quy tắc đồng nhất đơn vị tính theo tháng)
대부분의 은행 대출 및 적금은 매월 납입되지만 문제에서는 연이율과 연단위 기간이 주어진다. 따라서 반드시 월 단위로 일치시켜야 한다:
- **월 이자율 (Rate):** $\text{연이율} / 12$ $\rightarrow$ 예: `8% / 12`
- **총 납입 개월 수 (Nper):** $\text{거치 연수} \times 12$ $\rightarrow$ 예: `3 * 12`

#### 2. 현금 흐름(Cash Flow) 부호 규약 (+ / -)
- **내 지갑에서 나가는 돈 (지출/투자/납입):** **음수(`-`)**로 처리한다.
- **내 지갑으로 들어오는 돈 (대출수령/만기환급):** **양수(`+`)**로 처리한다.

---

### 2.3 실전 계산 예시 (Ví dụ tính toán thực tế chuẩn thi KCCI)

#### [실제 시험 지시문 예시]
> **▶ 연이율 6%, 상환 기간 3년, 대출 원금 50,000,000원일 때 매월 말 상환해야 하는 원리금을 [C15] 셀에 계산하시오.**  
> - 단, 계산된 결과값은 양수로 표시되도록 작성하시오. `PMT` 함수를 사용하시오.

```excel
=PMT(6%/12, 3*12, -50000000)
```
또는
```excel
=-PMT(6%/12, 3*12, 50000000)
```

- **상세 분석 (Phân tích chi tiết):**  
  대출 원금 50,000,000원은 내가 대출받아 지갑으로 들어온 돈이므로 본래 양수(`+50,000,000`)이다. 그러면 `PMT`의 반환값은 매달 나가는 돈이므로 기본적으로 음수(`-1,521,097`)로 출력된다. 그러나 지시문에서 *"결과값을 양수로 표시하시오"*라고 명시했으므로 대출금 앞에 마이너스를 붙여 `-50000000`으로 넣거나 함수 전체 앞에 `-PMT(...)`를 붙여야 정답 처리된다.

## 3. 고급 찾기 및 참조 함수 (Hàm tra cứu & Tham chiếu nâng cao)

*(Vượt qua giới hạn của VLOOKUP thông thường, phần này kiểm tra kỹ năng định vị tọa độ 2 chiều giao nhau giữa hàng và cột, tra cứu ngược từ phải qua trái, và trỏ vùng động).*

### 3.1 `INDEX` + 2차원 `MATCH` 동시 교차 검색 (Tra cứu 2 chiều giao nhau hàng và cột)

#### [실제 시험 지시문 예시]
> **▶ [표2]에서 사원코드(가로 방향)와 평가항목(세로 방향)이 교차하는 점수를 [표1]의 사원코드와 평가항목을 참조하여 계산하시오.**  
> - `INDEX`, `MATCH` 함수를 사용하시오.

```excel
=INDEX($C$15:$G$20, MATCH($B4, $B$15:$B$20, 0), MATCH($C4, $C$14:$G$14, 0))
```

```
                        INDEX 2차원 교차 매핑 원리
                                    │
               행 위치(Row): MATCH($B4, $B$15:$B$20, 0)
                                    │
                                    ▼
       [$C$15:$G$20] 전체 데이터 영역 ────► [교차 셀 값 추출]
                                    ▲
                                    │
               열 위치(Col): MATCH($C4, $C$14:$G$14, 0)
```

- **`MATCH` 행 위치:** 첫 번째 `MATCH`는 평가항목(`$B4`)이 세로 머리글(`$B$15:$B$20`)에서 몇 번째 행에 있는지 찾는다.
- **`MATCH` 열 위치:** 두 번째 `MATCH`는 사원코드(`$C4`)가 가로 머리글(`$C$14:$G$14`)에서 몇 번째 열에 있는지 찾는다.
- **`INDEX(범위, 행번호, 열번호)`:** 찾아낸 행과 열이 만나는 정밀한 좌표의 점수를 반환한다.

---

### 3.2 역방향 검색: `VLOOKUP` + `CHOOSE` 결합 (Tra cứu ngược từ phải sang trái)

`VLOOKUP`은 기준 열의 오른쪽에 있는 데이터만 가져올 수 있는 태생적 한계가 있다. 기준 열의 좌측에 위치한 열을 가져와야 할 때 `CHOOSE` 함수로 가상 열 배열을 재구성한다.  
*(Hàm VLOOKUP chỉ tra cứu được sang bên phải. Khi cột cần lấy dữ liệu nằm ở bên trái cột tham chiếu, ta kết hợp với CHOOSE để đảo vị trí các cột trong bộ nhớ).*

#### [실제 시험 지시문 예시]
> **▶ 사원번호를 기준으로 직급을 조회하시오. 단, 참조표의 1열에는 성명, 2열에는 직급, 3열에는 사원번호가 배치되어 있다.**  
> - `VLOOKUP`, `CHOOSE` 함수를 사용하시오.

```excel
=VLOOKUP(A4, CHOOSE({1, 2}, $C$4:$C$20, $B$4:$B$20), 2, FALSE)
```

- **`CHOOSE({1, 2}, C열, B열)`의 마법:**  
  중괄호 상수 배열 `{1, 2}`를 넘겨주면, 엑셀은 메모리 상에서 C열(사원번호)을 가상 1열로, B열(직급)을 가상 2열로 배치한 새로운 가상 테이블을 생성한다.
- `VLOOKUP`은 이 가상 테이블의 1열(C열)에서 사원번호를 찾고, 2열(B열)의 직급을 완벽하게 반환할 수 있게 된다.

---

### 3.3 동적 오프셋 참조: `OFFSET` 함수

기준 셀로부터 지정된 행/열 수만큼 이동한 위치의 셀이나 범위 영역을 동적으로 반환한다.  
*(Hàm OFFSET xác định một ô hoặc vùng ô mới dựa trên khoảng cách dịch chuyển số hàng và số cột tính từ một ô gốc cố định).*

$$\text{구문 문법: } =OFFSET(\text{기준셀}, \text{이동할 행수}, \text{이동할 열수}, [\text{높이}], [\text{너비}])$$

#### 실전 수식 예시:
```excel
=AVERAGE(OFFSET($C$3, 1, 3, 5, 1))
```
- 기준 셀 `$C$3`에서 아래로 1행, 오른쪽으로 3열 이동한 위치(`F4`)부터 높이 5행, 너비 1열에 해당하는 `F4:F8` 범위의 평균을 계산한다.

---

### 3.4 조회 오류 완벽 방어: `IFERROR` 래핑 기법

`MATCH`나 `VLOOKUP` 검색 실패 시 표시되는 `#N/A` 오류를 사용자 지정 메시지나 빈칸으로 안전하게 전환한다.  
*(Hàm IFERROR bọc bên ngoài các hàm tra cứu để bắt lỗi #N/A khi không tìm thấy kết quả và thay thế bằng chuỗi mong muốn).*

```excel
=IFERROR(VLOOKUP(A4, $E$4:$G$20, 3, FALSE), "코드 미등록")
```

### 4.1 텍스트 처리 및 서식 변환 함수 (`TEXT`, `REPT`, 문자열 슬라이싱)

#### 1. `TEXT(값, "표시형식")`
숫자나 날짜 데이터를 사용자가 지정한 서식 문자열 형태의 텍스트로 강제 변환한다.
```excel
=TEXT(TODAY(), "yyyy-mm-dd (aaa)")   ' 결과: 2026-10-16 (금)
=TEXT(F4, "#,##0원")                  ' 결과: 4,500,000원
```

#### 2. `REPT(문자열, 반복횟수)`
특정 문자(특수문자 기호 등)를 지정한 횟수만큼 반복 출력하여 인라인 막대그래프 효과를 낼 때 빈출된다.
```excel
=REPT("★", INT(G4/10))                ' 총점이 85점이면 8개의 ★ 출력
```

#### 3. 문자열 추출 함수와 숫자 변환 함정 (`LEFT`, `RIGHT`, `MID`)
- **치명적 주의점:** `LEFT`, `RIGHT`, `MID`로 추출된 결과는 화면에 숫자처럼 보여도 **100% 텍스트(String) 형식**이다!
- 만약 `MID(A4, 2, 2) >= 10`과 같이 숫자 10과 직접 비교하면 텍스트와 숫자의 비교 오류로 인해 엉뚱한 결과가 나온다.
- **해결책:**
  - 방법 1: `VALUE(MID(A4, 2, 2)) >= 10` (명시적 숫자 변환)
  - 방법 2: `(MID(A4, 2, 2) * 1) >= 10` (산술 연산을 통한 암시적 형변환)
  - 방법 3: `MID(A4, 2, 2) >= "10"` (문자열 대 문자열 비교)

### 4.2 실무 날짜/시간 연산 함수 (`EDATE`, `EOMONTH`, `WORKDAY`, `WEEKDAY`)

| 함수명 | 구문 구조 | 핵심 기능 및 컴활 1급 출제 포인트 |
|---|---|---|
| **`EDATE`** | `=EDATE(시작일, 개월수)` | n개월 전/후의 **동일한 날짜**를 반환 (만기일, 계약 갱신일 계산).<br>예: `=EDATE("2026-03-15", 3)` $\rightarrow$ `2026-06-15` |
| **`EOMONTH`** | `=EOMONTH(시작일, 개월수)` | n개월 전/후 해당 월의 **마지막 날(말일)**을 반환.<br>예: `=EOMONTH("2026-03-15", 1)` $\rightarrow$ `2026-04-30` |
| **`WORKDAY`** | `=WORKDAY(시작일, 일수, [휴일])` | 주말(토, 일)과 지정된 법정 공휴일을 제외한 **순수 근무일 기준 n일 후 날짜** 계산. |
| **`WEEKDAY`** | `=WEEKDAY(날짜, [반환유형])` | 특정 날짜의 요일을 나타내는 숫자(1~7)를 반환. |

---

#### `WEEKDAY`의 반환 유형 옵션과 `CHOOSE` 결합 요일 명칭 도출
상공회의소 실기 시험에서는 `WEEKDAY` 함수와 `CHOOSE` 함수를 결합하여 한글 요일 명칭("월요일", "화요일"...)을 출력하는 문제가 매우 높은 빈도로 출제된다.

- **유형 1 (생략 또는 1):** 일요일이 1, 월요일이 2, ..., 토요일이 7
  ```excel
  =CHOOSE(WEEKDAY(D4, 1), "일요일", "월요일", "화요일", "수요일", "목요일", "금요일", "토요일")
  ```
- **유형 2 (옵션 2):** 월요일이 1, 화요일이 2, ..., 일요일이 7
  ```excel
  =CHOOSE(WEEKDAY(D4, 2), "월요일", "화요일", "수요일", "목요일", "금요일", "토요일", "일요일")
  ```
