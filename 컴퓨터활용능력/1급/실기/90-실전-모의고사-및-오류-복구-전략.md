## 1. 1과목: 스프레드시트 실무 (Excel 45분) 실전 시간 배분 모델

**[한국어 실전 문제 풀이 순서 전략]**
> 시험지의 문항 번호 순서(1번 $\to$ 2번 $\to$ 3번 $\to$ 4번)대로 풀면, 2번 계산작업(배열 수식)에서 시간이 지체되어 뒤쪽의 쉬운 배점(피벗 테이블, 차트, 매크로 40점)을 놓치고 탈락하게 됩니다. 반드시 **배점 대비 소요 시간이 적은 고효율 영역부터 우선 공략**해야 합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│               엑셀 실기 45분 전략적 문제 풀이 타임라인                 │
├─────────────────┬─────────────────┬──────────────────┬─────────────────┤
│ 1단계 (0~10분)  │ 2단계 (11~18분) │ 3단계 (19~26분)  │ 4단계 (27~40분) │
│ 기본작업 (30점) │ 분석작업 (20점) │ 기타작업 (15점)  │ 계산작업 (24점) │
│ • 고급필터 (5점)│ • 피벗테이블(10)│ • 차트 수정 (10) │ • 사용자함수 (6)│
│ • 조건부서식 (5)│ • 데이터표/시나 │ • 기타-2 (1,3번) │ • 배열수식 (12) │
│ • 페이지설정 (5)│   리오/통합 (10)│   (폼열기/닫기 5)│ • 일반함수 (6)  │
├─────────────────┴─────────────────┴──────────────────┴─────────────────┤
│ 5단계 (41~45분): 최종 저장(Ctrl+S) 및 서식/수식 에러 검토 (5분)        │

```

**[Tiếng Việt diễn giải thứ tự làm bài tối ưu]**
1. **Bước 1 (0 – 10 phút): [기본작업 - 30 điểm]**
   - Làm ngay 고급필터 (5đ), 조건부서식 (5đ), 페이지 레이아웃/시트보호 (5đ). Đây là phần dễ lấy trọn điểm nhất.
2. **Bước 2 (11 – 18 phút): [분석작업 - 20 điểm]**
   - Làm 피벗테이블 (10đ) cẩn thận theo quy trình chống điểm 0, sau đó làm câu phân tích phụ (데이터 표, 시나리오, 통합 - 10đ).
3. **Bước 3 (19 – 26 phút): [기타작업 - 15 điểm]**
   - Hoàn thành 5 câu sửa biểu đồ 차트 (10đ).
   - Làm câu lập trình 기타작업-2: câu 1 mở form (`Form.Show` + Initialize) và câu 3 đóng form (`Unload Me`). Tạm thời bỏ qua câu 2 (ghi dữ liệu dòng cuối) để tiết kiệm thời gian.
4. **Bước 4 (27 – 40 phút): [계산작업 - 18~24 điểm]**
   - Mở Alt+F11 viết ngay hàm tự tạo 사용자 정의 함수 (6đ tuyệt đối).
   - Giải 2 đến 3 câu công thức mảng 배열수식 và hàm tra cứu ma trận.
5. **Bước 5 (41 – 45 phút): [최종 검토 및 저장 - 5 phút]**
   - Nhấn `Ctrl + S`, kiểm tra xem có ô nào bị lỗi `#VALUE!`, `#REF!` không.

## 2. 2과목: 데이터베이스 실무 (Access 45분) 실전 시간 배분 모델

**[한국어 실전 시간 배분 원칙]**
> 액세스는 테이블 구조(DB 구축)가 올바르게 완성되지 않으면 뒤이어 나오는 폼, 보고서, 쿼리가 모두 연쇄적으로 오작동합니다. 따라서 **DB 구축(30점)을 가장 완벽하게 해결한 후, 폼 $\to$ 보고서 $\to$ 쿼리 순으로 진행**합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│               액세스 실기 45분 전략적 문제 풀이 타임라인               │
├─────────────────┬─────────────────┬──────────────────┬─────────────────┤
│ 1단계 (0~12분)  │ 2단계 (13~22분) │ 3단계 (23~32분)  │ 4단계 (33~42분) │
│ DB 구축 (30점)  │ 화면 구현 (25점)│ 조회 및 출력(25) │ 처리 구현 (20점)│
│ • 테이블완성(20)│ • 폼 완성 (15점)│ • 보고서완성(15) │ • 선택 쿼리 (5) │
│ • 관계 설정 (5) │ • 도메인함수(5) │ • 보고서 이벤트/ │ • 크로스탭/매개 │

├─────────────────┴─────────────────┴──────────────────┴─────────────────┤
│ 5단계 (43~45분): 쿼리 실행 결과 및 개체 닫기/최종 저장 (3분)          │
```

## 3. KCCI 실기 0점 처리 치명적 함정 목록 (Các bẫy bị 0 điểm tuyệt đối)

### 3.1 엑셀(Excel) 0점 방지 체크리스트

**[한국어 치명적 감점 규정]**
1. **피벗 테이블 부분 점수 없음 (0점 처리):** 피벗 테이블은 10점 만점 아니면 0점의 이진 채점(Binary Scoring) 방식입니다. 지시사항 중 레이아웃 하나, 또는 표시 형식 하나라도 누락되면 10점 전체가 0점 처리됩니다.
   - *대책:* 피벗 테이블 생성 후 지시사항의 모든 조건(외부데이터 원본, 보고서 레이아웃, 빈 셀 표시, 값 필드 설정 서식)을 하나씩 체크하며 대조합니다.
2. **배열 수식 일반 Enter 입력 (0점 처리):** 배열 수식을 작성한 후 `Ctrl + Shift + Enter`를 누르지 않고 일반 `Enter`로 입력하면 수식 양 끝의 중괄호(`{ }`)가 사라져 계산 결과가 `#VALUE!`로 출력되거나 단일 셀 계산으로 왜곡되어 0점 처리됩니다.
3. **조건부 서식 열 고정 누락:** 조건부 서식에서 행 전체에 서식을 지정할 때 `$A4` 대신 `A4`나 `$A$4`를 사용하면 특정 단일 셀에만 색상이 칠해지거나 전체 행에 서식이 번져 0점 처리됩니다.
4. **사용자 정의 함수 철자 오류:** VBA 모듈에서 선언한 함수 이름(`Public Function fn비고`)과 엑셀 시트에서 호출한 이름이 단 한 글자라도 틀리면 `#NAME?` 에러가 발생하여 0점 처리됩니다.

### 3.2 액세스(Access) 0점 방지 체크리스트

**[한국어 치명적 감점 규정]**
1. **수식 및 조건식 필드명 오타 (매개변수 값 입력 창 발생):** 폼이나 보고서의 컨트롤 원본, 또는 쿼리 디자인에서 필드 이름을 잘못 입력하면, Access는 이를 존재하지 않는 필드로 인식하여 폼/보고서를 열 때 **"매개변수 값을 입력하십시오"**라는 팝업 창을 띄웁니다. 이 창이 뜨면 해당 문항은 무조건 0점 처리됩니다.
   - *대책:* 필드명을 직접 타이핑하지 말고, 속성 시트의 드롭다운 목록에서 선택하거나 필드 목록 창에서 드래그하여 배치합니다.
2. **관계 설정 시 기존 데이터 불일치 에러:** 관계 창에서 `항상 참조 무결성 유지`를 체크했을 때 "참조 무결성을 강화할 수 없습니다"라는 오류 메시지가 뜨면, 자식 테이블에 부모 테이블에 존재하지 않는 외래키 데이터가 이미 입력되어 있는 상태입니다. 문제에서 테이블을 열어두었거나 수정 중인 상태일 수 있으므로 모든 테이블을 닫은 후 관계를 설정해야 합니다.
3. **실행 쿼리(Action Query) 중복 실행 금지:** 업데이트 쿼리(`UPDATE`), 추가 쿼리(`INSERT`), 삭제 쿼리(`DELETE`)는 **디자인 보기에서 단 한 번만 실행(`! 실행` 단추 클릭)**해야 합니다. 만약 실수로 2번 이상 누르면 데이터가 2배로 증가하거나 두 번 차감되어 원본 데이터가 영구 훼손되어 채점 시 0점 처리됩니다.
