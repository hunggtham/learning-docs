# 90 — 실전 모의고사

> **공식 시험시간:** 40분.  
> **목표:** 개별 기능 암기를 실제 시험 workflow로 통합하고, 오류가 나도 시간 안에 복구할 수 있게 한다.  
> **주의:** 아래 시간 배분은 학습용 추천안이며 대한상공회의소의 공식 영역별 배점/시간 규정이 아니다.

# 1. 실전의 핵심은 순서다

실전에서는 모든 문제를 syllabus 순서대로 풀 필요가 없다.

안정적인 전략은:

1. 문제 전체를 빠르게 스캔
2. 확실한 작업부터 점수 확보
3. 계산작업은 reference/함수 검산
4. 분석/차트/매크로 수행
5. 마지막에 저장 + 범위 + 누락 확인

→ Không để một công thức khó chặn toàn bộ bài thi.

---

# 2. 추천 시간 budget

연습 초기 예시:

- 2~3분: 전체 지시문 scan
- 8~10분: 기본작업
- 10~12분: 계산작업
- 8~10분: 분석작업
- 5~7분: 차트/매크로
- 3~5분: 검토/저장

개인 약점에 따라 조정한다.

예:
Function이 약하면 계산작업에 더 많은 시간을 배정하되, 다른 영역 검토 시간을 0으로 만들지 않는다.

# 3. 문제를 받자마자 하는 일

## 3.1 파일 확인

- 올바른 workbook인가?
- sheet name이 맞는가?
- 저장 위치/파일 이름 지시가 있는가?

## 3.2 문제 marking

각 문항을 세 종류로 표시한다.

- A: 바로 가능
- B: 생각 필요
- C: 현재 막힘

A를 먼저 끝내고 B, C로 간다.

---

# 4. 지시문 parsing template

모든 문제를 아래 구조로 읽는다.

**Target → Operation → Condition → Output → Constraint**

예:

“B4:G20 범위에서 부서가 영업이고 매출이 100 이상인 데이터를 고급 필터로 J4부터 복사하시오.”

- Target → B4:G20
- Operation → Advanced Filter
- Condition → 부서=영업 AND 매출>=100
- Output → J4부터
- Constraint → Advanced Filter 사용

이렇게 바꾸면 긴 Korean instruction도 작업 sequence로 단순해진다.

---

# 5. 계산작업 실전 루틴

1. 첫 output cell 선택
2. 문제에서 요구한 function 확인
3. Formula 작성
4. Reference의 $ 확인
5. 첫 결과 manual sanity check
6. Fill
7. 마지막 row formula 확인

### 막혔을 때

Function 이름이 기억나지 않으면 문제 keyword를 다시 본다.

- 조건 개수 → COUNTIF
- 조건 합계 → SUMIF
- lookup → VLOOKUP/HLOOKUP
- 문자열 위치 → LEFT/RIGHT/MID
- 날짜 component → YEAR/MONTH/DAY

---

# 6. 분석작업 실전 루틴

## Subtotal

Sort 여부 확인 후 실행.

## Goal Seek

Result formula cell / target value / changing input cell을 말로 먼저 구분.

## Data Table

Row input / Column input 방향 확인.

## Scenario

Changing cells list를 먼저 표시.

## PivotTable

Rows / Columns / Values / Filters layout을 종이에 짧게 그려도 좋다.

---

# 7. 차트/매크로 실전 루틴

## Chart

Source → Type → Elements → Format → Position 순서.

## Macro

Name → Record → Required actions → Stop → Assign/Run → Verify.

Macro를 기록하기 전에 동작을 머릿속에서 한 번 rehearsal하면 불필요한 action 기록을 줄일 수 있다.

---

# 8. 오류가 났을 때 recovery

실전에서는 완벽히 안 막히는 것보다 **막혔을 때 빨리 빠져나오는 능력**이 중요하다.

## Formula Error

1. 괄호
2. Function spelling
3. Range
4. $ reference
5. Text quote
6. Lookup option

## Filter Error

1. Header
2. Criteria range
3. AND/OR row structure
4. List range
5. Copy To

## Pivot Error

1. Source data
2. Field placement
3. Value aggregation
4. Refresh

## Macro Error

작업 취소/기록 종료 상태를 확인하고, 필요하면 문제 범위만 다시 수행한다.

---

# 9. 마지막 검토 순서

검토는 random하게 하지 않는다.

## 9.1 Save

가장 먼저 저장 상태 확인.

## 9.2 Blank Output

결과를 입력해야 할 셀이 비어 있는지 scan.

## 9.3 Formula

몇 개 cell을 click하여 Formula Bar와 $를 확인.

## 9.4 Filter/Analysis

결과 위치와 criteria를 확인.

## 9.5 Chart

Title, legend, series, position 확인.

## 9.6 Macro

요구된 이름/연결 여부 확인.

# 11. 실기 오답 taxonomy

## Knowledge

기능 자체를 몰랐다.

## Navigation

메뉴 위치를 찾지 못했다.

## Reference

Cell/range/$를 틀렸다.

## Condition

>=, AND/OR, exact match 등을 잘못 읽었다.

## Output

결과 위치/형식이 틀렸다.

## Time

알지만 너무 오래 걸렸다.

## Recovery

오류 후 원복에 시간을 과도하게 사용했다.

이 taxonomy를 사용하면 다음 연습이 무엇인지 바로 결정할 수 있다.

# 12. 재시험 기준

모의고사를 한 번 잘 본 것으로 끝내지 않는다.

다음 조건을 연속적으로 만족하는 것을 목표로 한다.

- 40분 안에 완료
- 저장/파일 구조 실수 없음
- function reference 오류 거의 없음
- Advanced Filter 조건 논리 안정
- Pivot/Goal Seek 등 분석 도구를 메뉴 탐색 없이 수행
- Chart/Macro에서 지시 누락 없음

안정성은 최고 점수보다 **분산이 작은 수행**을 의미한다.

---

# 13. 시험 전날

새로운 기능을 많이 추가하지 않는다.

복습 우선순위:

1. Reference
2. IF/Lookup/Text/Date functions
3. Advanced Filter criteria
4. Subtotal/Goal Seek/Pivot
5. Chart element
6. Macro workflow

그리고 한 번의 짧은 timed run으로 손 순서를 확인한다.

# 14. 시험 직전 checklist

- 파일 저장 규칙 기억
- Ctrl+S 습관
- 같은 행 AND / 다른 행 OR
- $의 row/column lock 의미
- Goal Seek: result → target → input
- Pivot: Rows/Columns/Values/Filters
- Chart: source 먼저
- Macro: Stop Recording 확인
- 한 문제에 오래 묶이지 않기

# 15. 전체 학습 loop

실기는 다음 loop를 반복한다.

**Concept 이해 → 느리게 정확히 수행 → 반복 → Timed Practice → Error Classification → 재훈련**

단순히 영상으로 보는 것은 “recognition”만 만들고 실제 시험은 “execution”을 요구한다.
