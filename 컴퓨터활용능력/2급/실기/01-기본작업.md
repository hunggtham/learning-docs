# 01 — 기본작업

> **목표:** 지시문을 읽고 정확한 범위에 정확한 기능을 적용하는 능력을 만든다.  
> **환경:** Microsoft Office LTSC 2021 기준.  
> **핵심 원칙:** 실기는 “기능을 알고 있다”보다 **범위 선택 → 조건 해석 → 작업 수행 → 결과 검증**이 더 중요하다.

## 0. 기본작업의 mental model

기본작업은 Excel 사용의 입구다.

**문제 지시문 → 대상 Range → 적용 Rule → 표시/추출 Result**

→ Ví dụ đề yêu cầu “B4:H15에서 점수가 80 이상인 행을 조건에 맞게 표시하라”, trước tiên phải xác định phạm vi, sau đó mới chọn Conditional Formatting hoặc Filter tùy wording.

실기에서 가장 위험한 실수는 기능을 몰라서가 아니라 다음 네 가지다.

1. 범위를 한 칸 잘못 선택
2. Header를 포함/제외해야 하는데 반대로 선택
3. 조건식을 상대/절대 참조로 잘못 작성
4. 결과 위치를 잘못 지정

---

# 1. 시험 파일을 열기 전에 확인할 것

## 1.1 원본 구조를 함부로 바꾸지 않는다

문제에서 요구하지 않은 sheet 이름, row/column 구조, 기존 값은 변경하지 않는다.  
→ Không tự ý “dọn đẹp” file thi.

## 1.2 저장은 작업의 일부다

실전에서는 기능 수행뿐 아니라 **정확한 파일을 유지하고 저장하는 것**도 중요하다.

습관:

- 작업 시작 직후 파일 이름/위치 확인
- 큰 작업 하나가 끝날 때마다 저장
- 마지막 2~3분에는 새 기능을 시도하지 말고 저장/검토

Ctrl + S는 매우 자주 쓰게 된다.

---

# 2. 지시문 parsing

문제 문장을 네 칸으로 나눈다.

| 질문 | 예 |
|---|---|
| 어디에? | B4:G15 |
| 무엇을? | 조건부 서식 |
| 어떤 조건으로? | 점수 >= 80 |
| 결과는 어디에/어떻게? | 지정된 서식 적용 |

이 네 요소 중 하나라도 놓치면 기능을 맞게 사용해도 점수를 잃기 쉽다.

---

# 3. 데이터 입력과 편집

## 3.1 셀 입력

Cell을 선택하고 값을 입력한다.

- Enter → 보통 아래 셀로 이동
- Tab → 오른쪽 셀로 이동
- F2 → 현재 셀 내용을 직접 편집할 때 유용

## 3.2 여러 셀 범위

연속 범위는 drag 또는 Shift로 선택하고, 비연속 범위는 Ctrl을 이용할 수 있다.

## 3.3 Fill Handle

수식, 숫자 계열, 날짜 등을 빠르게 복사한다.

중요:
수식을 Fill Handle로 복사하면 **relative reference가 이동**한다.

---

# 4. 셀 서식

## 4.1 값과 서식을 분리해서 생각한다

Cell의 실제 값과 화면 표시 방식은 다르다.

예:
실제 값 = 0.25  
표시 형식 = Percentage  
화면 = 25%

→ Dữ liệu không đổi, chỉ cách hiển thị đổi.

## 4.2 자주 조작하는 서식

- Font
- Font Size
- Bold
- Font Color
- Fill Color
- Border
- Horizontal/Vertical Alignment
- Wrap Text
- Merge & Center
- Number Format

### 실전 원칙

문제가 “굵게, 가운데 맞춤, 배경색”을 요구하면 각각 독립 조건으로 체크한다. 하나라도 빠지면 작업이 미완성이다.

---

# 5. 표시 형식 — Number Format

## 5.1 숫자

천 단위 구분, 소수 자릿수, 음수 표시 등을 조절한다.

## 5.2 날짜

같은 날짜 serial value를 yyyy-mm-dd, m/d 등 다양한 형태로 표시할 수 있다.

## 5.3 백분율

0.85를 85%로 보여준다.

## 5.4 사용자 지정 표시 형식

사용자 지정 형식은 데이터를 변환하는 것이 아니라 표현 규칙을 만든다.

대표 사고법:

**양수 ; 음수 ; 0 ; 텍스트**

→ Khi gặp đề custom format, hãy hỏi “giá trị nào cần hiển thị theo pattern nào”, không sửa giá trị bằng công thức nếu đề chỉ yêu cầu format.

---

# 6. 조건부 서식 — Conditional Formatting

조건부 서식은 조건을 만족하는 셀을 자동으로 강조한다.

## 6.1 기본 흐름

1. 적용 범위를 선택한다.
2. 홈(Home) → 조건부 서식(Conditional Formatting)
3. 필요한 rule을 선택한다.
4. 조건 또는 formula를 지정한다.
5. Format을 설정한다.
6. 적용 범위를 다시 확인한다.

## 6.2 수식 사용 규칙

문제가 “수식을 사용하여” 조건부 서식을 만들도록 요구하면 **선택 범위의 첫 번째 셀 기준으로 formula를 작성**한다.

예:
적용 범위가 A2:D10이고 C열 점수가 80 이상인 행 전체를 강조하고 싶다면 개념적으로:

=$C2>=80

핵심:

- C열은 고정 → $C
- Row는 각 행마다 바뀜 → 2는 고정하지 않음

→ Đây chính là mixed reference. 필기에서 배운 참조가 바로 실기 작업으로 연결된다.

## 6.3 자주 하는 실수

- 적용 범위 첫 행과 formula row가 맞지 않음
- $를 과도하게 써서 모든 행이 같은 셀만 검사
- 전체 행 강조인데 조건 열 하나만 format 적용
- 숫자와 text 조건을 혼동

---

# 7. 자동 필터 — AutoFilter

AutoFilter는 조건에 맞는 row만 화면에 보여준다.

## 흐름

1. 데이터 범위 안의 셀 선택
2. 데이터(Data) → 필터(Filter)
3. Header drop-down에서 조건 설정

### 핵심

Filter는 row를 삭제하지 않는다.  
→ Dữ liệu vẫn còn; chỉ một số dòng được ẩn tạm thời.

### 조건 예

- 숫자: >= 80
- Text: 특정 문자열 포함
- Date: 특정 기간
- Top N

---

# 8. 고급 필터 — Advanced Filter

고급 필터는 2급 실기에서 특히 중요한 기능이다. 단순 UI 조건보다 **criteria range 구조**를 이해해야 한다.

## 8.1 세 범위를 분리한다

1. List Range — 원본 데이터
2. Criteria Range — 조건 영역
3. Copy To — 결과를 복사할 위치

## 8.2 AND / OR 규칙

### 같은 행 = AND

| 부서 | 점수 |
|---|---|
| 영업 | >=80 |

의미:

부서 = 영업 **AND** 점수 >= 80

### 다른 행 = OR

| 부서 | 점수 |
|---|---|
| 영업 | |
| | >=80 |

의미:

부서 = 영업 **OR** 점수 >= 80

이 규칙은 반드시 손으로 한두 번 표를 그려 이해해야 한다.

## 8.3 Header matching

Criteria의 header는 원본 field와 정확히 연결되어야 하는 경우가 많다.

→ Sai tên header có thể khiến filter không hoạt động đúng dù điều kiện 자체는 đúng.

## 8.4 결과 복사

문제에서 “다른 위치에 복사”를 요구하면 Advanced Filter의 Copy to another location을 사용한다.

원본 필터링만 해놓고 끝내지 않는다.

---

# 9. Data Validation — 데이터 유효성 검사

Data Validation은 입력 가능한 값을 제한한다.

예:

- 1~100 사이 정수
- 특정 날짜 범위
- 목록 선택

## 흐름

1. 범위 선택
2. 데이터(Data) → 데이터 유효성 검사(Data Validation)
3. 허용 조건 선택
4. 최소/최대 또는 source 지정
5. 필요 시 Input Message/Error Alert 설정

### Conditional Formatting과 차이

- Conditional Formatting → 입력된 값을 보고 **보이는 모습** 변경
- Data Validation → **입력 가능한 값** 자체를 제한

---

# 10. 텍스트 나누기 — Text to Columns

한 셀 안에 들어 있는 텍스트를 여러 열로 분리할 때 사용한다.

예:
Pham,Hung,Tham

쉼표 delimiter를 기준으로 세 열로 나눌 수 있다.

## 방식

- Delimited → comma, tab, space 등 구분자 사용
- Fixed Width → 고정 위치를 기준으로 분리

→ Đề thi thường cần chọn đúng kiểu tách và destination.

---

# 11. 외부 데이터 가져오기

외부 텍스트/CSV 등에서 데이터를 worksheet로 불러올 수 있다.

핵심은 import 자체보다 다음을 확인하는 것이다.

- delimiter
- encoding/문자 깨짐
- column data type
- destination

문제에서 시작 셀 또는 worksheet 위치를 지정하면 그 위치를 정확히 지킨다.

---

# 12. 복사와 Paste Special

일반 복사 외에 Paste Special을 사용하면 값, 수식, 서식 등을 선택적으로 붙여넣을 수 있다.

대표 목적:

- Value만 붙여넣기
- Format만 붙여넣기
- Formula만 붙여넣기
- Transpose

→ Copy/Paste 문제는 “무엇을 복사하는가”가 아니라 **어떤 layer를 붙여넣는가**를 묻는 경우가 있다.

# 13. 기본작업 검증 workflow

기능을 적용한 직후 다음 순서로 확인한다.

## 13.1 Range

정확한 셀 범위인가?

## 13.2 Condition

>= 와 >, 포함과 같음 등을 헷갈리지 않았는가?

## 13.3 Output

결과가 원본 위치인가, 다른 위치인가?

## 13.4 Format

폰트, 색, 테두리, 정렬 조건이 모두 들어갔는가?

## 13.5 Save

저장했는가?

# 14. 자주 발생하는 감점 패턴

| 실수 | 왜 발생하는가 | 방지법 |
|---|---|---|
| Header 포함 오류 | 범위 구조를 안 봄 | 시작 전에 header row 확인 |
| 조건부 서식 formula row 오류 | 첫 셀 기준을 무시 | 선택 범위 첫 row와 formula row 맞추기 |
| Advanced Filter AND/OR 오류 | criteria table 논리 미숙 | 같은 행 AND / 다른 행 OR 암기 후 이해 |
| Copy To 위치 오류 | 결과 위치를 대충 선택 | 문제의 시작 셀을 먼저 표시 |
| 값 수정으로 format 해결 | value와 presentation 혼동 | 서식 문제면 원본 값 유지 |
| 저장 누락 | 마지막에 몰아서 저장 | 작업 단위마다 Ctrl+S |

# 15. Mini Practice

원본 데이터:

| 이름 | 부서 | 점수 |
|---|---|---:|
| A | 영업 | 85 |
| B | 개발 | 92 |
| C | 영업 | 70 |
| D | 개발 | 78 |

### 연습 1

점수 80 이상인 행 전체를 조건부 서식으로 강조하라.

사고:
- 조건 열 = 점수
- row 전체 표시
- 점수 column 고정 + row 이동

### 연습 2

부서가 영업이고 점수가 80 이상인 데이터만 Advanced Filter로 다른 위치에 복사하라.

사고:
- 같은 criteria row에 영업, >=80 작성
- AND
- Copy to another location

### 연습 3

점수 열에 0~100 정수만 입력되도록 제한하라.

사고:
- Data Validation
- Whole Number
- Between 0 and 100
