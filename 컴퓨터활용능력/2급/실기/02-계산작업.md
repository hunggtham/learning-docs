# 02 — 계산작업

> **목표:** 문제 문장을 formula 구조로 변환하고, 정확한 cell reference와 function을 사용해 결과를 만든다.  
> **핵심 원칙:** 함수를 많이 외우는 것보다 **문제 유형 → 함수군 → argument → reference → 검산** 순서를 고정한다.

## 0. 계산작업 workflow

모든 함수 문제를 아래 다섯 단계로 푼다.

1. **Output Range** 확인
2. 문제에서 요구한 **Function** 확인
3. **조건/검색/계산 대상 Range** 분리
4. Relative / Absolute / Mixed reference 결정
5. 첫 셀 결과 검산 후 Fill Handle로 복사

→ Đây là workflow cốt lõi. Sai ở bước 3 hoặc 4 thì công thức nhìn “đúng” nhưng cả cột có thể sai.

---

# 1. 수식 기본

Formula는 = 로 시작한다.

예:
=A2+B2  
=C2*$F$1  
=SUM(D2:D10)

## 1.1 함수보다 먼저 식의 목적을 말한다

예:
“판매금액 = 수량 × 단가”

먼저 자연어 관계를 만든 뒤 formula로 바꾼다.

=수량셀*단가셀

이 방식은 함수를 무작정 입력하는 것보다 오류가 적다.

---

# 2. 셀 참조

## 2.1 상대 참조

A2

복사 방향에 따라 row/column이 함께 이동한다.

## 2.2 절대 참조

$A$2

row와 column 모두 고정.

## 2.3 혼합 참조

$A2 또는 A$2

한 축만 고정.

## 2.4 실전 판단 질문

Formula를 복사하기 전에 묻는다.

- 이 참조는 아래 row로 이동해야 하는가?
- 오른쪽 column으로 이동해야 하는가?
- 고정된 기준표/세율/구간표인가?

고정된 table range라면 absolute reference가 필요한 경우가 많다.

# 3. 기본 집계 함수

## SUM

합계.

예:
=SUM(C2:C10)

## AVERAGE

평균.

## MAX / MIN

최댓값 / 최솟값.

## COUNT / COUNTA

- COUNT → number cell count
- COUNTA → non-empty cell count

### 실전 trap

ID가 숫자처럼 보여도 text로 저장되어 있으면 COUNT 결과에서 빠질 수 있다.

---

# 4. IF 함수

IF는 가장 중요한 분기 함수다.

형태:

=IF(condition, value_if_true, value_if_false)

예:
=IF(C2>=60,"합격","불합격")

## 4.1 문제를 세 부분으로 자른다

“점수가 60 이상이면 합격, 아니면 불합격”

- condition → C2>=60
- TRUE → "합격"
- FALSE → "불합격"

## 4.2 Nested IF

등급 문제가 대표적이다.

예:
90 이상 A  
80 이상 B  
그 외 C

중요:
조건 순서를 큰 값부터 내려오게 배치하는 방식이 자연스럽다.

---

# 5. AND / OR

## AND

모든 조건이 참이어야 TRUE.

예:
=AND(B2>=80,C2="합격")

## OR

하나 이상 참이면 TRUE.

## IF와 결합

=IF(AND(B2>=80,C2>=80),"통과","재검토")

### 판단

“그리고”, “동시에”, “모두” → AND  
“또는”, “하나라도” → OR

---

# 6. COUNTIF / SUMIF / AVERAGEIF

조건 기반 집계에 사용한다.

## COUNTIF

조건을 만족하는 개수.

=COUNTIF(B2:B20,">=80")

## SUMIF

조건을 만족하는 row의 값을 합산.

개념:

=SUMIF(criteria_range, criteria, sum_range)

### 핵심

조건을 검사하는 range와 실제 합계를 낼 range를 구분한다.

## Multiple criteria

COUNTIFS, SUMIFS 등은 여러 criteria pair를 사용한다.

---

# 7. 수학 함수

## ROUND

반올림.

=ROUND(number, num_digits)

### num_digits mental model

- 2 → 소수 둘째 자리
- 0 → 정수
- -1 → 십 단위
- -2 → 백 단위

## ROUNDUP / ROUNDDOWN

지정 자리 기준 올림/내림.

## INT

정수 처리.

## MOD

나머지.

=MOD(10,3) → 1

## ABS

절댓값.

---

# 8. 통계 함수

## LARGE / SMALL

k번째 큰/작은 값.

=LARGE(C2:C10,2)

→ 두 번째로 큰 값.

## RANK 계열

값의 순위를 구한다.

실기에서는 descending/ascending 기준을 정확히 읽어야 한다.

---

# 9. 문자열 함수

## LEFT

왼쪽부터 n글자.

=LEFT(A2,2)

## RIGHT

오른쪽부터 n글자.

## MID

중간 위치에서 length만큼.

=MID(A2,3,4)

## LEN

문자 수.

## FIND / SEARCH

특정 text의 위치를 찾는다.

## 문자열 결합

& 연산자 또는 결합 함수를 사용할 수 있다.

예:
=A2&"-"&B2

### 실전 pattern

주민번호/상품코드/사번처럼 일정 pattern의 code를 분해할 때 LEFT, RIGHT, MID가 자주 연결된다.

---

# 10. 날짜 함수

Excel date는 내부적으로 number이므로 계산할 수 있다.

## YEAR / MONTH / DAY

날짜 component 추출.

## TODAY

오늘 날짜.

## NOW

현재 날짜와 시간.

## DATE

year, month, day를 조합.

## WEEKDAY

요일 정보를 숫자로 반환.

### 실전 판단

문제에 “생년월일의 월”, “입사연도”, “오늘 기준”이 나오면 Date function 후보를 먼저 찾는다.

---

# 11. VLOOKUP / HLOOKUP

## 11.1 VLOOKUP mental model

**key를 첫 column에서 찾고 → 같은 row에서 지정 column의 값을 반환**

형태:

=VLOOKUP(lookup_value, table_array, col_index_num, range_lookup)

### table_array

기준표는 formula를 Fill할 때 움직이지 않는 경우가 많으므로 absolute reference가 필요하다.

예:
=VLOOKUP(B2,$H$2:$J$10,3,FALSE)

## 11.2 Exact / Approximate

FALSE → exact match  
TRUE 또는 생략 → approximate match 가능

근사 검색은 기준표 정렬 등 전제가 중요하다.

## 11.3 HLOOKUP

첫 row에서 찾고 아래 row 값을 반환.

V = vertical table  
H = horizontal table

---

# 12. Database Functions

대표:

- DSUM
- DAVERAGE
- DCOUNT
- DMAX
- DMIN

구조:

Database + Field + Criteria

### 가장 중요한 부분

Criteria range가 올바른 header와 condition 구조를 가져야 한다.

Database function은 Advanced Filter와 같은 criteria 논리를 공유한다.

- 같은 criteria row → AND
- 다른 criteria row → OR

---

# 13. 함수 중첩

한 함수의 결과를 다른 함수의 argument로 넣을 수 있다.

예:
=IF(AVERAGE(C2:E2)>=80,"우수","일반")

읽는 순서:

1. 내부 AVERAGE 계산
2. >=80 비교
3. IF 분기

→ Công thức lồng nhau nên đọc từ trong ra ngoài.

---

# 14. Error Values

## #DIV/0!

0으로 나눔.

## #VALUE!

잘못된 type 또는 argument.

## #REF!

Reference가 유효하지 않음.

## #NAME?

Function/name spelling 문제.

## #N/A

Lookup 등에서 값이 없음.

## #####

대개 column width 부족 등 display 문제.

### 실전 debugging 순서

1. Formula spelling
2. Parentheses
3. Range
4. Reference lock
5. Data type
6. Lookup exact/approximate option

# 15. 문제 문장 → 함수 선택

## Pattern A: “이상이면”

IF

## Pattern B: “조건에 맞는 개수”

COUNTIF / COUNTIFS

## Pattern C: “조건에 맞는 합계”

# 16. Formula 작성 순서 예제

문제:

“판매수량이 100 이상이고 평가가 A이면 우수, 아니면 일반으로 표시하시오.”

## Step 1

Output cell 확인.

## Step 2

조건 두 개 → AND.

## Step 3

IF와 결합.

=IF(AND(B2>=100,C2="A"),"우수","일반")

## Step 4

첫 row 결과를 데이터와 눈으로 비교.

## Step 5

Fill Handle.

---

# 17. 검산 방법

계산작업은 결과만 보고 맞다고 믿으면 안 된다.

## Boundary value

IF 조건이 >=80이면 79, 80, 81 같은 경계값을 확인한다.

## Lookup

찾는 key가 기준표의 첫 column/row에 실제로 존재하는지 확인한다.

## Reference

Formula Bar에서 $ 위치를 확인한다.

## Fill

첫 row와 마지막 row를 비교하여 reference 이동이 기대와 같은지 본다.

---

# 18. 자주 발생하는 감점 패턴

| 실수 | 원인 | 해결 |
|---|---|---|
| 함수는 맞지만 range가 틀림 | 문제 range 미확인 | argument별 range에 색을 mental mapping |
| 기준표가 내려감 | absolute reference 누락 | lookup table은 먼저 고정 여부 확인 |
| >= 와 > 혼동 | 조건어를 빨리 읽음 | 문제에서 이상/초과 구분 |
| Text에 quote 누락 | 문자열 처리 실수 | text result/criteria는 quote 확인 |
| IF 순서 오류 | threshold ordering 미정 | 큰 값부터 또는 논리 구간 먼저 설계 |
| VLOOKUP column index 오류 | table 구조 미확인 | table_array 안에서 몇 번째 column인지 세기 |
| Formula Fill 누락 | 첫 셀만 계산 | output range 전체 확인 |
