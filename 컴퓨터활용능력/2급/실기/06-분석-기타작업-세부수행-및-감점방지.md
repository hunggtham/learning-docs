# 06 — 분석·기타작업 세부 수행 및 감점 방지 매뉴얼

> **Baseline:** 대한상공회의소 컴퓨터활용능력 2급 실기 · 2024–2026 출제기준 · Microsoft Office LTSC 2021
> **배점 체계:** 분석작업 총 20점 (2문항 × 10점, **부분점수 없음**) + 기타작업 총 20점 (매크로 10점 + 차트 10점)
> **학습 공식:** 개념(Concept) → 동작 원리(Mechanism) → 비교 및 함정(Comparison/Trap) → 구체적 엑셀 조작(Concrete Excel Action) → 제한 시간 훈련(Timed Practice)

## 0. 분석·기타작업 배점과 '부분점수 0점'의 공포

컴활 2급 실기 수험생이 가장 방심하다가 불합격하는 영역이 바로 분석작업이다.
- **분석작업(20점):** 2문항이 출제되며, 각 문항당 10점이다. **부분점수가 일절 없다.** 피벗 테이블에서 옵션 하나를 빠뜨리거나, 부분합에서 정렬을 깜빡하면 문항 전체가 0점 처리되어 10점이 단번에 증발한다.
- **기타작업(20점):**
  - **매크로(10점):** 2문항 × 5점. 매크로 기록 및 버튼/도형 연결.
  - **차트(10점):** 5문항 × 2점. 부분점수가 있으나, 차트를 새로 만들면 0점 처리된다.

이 영역은 복잡한 논리 공식보다는 **"정확한 메뉴 조작 순서"**와 **"지시사항 누락 방지"**가 100% 점수를 결정한다.

## 1. 부분합 (Subtotal) — 정렬 선행과 이중 부분합

### Concept
데이터 표의 특정 필드를 기준으로 행들을 그룹화한 뒤, 그룹별로 합계, 평균, 개수, 최대값 등의 부분 통계를 자동으로 삽입하는 기능이다.

### Mechanism
엑셀의 부분합 엔진은 **데이터가 위에서 아래로 연속되어 있을 때만** 동일한 그룹으로 인식한다. 데이터가 섞여 있으면 동일한 그룹명이 등장할 때마다 부분합 행을 반복해서 삽입하므로 표가 완전히 망가진다.

### Comparison & Trap (3대 감점 함정)
1. **Trap 1 (치명적 0점): 사전 정렬(Sort) 누락**
   - 문제 지시문: *"부분합을 작성하기 전에 '부서'를 기준으로 오름차순 정렬하시오."*
   - 정렬을 하지 않고 부분합을 실행하면 그룹이 쪼개져 산출물이 완전히 달라지며, **10점 전액 0점**이다.
2. **Trap 2: 이중 부분합 시 '새로운 값으로 대치' 미해제**
   - 문제 지시문: *"합계를 구한 후, 평균을 추가로 계산하시오."*
   - 첫 번째 부분합(합계)을 만든 뒤 두 번째 부분합(평균) 대화상자에서 **`새로운 값으로 대치` 체크를 해제하지 않으면**, 기존에 구한 합계가 사라지고 평균만 남아 0점 처리된다.
3. **Trap 3: 윤곽(그룹) 지우기 요구**
   - 지시문에 *"부분합 결과의 윤곽(윤곽 기호)을 지우시오"* 가 포함된 경우, `데이터 → 그룹 해제 → 윤곽 지우기`를 실행하지 않으면 감점된다.

### Concrete Excel Action
1. 데이터 범위 내 임의의 셀 클릭.
2. `데이터` 탭 → `정렬` 클릭 → 기준 필드(예: `부서`), 정렬 방식(예: `오름차순`) 선택 후 `확인`.
3. `데이터` 탭 → 윤곽선 그룹의 `부분합` 클릭.
4. **1차 부분합 설정:**
   - `그룹화할 항목`: 정렬했던 필드 선택 (예: `부서`).
   - `사용할 함수`: 지시된 함수 선택 (예: `합계`).
   - `부분합 계산 항목`: 계산할 필드만 체크 (기존 체크된 엉뚱한 필드는 반드시 해제).
   - `확인` 클릭.
5. **2차 부분합 설정 (두 번째 함수 추가 시):**
   - 다시 `부분합` 클릭.
   - `사용할 함수`: 두 번째 지시된 함수 선택 (예: `평균`).
   - `부분합 계산 항목`: 대상 필드 체크.
   - **★ 핵심: `새로운 값으로 대치` 체크박스 클릭하여 해제!**
   - `확인` 클릭.

### Timed Practice (Target: 90초)
- **과제:** `[A2:F20]` 표에서 '직급' 기준 오름차순 정렬 후, 직급별 '기본급'의 합계와 '수당'의 평균을 계산하시오.
- **체크포인트:** 정렬 선행 여부, 2차 부분합 시 '새로운 값으로 대치' 해제 여부.

## 2. 피벗 테이블 (PivotTable) — 10점 전액 감점을 막는 체크리스트

### Concept
대량의 데이터를 행, 열, 값, 필터의 4개 차원으로 자유롭게 재배치하여 요약 집계하는 동적 보고서다.

### Mechanism
원본 데이터 표를 기반으로 피벗 캐시를 생성하고, 지시된 행/열 교차점에 값 필드의 요약 통계(합계, 평균 등)를 계산하여 표시한다.

### Comparison & Trap (단 1개라도 틀리면 10점 증발)
1. **Trap 1: 시작 위치 셀 오지정**
   - 문제: *"피벗 테이블 보고서는 [A20] 셀에서 시작하시오."*
   - 새 워크시트에 만들거나 A21 셀 등에 만들면 즉시 0점이다.
2. **Trap 2: 보고서 레이아웃 미지정 또는 잘못 지정**
   - 지시문: *"보고서 레이아웃을 '개요 형식으로 표시' 또는 '테이블 형식으로 표시'로 지정하시오."*
   - 기본 설정(압축 형식) 상태로 두면 레이아웃 감점으로 0점이다.
3. **Trap 3: 값 필드 서식을 일반 셀 서식(Ctrl+1)으로 변경**
   - 피벗 테이블 값 영역을 드래그해서 `Ctrl+1`로 서식을 바꾸면 피벗 새로고침 시 서식이 풀릴 수 있어 채점 엔진에서 감점된다.
   - **올바른 방법:** 값 필드 목록에서 해당 필드 클릭 → `값 필드 설정` → 좌측 하단 `표시 형식` 버튼 클릭 후 서식 지정.
4. **Trap 4: 피벗 테이블 옵션 세부 조건 누락**
   - 지시문: *"레이블이 있는 셀 병합 및 가운데 맞춤", "빈 셀은 '*'로 표시", "행의 총합계는 표시하지 마시오."*
   - 피벗 테이블 우클릭 → `피벗 테이블 옵션` 대화상자에서 이 세 가지 옵션을 반드시 설정해야 한다.

### Concrete Excel Action
1. 원본 표 클릭 → `삽입` 탭 → `피벗 테이블`.
2. 테이블/범위 확인 후, `기존 워크시트` 선택 → 위치 입력란에 지시된 셀(예: `A20`) 클릭 → `확인`.
3. 우측 피벗 테이블 필드 창에서 지시된 필드를 `행`, `열`, `값`, `필터` 영역으로 드래그.
4. 값 영역 필드가 기본 '합계'가 아닐 경우(예: '평균'): 값 필드 클릭 → `값 필드 설정` → `평균` 선택 → 좌측 하단 `표시 형식` 클릭 → 지정된 서식(통화, 숫자 등) 설정 후 `확인`.
5. 피벗 테이블 클릭 상태에서 상단 `디자인` 탭:
   - `보고서 레이아웃` → 지시된 형식(예: `개요 형식으로 표시`) 클릭.
   - `총합계` → 지시사항에 따라 `행의 총합계만 설정` 또는 `열의 총합계만 설정` 등 클릭.
6. 피벗 테이블 임의 셀 우클릭 → `피벗 테이블 옵션`:
   - `레이아웃 및 서식` 탭: `레이블이 있는 셀 병합 및 가운데 맞춤` 체크, `빈 셀 표시`에 `*` 입력.
   - `요약 및 필터` 탭: 총합계 표시 옵션 확인 후 `확인`.

### Timed Practice (Target: 2분)
- **과제:** 원본 데이터를 이용해 [A18] 셀부터 부서(행), 직급(열), 급여(값: 평균)를 배치하고, 개요 형식 표시, 빈 셀은 `**`로 표시하시오.

## 3. 데이터 표 (Data Table) — 1변수 vs 2변수 공식 매핑

### Concept
특정 수식에 사용된 1개 또는 2개의 변수 값이 바뀔 때, 결과 수식의 값이 어떻게 변하는지를 표 형태로 일괄 시뮬레이션하는 What-If 분석 도구다.

### Mechanism
- **1변수 데이터 표:** 변수가 행 방향(가로) 또는 열 방향(세로) 하나로만 나열됨.
- **2변수 데이터 표:** 가로 행과 세로 열에 각각 서로 다른 두 변수가 교차 배치됨.

### Comparison & Trap
- **Trap 1: 교차점 공식 셀 참조 누락 (2변수 표)**
  - 2변수 표에서 가로 행 머리글과 세로 열 머리글이 만나는 **좌측 상단 모서리 빈 셀**에 반드시 원본 수식을 연결(`=원본결과셀`)해야 한다. 이를 빠뜨리면 계산 결과가 모두 0이나 빈칸이 된다.
- **Trap 2: 행 입력 셀과 열 입력 셀의 혼동 (치명적)**
  - 데이터 표 대화상자에서:
    - **`행 입력 셀`:** 표의 **가로(행) 방향**으로 적혀있는 값들이 원본 수식에서 참조하는 원래 셀.
    - **`열 입력 셀`:** 표의 **세로(열) 방향**으로 적혀있는 값들이 원본 수식에서 참조하는 원래 셀.
  - 가로/세로를 반대로 지정하면 엉뚱한 수치가 계산되어 0점 처리된다.

### Concrete Excel Action (2변수 기준)
1. 결과 표의 좌상단 교차점 셀 클릭 → `=` 입력 후 원본 수식 셀(예: `C5`) 클릭 → `Enter`.
2. 교차점 수식 셀과 가로/세로 변수값 영역을 모두 포함하여 블록 지정 (예: `E5:J12`).
3. `데이터` 탭 → `예측` 그룹 → `가상 분석` → `데이터 표` 클릭.
4. `행 입력 셀` 클릭 후, 표의 가로 방향 값들이 대입될 원본 셀(예: `C2`) 클릭.
5. `열 입력 셀` 클릭 후, 표의 세로 방향 값들이 대입될 원본 셀(예: `C3`) 클릭.
6. `확인` 클릭.

### Timed Practice (Target: 60초)
- **과제:** 이자율(행)과 기간(열)의 변동에 따른 월 납입액 표를 데이터 표 기능을 이용해 산출하시오.

## 4. 시나리오 (Scenario) — 이름 정의와 요약 시트 위치

### Concept
다양한 가상 상황(예: 매출 20% 증가, 원가 10% 상승 등)을 미리 설정해 두고, 이에 따른 최종 결과값(예: 당기순이익)의 변화를 요약 보고서로 비교하는 도구다.

### Mechanism
변경 셀(Changing Cells)의 값을 시나리오별로 교체 대입하여 결과 셀(Result Cells)의 수식을 재계산한다.

### Comparison & Trap
1. **Trap 1 (치명적 0점): 이름 정의(Name Definition) 누락 또는 오타**
   - 문제 지시문: *"B10 셀의 이름은 '할인율', D15 셀의 이름은 '순매출'로 정의하시오."*
   - 시나리오를 만들기 전에 이름 정의를 하지 않으면 요약 보고서에 `할인율` 대신 `$B$10`이라는 셀 주소가 표시되어 **채점 시 오답(0점) 처리**된다.
   - 이름에 오타가 났다면 `수식 → 이름 관리자`(`Ctrl+F3`)에서 반드시 수정하거나 삭제 후 재작성해야 한다.
2. **Trap 2: 시나리오 요약 시트의 위치**
   - 엑셀은 시나리오 요약 보고서를 기본적으로 **현재 시트의 바로 앞(왼쪽)**에 생성한다.
   - 문제 지시문: *"시나리오 요약 시트는 [분석작업-1] 시트의 바로 뒤(오른쪽)에 위치시키시오."*
   - 이 경우 생성된 시트 탭을 마우스로 드래그하여 기준 시트 뒤로 이동시켜야 한다.

### Concrete Excel Action
1. 변경 셀(예: `B10`) 클릭 → 좌측 상단 이름 상자에 `할인율` 입력 후 `Enter`.
2. 결과 셀(예: `D15`) 클릭 → 이름 상자에 `순매출` 입력 후 `Enter`.
3. `데이터` 탭 → `가상 분석` → `시나리오 관리자` 클릭.
4. `추가` 클릭:
   - 시나리오 1: 이름에 `할인율 인상` 입력, 변경 셀에 `B10` 확인 후 `확인`. 값에 `0.15` 입력 후 `추가`.
   - 시나리오 2: 이름에 `할인율 인하` 입력, 변경 셀 확인 후 `확인`. 값에 `0.05` 입력 후 `확인`.
5. 시나리오 관리자 창에서 `요약` 버튼 클릭.
6. 보고서 종류 `시나리오 요약` 선택, 결과 셀에 `D15` 지정 후 `확인`.
7. 문제 지시사항에 따라 생성된 시트 탭 위치 확인 및 이동.

### Timed Practice (Target: 90초)
- **과제:** 집행률(B4)이 80%, 120%로 변할 때 집행금액(D10)의 변화를 시나리오로 작성하시오 (각 셀 이름 정의 필수).

## 5. 목표값 찾기 (Goal Seek) & 데이터 통합 (Consolidate)

### 5.1 목표값 찾기 (Goal Seek)

#### 3대 매개변수 구조
1. `수식 셀`: 결과값이 계산되어 있는 수식이 들어있는 셀.
2. `찾는 값`: 도달하고자 하는 목표 수치 (직접 키보드로 숫자 입력, 셀 참조 불가!).
3. `값을 바꿀 셀`: 목표값을 달성하기 위해 조정할 단일 입력 셀.

#### Concrete Excel Action
`데이터` → `가상 분석` → `목표값 찾기` → 3개 입력란 채운 후 `확인`. (30초 내 해결 가능)

---

### 5.2 데이터 통합 (Consolidate)

#### Concept & Trap
- 서로 다른 위치나 시트에 분산된 여러 데이터 표를 하나의 표로 합산/평균 집계하는 기능.
- **핵심 체크박스:** `사용할 레이블`에서 **`첫 행`**과 **`왼쪽 열`**을 반드시 둘 다 체크해야 표 머리글을 기준으로 정확히 매칭된다.

## 6. 기타작업 — 매크로 (Macro) 10점 완벽 확보법

### Concept & 배점
반복 작업을 자동화하는 매크로를 기록하고, 이를 워크시트에 삽입한 단추나 도형에 연결한다. 2문항 × 5점 = 10점.

### Comparison & Trap (5대 감점 요소)
1. **Trap 1 (치명적): 기록 시작 전 임의의 빈 셀 미선택**
   - 이미 데이터 범위(예: `A3`)를 선택한 상태에서 매크로 기록을 시작하면, 셀 선택 동작이 매크로에 포함되지 않아 버튼을 누를 때 엉뚱한 셀에 서식이 적용될 수 있다.
   - **철칙:** **매크로 기록 버튼을 누르기 전에 반드시 데이터 표 바깥의 임의의 빈 셀(예: `A1` 또는 `빈 셀`)을 클릭해 둔다.**
2. **Trap 2: 단추/도형 생성 시 Alt 키 미사용**
   - 문제: *"[E12:F13] 영역에 단추를 생성하시오."*
   - 마우스로 대충 그리면 셀 경계선과 오차가 발생하여 감점된다. **`Alt` 키를 누른 채 마우스를 드래그**하면 셀 모서리에 자석처럼 완벽하게 밀착(Snap)된다.
3. **Trap 3: 단추/도형 텍스트 오타**
   - 단추의 텍스트가 지시문과 한 글자라도 다르면(공백 포함) 5점 감점이다.
4. **Trap 4: 개발 도구 탭 미표시**
   - 리본 메뉴에 `개발 도구`가 없으면 `파일 → 옵션 → 리본 사용자 지정`에서 `개발 도구`에 체크한다. 단, 상단 `보기` 탭의 `매크로` 메뉴를 이용해도 무방하다.

### Concrete Excel Action
#### [매크로 1: 서식 적용 매크로]
1. 데이터 표 바깥 빈 셀 클릭.
2. `개발 도구` 탭 → `매크로 기록` 클릭.
3. 매크로 이름 입력 (예: `서식적용`) → `확인` (이 순간부터 모든 조작이 녹화됨).
4. 지시된 작업 범위 드래그 (예: `A3:E3`) → 지시된 서식 적용 (예: 노랑 채우기).
5. 데이터 바깥 빈 셀 클릭.
6. `개발 도구` 탭 → `기록 중지` 클릭.

#### [버튼 생성 및 매크로 연결]
1. `개발 도구` 탭 → `삽입` → `양식 컨트롤`의 `단추` 클릭 (도형 지시 시 `삽입` → `도형`).
2. 키보드 `Alt` 키를 누른 채 지시된 영역(예: `G2:H3`)에 마우스 드래그.
3. 마우스를 놓으면 자동으로 뜨는 `매크로 지정` 창에서 방금 기록한 `서식적용` 선택 후 `확인`.
4. 단추 우클릭 → `텍스트 편집` 클릭 → 기존 글자를 지우고 지시된 텍스트(예: `서식적용`) 입력.
5. 빈 셀 클릭하여 편집 완료. 반드시 버튼을 클릭하여 정상 동작 확인.

## 7. 기타작업 — 차트 (Chart) 5문항 10점 만점 테크닉

### 절대 원칙
**"기존 차트를 수정하시오. 신규로 차트를 작성하면 0점 처리됩니다."**
시험지에 이미 제공된 차트 개체를 반드시 클릭하여 편집해야 한다.

### 5대 단골 수정 유형과 정밀 조작법
1. **데이터 계열 추가 및 제거:**
   - 제거: 차트 내에서 해당 막대나 꺾은선을 클릭하고 `Delete` 키.
   - 추가: 추가할 데이터 영역을 워크시트에서 복사(`Ctrl+C`) → 차트 선택 후 붙여넣기(`Ctrl+V`). 또는 차트 우클릭 → `데이터 선택`에서 `추가` 버튼 이용.
2. **차트 종류 변경 및 보조 축 지정 (이중 축 혼합형):**
   - 차트 우클릭 → `차트 종류 변경` → 좌측 하단 `혼합` 클릭.
   - 특정 계열의 차트 종류를 `표식이 있는 꺾은선형`으로 바꾸고, 우측 `보조 축` 체크박스 체크.
3. **데이터 레이블 추가 (특정 요소 단독 지정):**
   - 전체 막대에 레이블을 넣을 때는 막대를 한 번 클릭.
   - **특정 막대 하나에만 넣을 때:** 막대를 클릭한 후, 1초 뒤 해당 막대를 **다시 한 번 클릭(단독 선택 확인)** → 우클릭 → `데이터 레이블 추가`.
4. **축 서식 (주 단위, 최소/최대값):**
   - 축 숫자 더블클릭 → 우측 축 서식 창에서 `축 옵션` 아이콘 클릭.
   - `최소값`, `최대값`, `주 단위`를 지시된 숫자로 입력 (입력 후 자동으로 바뀌지 않도록 수치 확정).
5. **차트 제목 셀 연동:**
   - 차트 요소 추가(+)에서 `차트 제목` 삽입.
   - 차트 제목 박스의 테두리를 클릭하여 선택한 상태에서, **상단 수식 입력줄을 클릭**하고 `=A1` 입력 후 `Enter`. (제목 텍스트 안에 커서가 깜빡이는 상태에서 입력하면 연동되지 않음).
