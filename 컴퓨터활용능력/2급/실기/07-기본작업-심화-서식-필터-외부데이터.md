# 07 — 기본작업 심화 — 사용자 지정 표시 형식·조건부 서식 수식·고급 필터 논리식

> **Baseline:** 대한상공회의소 컴퓨터활용능력 2급 실기 · 2024–2026 출제기준 · Microsoft Office LTSC 2021
> **배점 체계:** 기본작업 총 20점 (기본작업-1 5점 + 기본작업-2 10점[5문항×2점] + 기본작업-3 5점)
> **학습 공식:** 개념(Concept) → 동작 원리(Mechanism) → 비교 및 함정(Comparison/Trap) → 구체적 엑셀 조작(Concrete Excel Action) → 제한 시간 훈련(Timed Practice)

---

## 0. 기본작업의 20점 배점 구조와 전략적 우선순위

기본작업은 시험 시작 후 수험생이 가장 먼저 마주하는 영역이다.
- **기본작업-1 (자료 입력, 5점):** 주어진 표 데이터를 있는 그대로 타이핑하는 작업. 오타나 띄어쓰기 오류 1개당 감점되며 시간이 많이 소요된다. **전략적으로 시험 마지막에 작성하거나 40분 타임어택 후순위로 미루는 것이 안전**하다.
- **기본작업-2 (셀 서식 및 편집, 10점 = 5문항 × 2점):** 문항당 2점으로 부분 감점이 적용된다. 표시 형식, 이름 정의, 메모, 병합, 테두리 등 정밀 조작이 핵심이다.
- **기본작업-3 (고급 필터 / 조건부 서식 / 텍스트 나누기 / 외부 데이터, 5점):** 단일 5점 문항이며 **부분점수가 없다.** 조건식이나 범위가 1개라도 어긋나면 5점 전액 감점된다.

## 1. 사용자 지정 표시 형식 (Custom Number Format) 정밀 공략

### Concept
셀의 실제 데이터 값은 전혀 변경하지 않은 채, 화면에 보이는 형태와 출력 모양만을 포맷 기호 규칙으로 변경하는 기능이다.

### Mechanism: 4구역 구분 구조
사용자 지정 서식은 세미콜론(`;`)으로 최대 4개의 영역을 구분한다.
```text
양수 서식 ; 음수 서식 ; 0 서식 ; 텍스트 서식
```
- 예: `#,##0원;[빨강]-#,##0원;"-";@ "귀하"`
  - 양수가 입력되면 천 단위 쉼표와 함께 `1,000원` 표시
  - 음수가 입력되면 빨간색 글씨로 `-1,000원` 표시
  - 0이 입력되면 `-` 기호 표시
  - 텍스트가 입력되면 뒤에 ` 귀하` 추가

### 주요 서식 기호와 동작 원리
| 기호 | 역할 및 동작 원리 | 예시 (입력값: 15) | 서식 적용 결과 |
|---|---|---|---|
| `0` | 자릿수 채움 (유효하지 않은 0도 강제 표시) | `000` | `015` |
| `#` | 유효한 자릿수만 표시 (의미 없는 0은 숨김) | `###` | `15` |
| `?` | 소수점 정렬을 위해 유효하지 않은 0을 공백으로 둠 | `?.?` | `15. ` |
| `,` | 천 단위 구분 기호 또는 끝에 붙여 자릿수 축약 | `#,##0,` | `0` (천 단위 절삭) |
| `@` | 문자열 대치 기호 | `@ "팀장"` (입력: 홍길동) | `홍길동 팀장` |

### Comparison & Trap (단골 출제 함정)
1. **천 단위 절삭 (쉼표 생략/추가 함정):**
   - 문제: *"1,250,000을 1,250(천원)으로 표시하시오."*
   - 서식 코드: `#,##0,` (맨 뒤에 쉼표 1개).
   - 문제: *"백만 단위로 절삭하시오."* → `#,##0,,` (맨 뒤에 쉼표 2개).
2. **조건식과 색상 지정의 위치:**
   - 대괄호(`[...]`) 안에 색상과 조건을 지정한다. **반드시 서식 기호보다 앞에 위치**해야 한다.
   - 예: `[파랑][>=1000]#,##0;[빨강][<500]#,##0;#,##0`
3. **날짜 및 요일 표시 형식:**
   - 연도: `yyyy` (2026), `yy` (26)
   - 월: `mm` (07), `m` (7)
   - 일: `dd` (07), `d` (7)
   - **요일 표시 (핵심 함정):**
     - `aaa`: 요일 1글자 (예: `수`)
     - `aaaa`: 요일 풀네임 (예: `수요일`)
     - `ddd`: 영문 약어 (예: `Wed`)
     - `dddd`: 영문 전체 (예: `Wednesday`)
   - 문제: *"2026-10-07 (수) 형태로 표시하시오."* → `yyyy-mm-dd (aaa)`

### Concrete Excel Action
1. 서식을 변경할 셀 범위 드래그 선택.
2. `Ctrl + 1` 눌러 `셀 서식` 대화상자 호출.
3. `표시 형식` 탭 → 좌측 분류에서 `사용자 지정` 클릭.
4. `형식(T)` 입력란에 커서를 두고 지시된 코드(예: `[빨강][>=1000]#,##0;[파랑]#,##0`) 입력.
5. `확인` 클릭.

### Timed Practice (Target: 30초)
- **과제:** `[C3:C12]` 영역의 수량 뒤에 "개"를 표시하되, 0일 때는 "없음"으로 표시하시오.
- **서식 코드:** `#,##0"개";-#,##0"개";"없음"`

## 2. 기본작업-2 셀 편집 정밀 테크닉

### 2.1 셀 병합 vs 선택 영역의 가운데로

- **`셀 병합하고 가운데 맞춤` (Merge & Center):**
  - 여러 셀을 물리적으로 하나의 셀로 합치고 내용을 가운데 정렬한다.
  - 리본 메뉴 `홈` 탭의 `병합하고 가운데 맞춤` 클릭.
- **`선택 영역의 가운데로` (Center Across Selection):**
  - **셀을 실제로 병합하지 않으면서** 선택한 여러 열의 중앙에 첫 셀의 텍스트가 걸쳐 보이게 하는 기능.
  - **조작:** 범위 선택 → `Ctrl+1` → `맞춤` 탭 → `텍스트 맞춤`의 `가로` 목록에서 `선택 영역의 가운데로` 선택.
  - **Trap:** 문제에서 "선택 영역의 가운데로"를 요구했는데 "셀 병합"을 누르면 즉시 감점이다.

---

### 2.2 이름 정의 (Name Definition) 및 관리

#### Mechanism
특정 셀이나 영역에 영문/한글 이름을 부여하여 수식이나 기타 작업에서 절대 주소 대신 의미 있는 이름으로 참조하게 한다.

#### Concrete Excel Action
1. 범위 지정 → 좌측 상단 `이름 상자` 클릭 → 이름(예: `판매수량`) 입력 후 `Enter`.
2. **오타 수정 및 삭제 (이름 관리자):**
   - 만약 이름을 잘못 입력했다면 이름 상자에서 다시 입력하면 안 된다 (두 개의 이름이 중복 정의됨).
   - 반드시 상단 `수식` 탭 → `이름 관리자` (`Ctrl + F3`) 실행 → 잘못된 이름 선택 후 `편집` 또는 `삭제`.

---

### 2.3 셀 메모 (Cell Comment / Note) 완벽 서식

#### 3대 출제 필수 조건
1. **메모 삽입 및 텍스트:** 셀 우클릭 → `메모 삽입` (또는 새 메모). 기본 사용자 ID 문자열 삭제 후 지시된 내용 입력.
2. **항상 표시:** 셀 우클릭 → `메모 표시/숨기기` 클릭.
3. **자동 크기 (치명적 조작 함정):**
   - **Trap:** 메모의 글자 안에서 우클릭하여 `메모 서식`을 누르면 글꼴 탭만 나타나고 맞춤 탭이 없다!
   - **올바른 조작:** **메모 박스의 테두리 실선(외곽 경계선)** 을 클릭한 상태에서 우클릭 → `메모 서식` 클릭 → `맞춤` 탭 클릭 → **`자동 크기`** 체크박스 선택 후 `확인`.

---

### 2.4 테두리 서식 (대각선 및 이중 실선)

- 빈 셀(예: 표의 우하단 사선 처리) 클릭 → `Ctrl+1` → `테두리` 탭.
- 대각선 버튼(좌하향/우하향) 클릭.
- 표 제목 아래나 합계 행 아래에 `이중 실선` 스타일을 선택하고 `아래쪽 테두리` 적용.

## 3. 조건부 서식 수식 작성법 (Conditional Formatting)

### Concept
주어진 수식 조건(참/거짓)을 만족하는 행 또는 셀에만 글꼴 색, 채우기 색 등의 서식을 동적으로 적용한다.

### Mechanism: 행 전체 강조 vs 단일 열 강조
- **절대 원칙 1: 범위 지정 시 열 머리글(Header)은 제외한다.**
  데이터가 시작되는 첫 데이터 행부터 끝 행까지 드래그한다 (예: `A3:E15`).
- **절대 원칙 2: 행 전체에 서식을 적용할 때는 혼합 참조(`$열번호`)를 사용한다.**
  - 조건 대상이 C열의 점수인 경우: `=$C3>=80`
  - 열(`$C`)은 고정하여 다른 열의 셀들도 C열의 값을 검사하게 하고, 행(`3`)은 상대 참조로 두어 아래 행으로 내려가면서 행마다 각자의 값을 검사하게 한다.
  - 만약 `$C$3`으로 절대 참조하면 모든 행이 3행의 점수만 보고 동일하게 서식이 칠해지는 대참사가 발생한다.

### Comparison & Trap (단골 함수 결합)
1. **AND 결합:**
   ```excel
   =AND($B3="기획부", $D3>=90)
   ```
2. **OR 결합:**
   ```excel
   =OR($B3="인사부", $B3="총무부")
   ```
3. **통계/문자열 함수 결합:**
   - 전체 평균 이상인 행:
     ```excel
     =$C3>=AVERAGE($C$3:$C$15)
     ```
     *(주의: AVERAGE의 비교 대상 전체 범위는 `$C$3:$C$15`로 절대 참조 고정해야 함).*
   - 사번의 왼쪽 1자리가 "A"인 행:
     ```excel
     =LEFT($A3, 1)="A"
     ```

### Concrete Excel Action
1. 데이터 범위 드래그 (예: `A3:F18`, 머리글 제외).
2. `홈` 탭 → `조건부 서식` → `새 규칙`.
3. 규칙 유형에서 `▶ 수식을 사용하여 서식을 지정할 셀 결정` 클릭.
4. 수식 입력란에 커서를 두고 `=AND($B3="영업", $E3>=500)` 입력.
5. 우측 하단 `서식` 버튼 클릭 → `글꼴` 탭(굵게, 글꼴 색 지정) 또는 `채우기` 탭(배경색 지정) 설정 후 `확인`.
6. 새 규칙 창에서 `확인`.

### Timed Practice (Target: 60초)
- **과제:** `[A3:G20]` 영역에서 생년월일(D열)의 연도가 2000 이상이고 총점(F열)이 80 이상인 행 전체에 글꼴 스타일 '굵게', 글꼴 색 '파랑'을 적용하시오.
- **수식:** `=AND(YEAR($D3)>=2000, $F3>=80)`

## 4. 고급 필터 (Advanced Filter) — 논리식 vs 일반식의 절대 차이

### Concept
복잡한 조건을 별도의 조건 범위(Criteria Range)에 작성하고, 조건을 만족하는 행들만 추출하여 현재 위치에 필터링하거나 다른 위치로 복사하는 기능이다.

### Mechanism: 일반식 조건 vs 논리식 조건
컴활 2급 실기에서 고급 필터는 다음 두 가지 방식 중 하나로 출제되며, 규칙이 완전히 다르다.

| 구분 | 일반식 조건 (Direct Criteria) | 논리식 조건 (Formula Criteria) |
|---|---|---|
| **출제 형태** | 단순 텍스트 일치 또는 부등호 비교 | 함수 수식 사용 (예: AVERAGE, LEFT 등) |
| **조건 머리글 규칙** | **원본 표의 열 머리글과 100% 동일해야 함** | **원본 머리글과 다른 임의의 이름(예: `조건`) 사용 필수!** |
| **조건값 표기** | `영업부`, `>=80` 등 값 직접 입력 | `=C3>=AVERAGE($C$3:$C$20)` 형태의 수식 |

### Comparison & Trap (치명적 감점 함정)
1. **논리식에서 원본 머리글명 사용 시 0점:**
   - 논리식 조건을 작성하면서 조건 머리글을 원본과 똑같이 `점수`라고 쓰면 엑셀 엔진이 필드와 수식을 정상 매칭하지 못해 필터링 결과가 비정상적으로 나오며 **5점 전액 0점**이다. 반드시 `조건` 또는 다른 이름을 써야 한다.
2. **AND / OR 조건 배치 규칙:**
   - **AND 조건:** 조건값들을 **같은 행**에 나란히 작성.
   - **OR 조건:** 조건값들을 **서로 다른 행**에 엇갈려 작성.
3. **특정 열만 추출할 때의 사전 복사 누락:**
   - 지시문: *"결과는 [A20] 셀부터 '성명', '부서', '급여' 열만 표시하시오."*
   - 고급 필터 창을 열기 전에 **반드시 워크시트에서 해당 3개 열 머리글을 복사하여 [A20:C20]에 미리 붙여넣어 두어야 한다.** 그리고 고급 필터 대화상자의 `복사 위치`에 해당 머리글 범위(`A20:C20`)를 지정해야 한다.

### Concrete Excel Action (논리식 + 특정 열 추출)
1. 원본 표에서 추출할 열 머리글(`성명`, `직급`, `총점`)을 복사(`Ctrl+C`)하여 복사 시작 셀(예: `A20`)에 붙여넣기(`Ctrl+V`).
2. 조건 지정 영역(예: `G2:G3`)에:
   - `G2` 셀에 `조건` 입력.
   - `G3` 셀에 `=C3>=AVERAGE($C$3:$C$15)` 입력.
3. 원본 데이터 표 클릭.
4. `데이터` 탭 → `고급` 클릭.
5. 고급 필터 대화상자:
   - 결과: **`다른 장소에 복사`** 라디오 버튼 선택.
   - 목록 범위: 원본 전체 표(머리글 포함, 예: `$A$2:$F$15`).
   - 조건 범위: `$G$2:$G$3`.
   - 복사 위치: 미리 붙여넣은 머리글 범위 지정 (예: `$A$20:$C$20`).
6. `확인` 클릭.

### Timed Practice (Target: 90초)
- **과제:** 부서(B열)가 "영업부"이거나 급여(E열)가 3,000,000 이상인 데이터를 고급 필터를 이용하여 [A22] 셀에 추출하시오.
- **체크포인트:** OR 조건 행 분리, 복사 위치 라디오 버튼 선택.

## 5. 텍스트 나누기 및 외부 데이터 가져오기

### 5.1 텍스트 나누기 (Text to Columns)
- 한 셀에 구분 기호(쉼표, 공백, 탭, 세미콜론)로 결합된 텍스트 데이터를 여러 열로 분리.
- **조작:** 열 범위 선택 → `데이터` → `텍스트 나누기` → `구분 기호로 분리됨` 선택 → 다음 → 해당 구분 기호 체크 → 다음 → 특정 열을 제외하라는 지시가 있으면 `열 가져오지 않음(건너뜀)` 선택 후 `마침`.

---

### 5.2 외부 데이터 가져오기 (텍스트/CSV 파일)
- 문제 지시문: *"외부 데이터 [성적.txt] 파일을 열고 [A3] 셀부터 배치하시오."*
- `데이터` 탭 → `텍스트/CSV에서` (또는 기존 마법사) 클릭 → 파일 선택 → 구분 기호 설정 → 로드 위치를 `기존 워크시트`의 지시된 셀(예: `A3`)로 지정.
