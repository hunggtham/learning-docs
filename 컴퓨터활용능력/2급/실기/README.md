# 컴퓨터활용능력 2급 실기 — Index

실기는 **스프레드시트 실무** 한 과목이며 시험시간은 40분이다. 이 문서는 Excel 기능을 메뉴별로 나열하지 않고 실제 작업 흐름과 배점 체계(100점 만점, 70점 이상 합격)에 맞추어 구성한다.

## Dependency

기본작업의 range 정확성 (01, 07)
→ 계산작업의 reference 정확성 및 함수 구문 (02, 05)
→ 분석작업의 0점 방지 순서 (03, 06)
→ 기타작업의 output/procedure 정확성 (04, 06)
→ timed mock에서 통합 (90)

> **상태:** 2024–2026 공식 출제기준 및 연습예제 배점/함수 목록에 맞춘 심화 실무 매뉴얼(05~07) 완비. 100점 전체 영역에 걸쳐 무감점 프로토콜을 제공한다.
