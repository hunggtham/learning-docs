# 컴퓨터활용능력 2급 — Study Map

Đây là bản đồ học cho **컴퓨터활용능력 2급**. File hiện chỉ khóa cấu trúc trước khi viết nội dung chi tiết.

## Cấu trúc kỳ thi

| 구분 | 과목 | 형식 | 시간 |
|---|---|---|---:|
| 필기 | 컴퓨터 일반 + 스프레드시트 일반 | 객관식 40문항 | 40분 |
| 실기 | 스프레드시트 실무 | 컴퓨터 작업형 | 40분 |

필기 cần đạt tối thiểu 40 điểm từng môn và trung bình 60 điểm; 실기 cần 70 điểm trở lên.
