# 컴퓨터활용능력 2급 — Study Map

이 문서는 컴퓨터활용능력 2급의 canonical learning route다. 현재 baseline은 **2024–2026 출제기준**이며, 필기에서 개념을 이해한 뒤 실기에서 같은 개념을 실제 Excel 동작으로 전환한다.

## 시험 구조

| 구분 | 과목 | 형식 | 시간 |
|---|---|---|---:|
| 필기 | 컴퓨터 일반 + 스프레드시트 일반 | 객관식 40문항 | 40분 |
| 실기 | 스프레드시트 실무 | 컴퓨터 작업형 | 40분 |

합격 기준:

- 필기: 각 과목 40점 이상 + 전체 평균 60점 이상
- 실기: 70점 이상

2024–2026 시험 환경은 Windows 10과 Microsoft Office LTSC 2021을 baseline으로 한다.

## Dependency

필기:
컴퓨터 일반 + 스프레드시트 일반
→ 개념 판별
→ 필기 문제풀이 전략

실기:
기본작업
→ 계산작업
→ 분석작업
→ 기타작업
→ 실전 모의고사

## 필기와 실기의 연결

| 필기 concept | 실기 action |
|---|---|
| Cell/Range | 기본작업 |
| Format/Filter | 기본작업 |
| Reference/Function | 계산작업 |
| What-if/Pivot | 분석작업 |
| Chart/Macro | 기타작업 |
