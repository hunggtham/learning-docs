## 학습 원칙

**컴퓨터 일반**은 비교 pair를 중심으로 학습한다.

RAM ↔ ROM, HDD ↔ SSD, LAN ↔ WAN, SMTP ↔ IMAP, Encryption ↔ Hash처럼 “무엇이 다른가”를 설명할 수 있어야 한다.

**스프레드시트 일반**은 각 기능을 실기 action으로 연결한다.

Reference → 계산작업  
Filter/Format → 기본작업  
What-if/Pivot → 분석작업  
Chart/Macro → 기타작업
