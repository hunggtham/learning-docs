# 90 — 필기 문제풀이 전략

> **시험 구조:** 2급 필기는 컴퓨터 일반 + 스프레드시트 일반, 객관식 40문항, 40분이다. 과목별 40점 이상이면서 전체 평균 60점 이상이어야 한다.  
> **핵심 목표:** “모든 내용을 완벽히 암기”하는 것이 아니라 **과락을 막고, 쉬운 문제를 먼저 확보하고, 비교형 함정을 빠르게 제거하는 것**이다.

## 1. 점수 전략부터 이해한다

2급 필기는 평균 60점만 넘으면 되는 시험이지만, 한 과목이라도 40점 미만이면 불합격이다.  
→ Vì vậy chiến lược đúng không phải dồn toàn bộ thời gian cho Excel rồi bỏ 컴퓨터 일반. Trước hết phải giữ từng môn vượt ngưỡng an toàn.

### 안전 목표

실전에서는 각 과목을 최소 합격선에 맞추기보다 **70점 이상을 안정권 목표**로 잡는 편이 좋다.

이유:

- CBT/상시검정에서 체감 난이도가 다를 수 있음
- 한두 개의 낯선 문제 때문에 점수가 흔들릴 수 있음
- 평균 60점만 목표로 하면 과락 위험이 커짐

---

# 2. 40분을 어떻게 쓸 것인가

40문항/40분이므로 평균 1문항당 약 1분이다. 그러나 실제로 모든 문제에 1분씩 쓰면 마지막 검토 시간이 없다.

추천 흐름:

1. **1차:** 즉시 판단 가능한 문제를 빠르게 해결
2. **2차:** 비교/계산/함수 문제 처리
3. **3차:** 표시해 둔 문제 재검토
4. **마지막:** 답 미입력 여부 확인

### 1차에서 오래 고민하지 않는다

20~30초 안에 핵심 개념이 안 떠오르면 표시하고 넘어간다.  
→ Một câu khó không nên lấy thời gian của ba câu dễ.

---

# 3. 컴퓨터 일반 문제 풀이법

컴퓨터 일반은 정의형보다 **비교형**으로 학습하면 효율이 높다.

대표 비교:

- RAM vs ROM
- Cache vs RAM
- HDD vs SSD
- LAN vs WAN
- SMTP vs POP3/IMAP
- Cache vs Cookie
- Virus vs Worm
- Authentication vs Authorization
- Encryption vs Hash

문제를 읽을 때 먼저 “두 개념을 나누는 결정적 기준이 무엇인가?”를 찾는다.

### 예시 사고법

문제: “다음 중 웜(Worm)에 대한 설명으로 옳은 것은?”

잘못된 접근:
- 웜 정의 문장을 통째로 기억하려고 함

좋은 접근:
- 바이러스와 차이점은?
- 웜은 독립적으로 자기 복제/네트워크 전파 가능
- “반드시 다른 실행파일에 기생” 같은 선지는 제거

# 4. 스프레드시트 일반 문제 풀이법

Excel 문제는 크게 세 종류로 나눈다.

## 4.1 개념 판별형

예:
- Workbook vs Worksheet
- Sort vs Filter
- Goal Seek vs Scenario
- Conditional Formatting vs Data Validation

→ 목적과 결과가 무엇인지 비교한다.

## 4.2 수식 결과형

예:
- 상대/절대 참조
- 연산 우선순위
- 함수 결과

→ 종이에 식을 다시 쓰는 것보다 **참조가 복사 후 어떻게 바뀌는지** 먼저 추적한다.

## 4.3 기능 절차형

예:
- 고급 필터
- 부분합
- PivotTable
- Print Area
- Macro

→ 메뉴명을 외우기보다 선행 조건을 기억한다.

예:
부분합 → 그룹 기준 정렬이 먼저 필요  
고급 필터 → criteria range 구조 이해 필요

# 5. 함수 문제를 푸는 decision tree

함수 이름을 보고 뜻을 떠올리는 방식보다, 문제 문장을 함수 종류로 변환한다.

## Step 1. 무엇을 계산하는가?

- 합계 → SUM
- 평균 → AVERAGE
- 개수 → COUNT/COUNTA
- 최대/최소 → MAX/MIN

## Step 2. 조건이 있는가?

- 조건에 따라 결과 분기 → IF
- 조건 만족 개수 → COUNTIF
- 조건 만족 합계 → SUMIF
- 여러 조건 → IFS 계열 또는 AND/OR와 조합

## Step 3. 문자열인가?

- 왼쪽 → LEFT
- 오른쪽 → RIGHT
- 중간 → MID
- 길이 → LEN

## Step 4. 날짜인가?

- 연도 → YEAR
- 월 → MONTH
- 일 → DAY
- 오늘 → TODAY

## Step 5. 표에서 찾는가?

- 세로 lookup → VLOOKUP
- 가로 lookup → HLOOKUP

이 tree를 반복하면 함수 암기량보다 문제 해석 능력이 먼저 올라간다.

# 6. 셀 참조 문제 푸는 법

수식이 복사될 때는 각 참조를 독립적으로 본다.

예:
=$A2*B$1

한 행 아래로 복사하면:

- $A2 → $A3
- B$1 → B$1

한 열 오른쪽으로 복사하면:

- $A2 → $A2
- B$1 → C$1

### 기억법

$는 바로 뒤의 축을 고정한다.

- $A → column 고정
- $1 → row 고정

# 7. 선지 소거법

## 7.1 지나치게 절대적인 표현

“항상”, “반드시”, “모든 경우”, “절대로”가 있으면 예외가 존재하는지 확인한다.

예:
“삭제한 파일은 모두 휴지통으로 간다.”  
→ Shift+Delete 등의 예외 존재.

## 7.2 계층이 섞인 문장

예:
“RAM은 전원을 꺼도 장기간 데이터를 보관하는 보조기억장치다.”  
→ RAM의 역할과 SSD/HDD의 역할이 섞였다.

## 7.3 목적이 뒤바뀐 문장

예:
“DNS는 자동으로 IP 주소를 임대한다.”  
→ DHCP 설명에 가깝다.

## 7.4 Excel에서 값과 표시를 혼동

예:
“조건부 서식은 셀의 실제 값을 변경한다.”  
→ 표시를 바꾸는 기능이다.

# 8. 오답노트 taxonomy

오답을 단순히 “틀린 문제”로 저장하면 반복 효과가 낮다. 원인별로 분류한다.

## A. Knowledge Missing

개념 자체를 몰랐다.

처리:
해당 chapter로 돌아가 mental model을 다시 만든다.

## B. Confusion Pair

두 개념을 혼동했다.

예:
SMTP vs IMAP  
COUNT vs COUNTA

처리:
A/B 비교표 한 줄을 만든다.

## C. Condition Miss

조건이나 예외를 놓쳤다.

예:
“정확히 일치”, “복사 후”, “같은 행”, “모든 경우”.

처리:
문제 문장의 조건어에 표시한다.

## D. Calculation Error

연산 순서, 참조 이동, 함수 argument를 실수했다.

처리:
계산 과정을 단계별로 다시 쓴다.

## E. UI Memory Error

기능은 이해하지만 메뉴/동작을 틀렸다.

처리:
실제 Excel에서 한 번 수행한다.

# 9. 기출/복원 문제 회독법

## 1회차 — 진단

시간 제한 없이 풀고 오답 원인을 taxonomy로 분류한다.

목표:
내가 무엇을 모르는지 찾는 것.

## 2회차 — 개념 연결

각 문제를 chapter 개념과 연결한다.

예:
문제 → 고급 필터 → 같은 행 AND / 다른 행 OR

## 3회차 — 속도

40분 제한을 적용한다.

## 4회차 — 변형 대응

선지 문구가 바뀌어도 판단할 수 있는지 확인한다.

정답 번호를 외운 상태라면 회독 효과가 낮다.  
→ Phải giải thích được vì sao các lựa chọn sai thì mới coi là đã học.

# 10. 과락 방지 체크

컴퓨터 일반에서 다음 영역이 모두 약하면 위험하다.

- Windows/OS
- Hardware/Memory
- Internet/Protocol
- Security

스프레드시트 일반에서 다음 영역이 모두 약하면 위험하다.

- Cell reference
- Function
- Data management
- Chart/Print/Macro

특정 한 chapter만 완벽하게 하고 나머지를 비우지 않는다.
