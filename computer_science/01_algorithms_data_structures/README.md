# Algorithms & Data Structures — Domain Hub

Phần nền tảng của domain này nằm tại [`../basic/01_algorithms_data_structures/`](../basic/01_algorithms_data_structures/). Đây là nơi xây mental model về algorithmic thinking, correctness, complexity, memory/data layout, array/list/stack/queue, hashing, trees, graphs, sorting/searching, dynamic programming, randomized/online algorithms và complexity reductions.

Phần [`advanced/`](./advanced/README.md) là **Knowledge Library DSA chuyên sâu**, đi sâu vào representation, invariant, proof, implementation, runtime behavior và edge cases bằng **C, Java và JavaScript**.

## Khi nào chuyển từ Basic sang Advanced?

Foundation nên đủ để trả lời được vì sao representation quyết định cost, Big-O mô tả growth gì, invariant dùng để reasoning correctness ra sao, và array/hash/tree/graph khác nhau ở mental model nào. Khi các câu hỏi đó đã rõ và bạn muốn đi sâu vào implementation, proof, specialized structures, cache/runtime behavior hoặc language-specific trade-offs, hãy chuyển sang Advanced.

**[Bắt đầu Advanced Data Structures & Algorithms](./advanced/README.md)**

Advanced DSA hiện bao gồm các cấu trúc và thuật toán sâu hơn như balanced/augmented trees, B/B+Tree, skip list, Fenwick/Segment Tree, sparse table, flow/matching, suffix structures, probabilistic structures, reduction/NP reasoning và implementation tương ứng trong C, Java và JavaScript.
