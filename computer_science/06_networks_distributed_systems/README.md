# Networks & phân tán (distributed / 분산) các hệ thống (systems / 시스템들) — lĩnh vực (domain / 도메인) Hub

> **Mạch đọc:** Đọc **Networks & phân tán (distributed / 분산) các hệ thống (systems / 시스템들) — lĩnh vực (domain / 도메인) Hub** như một mắt xích của lộ trình học (learning path / 학습 경로) hiện tại, không như một ghi chú tách rời. Hãy xác định đối tượng và câu hỏi trung tâm trước, rồi dùng phần này để đối chiếu với mục liên quan sau khi đã nắm mô hình tư duy (mental model / 사고 모델) chính.

Foundation nằm tại [`../basic/06_networks_distributed_systems/`](../basic/06_networks_distributed_systems/): packet/layering, Ethernet/IP/routing, TCP/UDP, DNS/HTTP/TLS, consistency, replication, consensus, IPv6/BGP và QUIC.

Phần [`advanced/`](./advanced/README.md) tập trung vào thất bại (failure / 실패) ngữ nghĩa (semantics / 의미론), phân tán (distributed / 분산) transactions, leases/fencing, membership/khám phá dịch vụ (service discovery / 서비스 디스커버리), sự kiện (event / 이벤트) streaming, CRDTs, tải (load / 로드) shedding, multi-region consistency và protocol-level hiệu năng (performance / 성능).

> **Bàn giao:** Sau **Networks & phân tán (distributed / 분산) các hệ thống (systems / 시스템들) — lĩnh vực (domain / 도메인) Hub**, hãy chốt bất biến (invariant / 불변식) và giới hạn của mục này trước khi nối sang kiến thức kế tiếp. Có thể đọc tiếp [00 network layers packets and encapsulation](./00_network_layers_packets_and_encapsulation.md) để đối chiếu ranh giới (boundary / 경계) gần nhất.
