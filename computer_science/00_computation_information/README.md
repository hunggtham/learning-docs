# Computation & Information — Domain Hub

Phần nền tảng của domain này nằm tại [`../basic/00_computation_information/`](../basic/00_computation_information/). Nội dung đó xây mental model về information, encoding, machine representation, logic, state, abstraction và giới hạn của computation.

Khi đã nắm vững foundation, phần [`advanced/`](./advanced/README.md) đi sâu hơn vào formal models of computation, reductions, decidability/recognizability, complexity boundaries, information-theoretic reasoning và các liên hệ giữa specification, proof và khả năng tính toán.

```text
computer_science/
├── basic/00_computation_information/   # nền tảng
└── 00_computation_information/
    └── advanced/                       # chuyên sâu
```

Mục tiêu của tầng advanced không phải lặp lại định nghĩa Turing machine hay Big-O, mà dùng chúng để reasoning các giới hạn và trade-off ở mức đủ sâu cho compiler, verification, security, distributed systems và algorithm design.
