# Programming Languages & thời gian chạy (runtime / 런타임) — lĩnh vực (domain / 도메인) Hub

> **Mạch đọc:** Đọc **Programming Languages & thời gian chạy (runtime / 런타임) — lĩnh vực (domain / 도메인) Hub** như một mắt xích của lộ trình học (learning path / 학습 경로) hiện tại, không như một ghi chú tách rời. Hãy xác định đối tượng và câu hỏi trung tâm trước, rồi dùng phần này để đối chiếu với mục liên quan sau khi đã nắm mô hình tư duy (mental model / 사고 모델) chính.

Foundation nằm tại [`../basic/04_programming_languages/`](../basic/04_programming_languages/): ngữ nghĩa (semantics / 의미론), kiểu (type / 타입)/giá trị (value / 값)/tham chiếu (reference / 참조), phạm vi (scope / 범위)/closure, trình biên dịch (compiler / 컴파일러)/VM/JIT, paradigms, lỗi (error / 오류)/tài nguyên (resource / 자원) an toàn (safety / 안전), parsing và tính đồng thời (concurrency / 동시성) các mô hình (models / 모델들).

Phần [`advanced/`](./advanced/README.md) đào sâu kiểu (type / 타입) lý thuyết (theory / 이론) ứng dụng, tác động (effect / 효과) các hệ thống (systems / 시스템들), quyền sở hữu (ownership / 소유권)/borrowing, advanced GC, JIT tối ưu hóa (optimization / 최적화)/deoptimization, IR/SSA, FFI/ABI boundaries và thời gian chạy (runtime / 런타임) tính đồng thời (concurrency / 동시성).

> **Bàn giao:** Sau **Programming Languages & thời gian chạy (runtime / 런타임) — lĩnh vực (domain / 도메인) Hub**, hãy chốt bất biến (invariant / 불변식) và giới hạn của mục này trước khi nối sang kiến thức kế tiếp. Có thể đọc tiếp [00 language semantics and execution models](./00_language_semantics_and_execution_models.md) để đối chiếu ranh giới (boundary / 경계) gần nhất.
