# Bảo mật (security / 보안) & độ tin cậy (reliability / 신뢰성) — lĩnh vực (domain / 도메인) Hub

> **Mạch đọc:** Đọc **bảo mật (security / 보안) & độ tin cậy (reliability / 신뢰성) — lĩnh vực (domain / 도메인) Hub** như một mắt xích của lộ trình học (learning path / 학습 경로) hiện tại, không như một ghi chú tách rời. Hãy xác định đối tượng và câu hỏi trung tâm trước, rồi dùng phần này để đối chiếu với mục liên quan sau khi đã nắm mô hình tư duy (mental model / 사고 모델) chính.

Foundation nằm tại [`../basic/07_security_reliability/`](../basic/07_security_reliability/): threat modeling, cryptographic primitives, định danh (identity / 식별자)/truy cập (access / 접근), vulnerabilities, testing, độ tin cậy (reliability / 신뢰성), web bảo mật (security / 보안), key management và supply-chain bảo mật (security / 보안).

Phần [`advanced/`](./advanced/README.md) đi sâu vào attack-chain lập luận (reasoning / 추론), giao thức (protocol / 프로토콜) composition, định danh (identity / 식별자) federation, key vòng đời (lifecycle / 생명주기), sandbox/privilege boundaries, exploit mitigations, SRE độ tin cậy (reliability / 신뢰성) mathematics, sự cố (incident / 인시던트) phản hồi (response / 응답) và adversarial testing.

Khi chuyển từ mechanics sang điều tra một failure thực tế, dùng [Engineering Incident, Debugging & System Reliability](../../thinking/90_connections/02_engineering_incidents_and_debugging.md) để nối observation → hypothesis → causal evidence → system boundary → feedback/delay → intervention. Các tool [Problem Framing](../../thinking/problem-framing/README.md), [Causal Reasoning](../../thinking/causal-reasoning/README.md), [Systems Thinking](../../thinking/systems-thinking/README.md) và [Risk](../../thinking/risk/README.md) giúp tổ chức reasoning; Computer Science/Security vẫn là canonical owner của technical mechanism và controls.

> **Bàn giao:** Sau **bảo mật (security / 보안) & độ tin cậy (reliability / 신뢰성) — lĩnh vực (domain / 도메인) Hub**, hãy chốt bất biến (invariant / 불변식) và giới hạn của mục này trước khi nối sang kiến thức kế tiếp. Có thể đọc tiếp [00 threat models and security principles](./00_threat_models_and_security_principles.md) để đối chiếu ranh giới (boundary / 경계) gần nhất.
