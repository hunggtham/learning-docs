# A. 작문 — viết ngắn nhưng đủ ý

Một bài tốt không cần vocabulary quá khó. Thứ tự ưu tiên:

`đúng đề → đủ ý → câu rõ → từ khóa KIIP đúng → grammar ổn → connector vừa đủ`

## Khung 4 bước

```text
1. 주제 제시     — nêu chủ đề
2. 사실/경험     — fact hoặc trải nghiệm
3. 이유/비교     — vì sao / so sánh
4. 결론/태도     — kết luận / thái độ
```

## Template 1 — giải thích xã hội

```text
______은/는 한국 사회에서 중요한 제도/문화입니다.
이것은 ______을/를 위해 필요합니다.
예를 들면 ______이/가 있습니다.
따라서 ______하는 것이 중요합니다.
```

## Template 2 — trải nghiệm thích nghi

```text
저는 한국에서 ______을/를 경험했습니다.
처음에는 ______ 때문에 어려움이 있었습니다.
하지만 ______을/를 알게 된 후 이해하게 되었습니다.
그래서 지금은 ______하려고 노력하고 있습니다.
```

## Template 3 — so sánh

```text
A와 B는 모두 ______과 관련이 있습니다.
하지만 A는 ______이 중심이고, B는 ______이 중심입니다.
예를 들면 ______입니다.
```

## Connector đủ dùng

`먼저 · 그리고 · 하지만 · 그래서 · 따라서 · 또한 · 예를 들면 · 반면에 · 마지막으로`

Một bài ngắn không cần nhồi connector.

# B. 구술 — nói theo schema

Mục tiêu:

`정의 → 이유/기능 → 예시/비교`

Một câu trả lời tốt thường chỉ cần 2~4 câu rõ ràng.

## Schema 1 — 정의형

```text
______은/는 ______을/를 말합니다.
이것은 ______을/를 위해 필요합니다.
```

## Schema 2 — 비교형

```text
A는 ______이 중심이지만 B는 ______이 중심입니다.
그래서 ______에서 차이가 있습니다.
```

## Schema 3 — 이유형

```text
______은/는 중요합니다.
왜냐하면 ______기 때문입니다.
```

## Schema 4 — 순서형

```text
먼저 ______했습니다.
그다음 ______했습니다.
마지막으로 ______했습니다.
```

## Schema 5 — 기관형

```text
이 상황에서는 ______에 도움을 요청할 수 있습니다.
이 기관은 ______을/를 담당합니다.
```

# Sample answers

## 사회보험 vs 공공부조

`사회보험은 보험료를 바탕으로 질병, 실업, 노후 같은 사회적 위험에 대비하는 제도입니다. 공공부조는 생활이 어려운 사람을 국가가 공적으로 지원하는 제도입니다.`

## 삼권분립

`삼권분립은 국가 권력을 입법, 행정, 사법으로 나누는 원리입니다. 권력이 한 곳에 집중되는 것을 막기 위해 필요합니다. 입법은 국회, 행정은 정부, 사법은 법원이 담당합니다.`

## 광복 vs 정부수립

`광복은 1945년에 일본의 식민지 지배에서 벗어난 것을 말합니다. 대한민국 정부 수립은 그 이후인 1948년에 이루어졌습니다.`

## 현재 형사사법 구조

`수사는 범죄 사실과 증거를 조사하는 과정이고, 기소는 형사재판을 법원에 청구하는 것이며, 재판은 법원이 사건을 판단하는 절차입니다. 2026년 10월 2일부터는 검찰청이 폐지되고 공소청과 중대범죄수사청을 포함한 새로운 체계가 시행되고 있습니다.`

# Khi luyện nói, tự chấm 5 điểm

Mỗi câu 0/1:

- [ ] trả lời đúng câu hỏi
- [ ] keyword chính xác
- [ ] có định nghĩa hoặc luận điểm chính
- [ ] có lý do/ví dụ/so sánh
- [ ] nói được không nhìn note

`5/5` mới coi là đã nắm chắc.

> **Workflow:** `17 coverage → chapter gốc → 18 심화 nếu cần → file này → 14 active recall → mock`.
