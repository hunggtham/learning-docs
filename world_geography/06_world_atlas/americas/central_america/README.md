# Central America

Theo UN M49, Central America gồm Belize, Costa Rica, El Salvador, Guatemala, Honduras, Mexico, Nicaragua và Panama.

Đọc vùng này qua **cầu đất hẹp giữa hai đại dương + vành đai núi lửa + gió tín phong/gió mùa nhiệt đới + corridor Bắc–Nam + các cửa ngõ Caribbean/Pacific**.
