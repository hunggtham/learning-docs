# Melanesia

> **Mạch đọc:** [README](./README.md) là bản đồ owner của **Melanesia**; nhìn vào vị trí đó trước để biết file này đang phục vụ nhánh kiến thức nào. Bắt đầu ở **Melanesia** để mở đối tượng chính của file và câu hỏi cần theo dõi, rồi dùng kết luận đó khi quay về lộ trình rộng hơn.

Theo UN M49, Melanesia gồm Fiji, New Caledonia, Papua New Guinea, Solomon Islands và Vanuatu.

Các mẫu (pattern / 패턴) nổi bật là **active plate boundaries, volcanic island arcs, steep high islands, coral coasts, linguistic/cultural fragmentation, limited inter-island vận chuyển (transport / 전송) và high cyclone/earthquake exposure**.
