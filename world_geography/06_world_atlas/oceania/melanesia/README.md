# Melanesia

Theo UN M49, Melanesia gồm Fiji, New Caledonia, Papua New Guinea, Solomon Islands và Vanuatu.

Các pattern nổi bật là **active plate boundaries, volcanic island arcs, steep high islands, coral coasts, linguistic/cultural fragmentation, limited inter-island transport và high cyclone/earthquake exposure**.
