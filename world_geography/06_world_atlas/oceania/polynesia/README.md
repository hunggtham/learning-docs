Theo UN M49, Polynesia gồm American Samoa, Cook Islands, French Polynesia, Niue, Pitcairn, Samoa, Tokelau, Tonga, Tuvalu và Wallis and Futuna Islands.

Đọc Polynesia qua **ocean distance, điều hướng (navigation / 내비게이션), high-island vs atoll contrast, reef các hệ thống (systems / 시스템들), cyclone belts, freshwater bảo mật (security / 보안) và aviation/shipping lifelines**.
