## Mục đích

Kiểm tra (audit / 감사) này đo **độ sâu, khả năng giải thích và liên kết khái niệm**, không đếm tệp (file / 파일). Một topic chỉ được coi là vững khi người đọc có thể đi từ concept → cơ chế (mechanism / 메커니즘) → bằng chứng (evidence / 증거)/mô hình (model / 모델) → limitation → cross-link → ứng dụng (application / 애플리케이션) mà không phải dựa vào country fact sheet.

Trạng thái dùng ở đây:

- **Deep**: đủ làm tài liệu học chính.
- **độ sâu (depth / 깊이) pass**: vừa được nâng đáng kể; ưu tiên QA/cross-link hơn rewrite toàn bộ.
- **Solid**: đúng và khá sâu nhưng còn một số cầu nối (bridge / 브리지) quan trọng cần bổ sung.

## Vật lý (physical / 물리적) Geography

Sau nền tảng, audit chuyển sang các process vật lý tạo relief, khí hậu, nước, sinh thái và hazard. Đọc bảng theo chuỗi nguyên nhân này để thấy trạng thái của từng nhóm không phải những nhãn độc lập.

| Nhóm | Trạng thái | Ghi chú |
|---|---|---|
| Geological thời gian (time / 시간) / plate tectonics | **Deep** | Plate driving forces, boundaries, magma generation, earthquake mechanics, geologic timescale. |
| Geomorphology | **Deep** | Weathering/erosion/mass movement, fluvial/coastal/glacial/karst/desert các hệ thống (systems / 시스템들), sediment routing. |
| Atmosphere / weather | **Deep** | Stability, adiabatic processes, fronts, jets, tropical cyclone, NWP/ensemble, observation độ lệch (bias / 편향). |
| Climate | **Deep** | năng lượng (energy / 에너지) balance, ocean bộ nhớ (memory / 메모리), ENSO, classification, proxy/paleoclimate, spatial heterogeneity. |
| Hydrology | **Deep** | Basin balance, hydrograph/baseflow, groundwater/Darcy, sediment, drought lag, reservoir sự đánh đổi (trade-off / 트레이드오프), water bảo mật (security / 보안). |
| Oceans / coasts | **Deep** | Stratification, gyres/Ekman/upwelling, overturning, tides/waves, sediment cells, delta/estuary, ports/cables. |
| Soils / biomes / ecosystems | **Deep** | CLORPT, CEC/pH, nutrient cycling, disturbance, succession, fragmentation, biome dynamics, degradation. |
| Natural hazards / rủi ro (risk / 위험) | **độ sâu (depth / 깊이) pass** | Expected mất mát (loss / 손실), động (dynamic / 동적) vulnerability, compound/cascading rủi ro (risk / 위험), hạ tầng (infrastructure / 인프라) phụ thuộc (dependency / 의존성), adaptation options, resilience. |

### Vật lý (physical / 물리적) cross-link còn cần QA

Các chapter riêng lẻ đã sâu; khoảng trống tiếp theo nằm ở **cầu nối (bridge / 브리지) giữa tiến trình (process / 프로세스)**. Cần tiếp tục kiểm tra các chuỗi:

**tectonics → relief → sediment → river/delta/coast → settlement/rủi ro (risk / 위험)**;

**atmosphere/climate → water balance → soil/ecosystem → agriculture → hazard**;

**ocean/coast → cổng (port / 포트)/city → trade → compound coastal rủi ro (risk / 위험)**.

Mục tiêu của pass sau không phải tăng độ dài từng tệp (file / 파일) mà làm prerequisite/ứng dụng (application / 애플리케이션) links rõ hơn.

### Human tích hợp (integration / 통합) hiện tại

Agriculture, năng lượng (energy / 에너지)/resources và development không còn đứng như ba sector riêng. dùng chung (shared / 공유) mô hình tư duy (mental model / 사고 모델) hiện là:

**tài nguyên (resource / 자원) cơ sở (base / 기반) → hạ tầng (infrastructure / 인프라)/năng lượng (energy / 에너지) → productivity → processing/giá trị (value / 값) capture → vận chuyển (transport / 전송)/trade → city/household truy cập (access / 접근) → inequality/resilience**.

Pass tiếp theo nên kiểm tra trùng lặp, thêm quantitative examples khi thật sự giúp lập luận (reasoning / 추론) và giữ cross-links hai chiều.

Regional chapters hiện đều phải dùng cùng chuỗi (chain / 사슬):

**vật lý (physical / 물리적) cơ sở (base / 기반) → water/resources → settlement → economy → vận chuyển (transport / 전송) → urban hierarchy → trade → regional role → hazard/transformation**.

## Khoảng trống tiếp theo

1. **Physical cross-link QA**: tectonics/geomorphology ↔ hydrology/sediment ↔ coasts/hazards.
2. **Population–urban–development bridge**: thêm causal examples và quantitative reasoning có chọn lọc, tránh lặp định nghĩa.
3. **Regional cross-link QA**: mỗi region nên trỏ tới core prerequisites và 1–3 Atlas learning cases có giá trị thật.
4. **Selective Atlas**: Thailand/Philippines chỉ promote nếu đạt full profile; long tail giữ Reference/Inventory.
5. **Atlas cleanup**: classify legacy short files thành `reference / merge / remove`; không dùng file count làm metric.
6. **Internal-link validation** sau depth passes lớn, ưu tiên broken relative links và duplicate concept.
